# MVK Live — повторный аудит настоящих профессиональных программ: подписи, настройки, оси и рабочие графики

**Дата:** 18.11.2026. **Ветка:** feature/mvk-live-standalone-20261117.

**Причина:** в исходной версии MVK Live в операторских формах ошибочно использовались X/Y: «Шкала амплитуды Y», «Шкала частоты X», «Развёртка X», «Амплитуда ±Y», «Предел X», «Масштаб Y». Такой язык не раскрывает, какую физическую величину оператор меняет. Этот аудит основан на **настоящих экранах и руководствах программ**, а не на догадках по скриншоту и не на общем слове «современно».

**Оговорка к фактам:** в **расширенных настройках** DewesoftX, OROS, Adash и SKF встречаются технические слова «X Axis» / «Y Axis», «X-Unit» / «Y-Unit». Было бы неверно утверждать, что таких слов нет ни в одной профессиональной программе. Для **обычного оператора MVK Live** сознательно используем названия физических величин; X/Y допустимы только во внутренних математических моделях и технической документации. Исключение для будущей орбиты: физически осмысленные X–Y каналы двух ортогональных датчиков, **не** абстрактные подписи настроек графика; только после подтверждённой синхронизации.

## 1. Реальные интерфейсы и что проверено

### DewesoftX — источник терминов настройки спектрального анализа и разделения Setup/Measure

- Официальный FFT Analyzer: https://manual.dewesoft.com/x/setupmodule/modules/freqdomain/fftapplication
- FFT Preview Widget: https://manual.dewesoft.com/x/measure/viscontrol/freqdom/fftanalysis
- Организация пользовательских экранов: https://manual.dewesoft.com/x/measure/displaydesign
- [Настоящий screenshot настроек FFT](https://manual.dewesoft.com/assets/img/FFTanalyser/fft_setup.png)
- [Настоящий screenshot рабочего экрана Recorder+FFT](https://manual.dewesoft.com/assets/img/screen_design.png)

**Непосредственно видимые настройки:**
- Output spectra: Amplitude, Complex, Max hold;
- Amplitude format: Peak / RMS / Peak-Peak;
- FFT Window: Rectangular / Hanning / Hamming / Flat Top / Blackman и другие;
- Resolution: Lines / Δf (Hz) / Block duration (s);
- Overlap и Averaging: No / Block-based / Overall; Linear / Energy / Energy exponential / Maximum;
- Frequency range: Start/End frequency; спектральная величина Linear / Power / PSD / ASD / ESD;
- В виджете дополнительной визуализации есть «X Axis (f)», «Y Axis (Value)», tick types и types шкал. **Это расширенные свойства графического виджета, а не образец названий основных параметров измерения.**

**Использовать:** разделить (A) физический источник, (B) алгоритм FFT/PSD, (C) представление результата, (D) экранные границы. Контекстные свойства на правой панели. **Не копировать** входные приборные параметры Dewesoft: устройство MVK01 управляет Fs/FRange через свой фактический приём, который этот UI не меняет.

### OROS NVGate — отдельный анализатор, источник, результаты и маркеры

- Официальная wiki FFT: https://wiki.oros.com/index.php?title=NVGate_FFT
- Официальный пример главной панели: https://wiki.oros.com/index.php?title=NVGate_Software_overview
- Официальный пример спектра огибающей / гармоник: https://wiki.oros.com/index.php?title=NVGate_Envelope_analysis
- [Screenshot FFT 1 / Main / Profile / Waterfall](https://wiki.oros.com/images/e/e4/AddingFFT.png)
- [Screenshot harmonic marker огибающей](https://wiki.oros.com/images/9/99/Envelope_08.png)
- [Screenshot sideband marker](https://wiki.oros.com/images/7/7e/Envelope_06.png)

**Наблюдения:** FFT 1–4 как разные расчётные модули; отдельно Channel (source/filter), Average, FFT analysis (Range, resolution, overlap), FFT zoom, Overall, status; разные результаты Inst. spectrum / Avg. spectrum, отдельные Main / Profile / Waterfall. Маркеры Harmonic и Sideband прямо на спектре, не вынесены в единственный текстовый блок. Технические свойства окна называются X/Y, но ключевые операторские измерительные поля — Range, Lines, Average, Input filter, Trigger.

**Использовать:** один приём MVK01 → несколько независимых представлений; отдельные окна тяжёлых методов, запись исходных данных не зависит от открытия окна; спектр огибающей с гармониками, боковыми полосами, амплитудами и результатом курсоров. **Не копировать** «FFT zoom» как простое изменение экранной верхней частоты: в OROS это иной расчётный режим.

### Adash VA5 Pro и DDS — инженерная краткость, физические единицы, курсоры и сравнение

- Руководство прибора VA5, раздел Spectrum и Graph Properties: https://adash.com/documents/A4500/Adash-VA5-manual.pdf
- Руководство DDS, Graph Type / Overlay / X-Unit / Y-Unit / Quantity: https://adash.com/documents/DDS/Adash-DDS-software-manual.pdf
- [Настоящий DDS screenshot гармонических семейств](https://adash.com/img/tutorial-videos/dds-tutorial-6.png)
- [Настоящий DDS screenshot разных графиков](https://www.ars-vibration.com/wp-content/uploads/2018/02/Picture6.png)

**VA5 Spectrum measurement:** Type=spectrum; Channel; Window=hanning; Unit=mm/s; Band fmin=10 Hz; Range=400 Hz; Lines=1600; t=4 s; df=0.25 Hz; Averaging, Avg, Overlap, Zoom Spectrum. **VA5 Time:** собственные Band fmin/fmax, Sampling Freq, Samples, trigger, duration. Заголовки результата показывают физику: диапазон, N/L, длительность, единицы «mm/s RMS», скорость, частота и значение курсора.

**DDS:** графические представления Amplitude, Amplitude+Phase, Amplitude+Trend, Amplitude Stacked, Waterfall, Spectrograph, Overlay нескольких сохранённых спектров. Есть контекстное изменение количества, единиц, частот и скорости, cursor/families. Его технические пункты X-Unit/Y-Unit и более старомодный ribbon **не переносим буквально** в современные быстро доступные поля MVK.

**Использовать:** плотный график, компактный статус Fs/N/T/Δf, отдельные «Показать гармоники», «Боковые частоты», «Маркеры подшипников», а также архивное совместное отображение нескольких сохранённых спектров. Разные входные Fs, единицы, полосы и рабочие условия должны сопровождаться проверкой сравнимости.

- Официальный каталог курсоров/наложений: https://cdn.skfmediahub.skf.com/api/public/0901d196805b1063/pdf_preview_medium/0901d196805b1063_pdf_preview_medium.pdf

**Фактические инструменты:** Single Cursor, Harmonic Cursor, Band Cursor (два предела, Δf и Δlevel), Sideband Cursor (пары около частоты), Peak Cursor (отмечает реальные пики), overlay settings, Frequency list. В archive/trend можно переходить к конкретному измерению. **Не брать** обязательную иерархию завод→агрегат→точка для MVP MVK Live: текущая задача — независимый приборный анализатор.

## 3. Нормальная русскоязычная номенклатура для MVK Live

### Применить ко всем операторским экранам (без X и Y)

| Неправильно | Правильно и что реально меняется |
|---|---|
| Шкала частоты X | **Частотная шкала** · Линейная / Логарифмическая. Только отображение, реальные Hz |
| Шкала амплитуды Y | **Шкала значений** · Линейная / В децибелах (с указанной опорой) |
| Предел X | **Показывать частоты до** · ... Гц. Только видимая верхняя граница, не новый Fs |
| Амплитуда/Масштаб Y | **Масштаб спектра** · Авто / фиксированный уровень. Реальные единицы текущего FFT/PSD/ASD |
| Развёртка X | **Развёртка времени** · мс/с |
| Мгновенная амплитуда ±Y | **Масштаб виброускорения** · Авто / ±м/с² |
| X минимум / X максимум | **Частота от, Гц / Частота до, Гц** |
| Y минимум / Y максимум | **Уровень от / Уровень до** (единица соответствует действующему спектру) |
| «X логарифмическая» | **Логарифмическая частотная шкала** |
| «X время, Y м/с²» | **Время, с · Виброускорение, м/с²** |

**Не переименовывать численные форматы в то, чем они не являются:** PSD — (единица)²/Гц, ASD — (единица)/√Гц, FFT — RMS конкретной спектральной линии. Переключатель «В децибелах» не является второй логарифмической трансформацией уже рассчитанных децибел.

### Главная панель, только реальное

- Профиль подключения, Измерить, Стоп, Freeze, Сохранить окно, АЦП 1–8, состояние потока и RAW (без постоянных IP-полей).
- Вкладки: **Обзор | Спектр | Временной сигнал | Расчётные данные**.
- Обзор: **СКЗ виброускорения**, **СКЗ виброскорости**, **Пик виброускорения**, **Крест-фактор**, два больших графика. Никаких 43 заглушек методов.
- График спектра: компактный заголовок «Спектр ВУ · FFT · АЦП 1», физические шкалы **Частота, Гц** и **Виброускорение, м/с² СКЗ линии**, маленькая строка Fs/N/T/Δf/фильтр/источник. Для PSD/ASD подставляется правильная единица. На графике — реальные курсоры/гармоники только когда включены.
- График времени: «Временной сигнал · АЦП 1», **Время, с**, **Виброускорение, м/с²** (знаковая амплитуда). Freeze не останавливает RAW.
- Правый инспектор показывает только параметры **активного** графика и не уменьшает его до нечитаемого размера.

### Правая панель для спектра — целевая последовательность

\`\`\`text
Спектр
  Величина                Виброускорение · м/с²
  Анализ                  FFT · СКЗ линии
  Шкала значений          Линейная
  Частотная шкала         Линейная
  Показывать частоты до   1000 Гц
  Масштаб спектра         Авто
  Фильтр спектра          Без фильтра
  [ Точные параметры ▾ ]
      FFT N = 32768   T=N/Fs   Δf=Fs/N
      Окно Hann, Welch усреднение — если выбран Welch
      Опора дБ, сглаживание, локальная АЧХ
  [ Вернуть автомасштаб ]
\`\`\`

**Не показывать одновременно** параметры FFT/Welch/огибающей: показывать секцию, относящуюся к выбранному анализу. Значения по умолчанию брать из реального состояния кода, а не из желаемой дорожной карты.

### Правая панель временного сигнала — целевая последовательность

\`\`\`text
Временной сигнал
  Развёртка времени       1 с
  Масштаб виброускорения  Авто  (или ±... м/с²)
  Фильтр временного сигнала  Без фильтра
  [ Подробнее ▾ ]
      Смещение замороженного сигнала
      АЧХ локального фильтра
\`\`\`

**Оценка LIVE/ОКНО/АРХИВ:** эти элементы должны работать и без прибора только там, где есть реальная NPZ; не использовать фиктивные sample traces и приборную команду при выборе графика.

## 4. Влияние на остальные окна

- **Огибающая / подшипники:** поля «Полоса демодуляции, Гц», «Обороты, об/мин», «Количество тел качения», «Диаметры, мм», «Угол контакта, °», «Гармоники H1…Hn», «Боковые полосы», «Допуск, Гц/%», «Минимальный локальный SNR». График — **Частота, Гц** и **Амплитуда огибающей, м/с² СКЗ линии**. Сначала независимые измеренные пики, потом проверка близости к расчётным BPFO/BPFI/BSF/BDF/FTF.
- **Кюртограмма:** «Частота центра полосы», «Ширина полосы», «Спектральный эксцесс», «Уровень разложения», а не произвольные «оси X/Y».
- **Водопад:** «Частота, Гц», «Время измерения / номер кадра», «Уровень спектра, [ед.]». В архиве время должно быть подтверждённым, не выдуманным UTC момента измерения.
- **STFT:** «Время, с», «Частота, Гц», «Уровень, [ед.]»; при открытии среза — соответствующий «Спектр выбранного момента».
- **Сравнение спектров:** «Период измерений», «Выбранные записи», «Единица вибрации», «Режим анализа», «Частотная область», «Наложение / по отдельности», «Совместимость данных». Разные приборные источники AUX4700 и NPZ — раздельно.
- **Тренды:** «Дата и время записи/сохранения (с оговоркой)», «Значение показателя», «АЦП», «Условия», «Режим». Не считать saved_utc доказанным временем получения данных с МВК01.

## 5. Кодовая приёмка и границы изменения

Только подписи/текст интерфейса, не алгоритм:
- modern_shell.py: названия полей инспектора спектра и времени.
- app.py: пункты combobox шкалы, legacy toolbar captions, status/help, диалог ручного масштаба и подписи осей.
- test_qt_modern_graphs.py: регрессионная проверка, что операторские поля названы физическими величинами; численные значения, enum keys и DSP не меняются.

**Проверить:** Qt smoke без прибора, 1280×720/150% DPI, 1920×1080/100%, длинные значения комбобоксов, log frequency with DC omitted, смена FFT ↔ PSD ↔ ASD не меняет физические единицы неверно. Не менять Native TCP/RAW/IPC/FRange/AUX4700, не включать скрытую имитацию измерения.

## 6. Результат

**Основной принцип:** оператор выбирает **что измеряет**, **как вычисляет**, **какую часть спектра видит** и **в каких единицах оценивает результат**. Он не должен мысленно переводить X в частоту, а Y в амплитуду, особенно когда вместо FFT выбран PSD, огибающая, временной сигнал или тренд. Техническое X/Y — детали реализации, а не язык главного окна.
