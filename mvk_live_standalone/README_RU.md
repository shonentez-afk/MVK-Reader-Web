# MVK Live Standalone — независимый анализатор вибрации МВК01

**Статус:** экспериментальная программа Windows; отдельная ветка
**feature/mvk-live-standalone-20261117**, не затрагивающая основную ветку
и восстановление оригинального MVKView.

## Установка, запуск, приём

Готовый комплект Windows собирается GitHub Actions как
**MVK_Live_Standalone_Windows_Experimental**. Распакуйте ZIP и запустите
MVK_Live.exe. Точно соответствующий Native R6.1 Go EXE и его SHA256
включены в комплект. **Вручную задаётся только IP МВК01.**
При запуске в Windows программа без сетевых запросов определяет
**единственную активную физическую проводную Ethernet-карту**
и автоматически подставляет её локальный IPv4. Имя сетевой карты,
IP и индекс отображаются в главном окне; кнопка
«Обновить Ethernet» повторяет обнаружение. Wi-Fi, VPN и виртуальные
адаптеры не выбираются автоматически. Если проводной Ethernet
не обнаружен, не имеет пригодного IPv4 или на нём несколько адресов,
программа не угадывает адрес: показывает причину и допускает ручной
ввод после проверки конфигурации Windows. Программа не меняет IP,
маску, шлюз или состояние сетевой карты.

Окончательное TCP-подключение по порту 10230 происходит **только**
после нажатия «Подключить и измерять» и отдельного разрешения
оператора. Go Native повторно проверяет, что локальный IPv4
принадлежит активному интерфейсу, и в Windows привязывает сокет
к его индексу через `IP_UNICAST_IF` без молчаливого перехода
на другое сетевое соединение. Никакого SetRate, Flash, записи регистров или
дополнительного TCP/10230 к прибору MVK Live не выполняет.

Go Native владеет единственным соединением и оригинальными RAW/BIN.
GUI читает только выбранный ADC из уже существующего Go-кольца через
ограниченный аутентифицированный IPC на 127.0.0.1. Для ранее разрешённых
сеансов без IPC предусмотрен проверенный ZIP-превью.

Запуск Python из корня репозитория:
- py -3 -m pip install numpy scipy PySide6 pyqtgraph pytest
- py -3 -m mvk_live_standalone.app
- py -3 -m mvk_live_standalone.app --capture-root C:\path\to\capture_root

## Полностью без TACH и без эталонных измерений

**Тахометр не подключается, не декодируется и не используется.**
Существующие исходные 10 Go-колец, включая исходные TACH хранилища,
не модифицируются ради этого интерфейса.

Частоту вращения **1×** можно ввести **вручную** или получить
**предложение по спектру виброскорости (ВС)**. Кнопка
«Предложить 1× из ВС» находит низшую заметную гармонику, проверяет
2×–5×, локальный SNR, разрешение FFT и уровень уверенности.
Только отдельная кнопка «Применить 1×» принимает предложение.
При неоднозначных спектрах обороты могут быть определены неверно:
предложение не эквивалентно тахометру.

**Никакой сверки с внешними эталонными измерениями не добавлено.**
Тесты используют лишь самостоятельно сформированные синтетические
сигналы для проверки математических и программных инвариантов.

## Режимы спектрального анализа

| Режим | Линейная ось Y | Логарифмическая ось Y |
| --- | --- | --- |
| FFT виброускорение ВУ | м/с² СКЗ спектральной линии | дБ отн. опоры м/с² |
| FFT виброскорость ВС | мм/с СКЗ спектральной линии | дБ отн. опоры мм/с |
| FFT виброперемещение ВП | мкм СКЗ спектральной линии | дБ отн. опоры мкм |
| PSD Welch ВУ/ВС/ВП | (единица)²/Гц | 10 log10(PSD / ref²) |
| ASD Welch ВУ/ВС/ВП | (единица)/√Гц | 20 log10(ASD / ref) |
| 1/3-октавы | физическая СКЗ каждой полосы | 20 log10(СКЗ / ref) |
| Огибающая Hilbert | м/с² СКЗ спектральной линии | 20 log10(СКЗ / ref) |

Физические опоры дБ: 10⁻⁶ м/с², 10⁻⁶ мм/с, 10⁻⁶ мкм
(соглашение ISO 1683) либо 1 соответствующая физическая единица.
Они всегда явно указываются. Это не приборный дБ и не dBFS;
вторая логарифмическая трансформация Y не выполняется.

ВУ → ВС/ВП по 1/(2πf), 1/(2πf)²; DC исключается, для
широкополосного интегрирования используется ограничение HP ≥2 Гц.
PSD интегрируется по частоте для реальной широкополосной СКЗ,
а не для пика отдельной линии. Butterworth SOS и выбираемый
Notch 50/60 Гц работают **локально**; notch по умолчанию отключён,
чтобы не скрыть механическую гармонику. Доступны готовые полосы
и собственные частотные границы с явной проверкой Nyquist.

## Диагностика подшипников и редукторов

Оператор задаёт 1× и геометрию подшипника. Рассчитываются
теоретические **BPFO, BPFI, BSF, FTF** с их гармониками;
реальные пики огибающей сопоставляются только с локальным
фоном текущего сигнала (SNR в дБ), **не с эталоном**.
Превышение порога SNR — не самостоятельный диагноз.

Полоса демодуляции — ручная или **автопоиск по ограниченному
двоичному фильтробанку с куртозисом огибающей**.
Это *kurtogram-like* приближение, не полный Fast Kurtogram Антони;
уровень уверенности и выбранные границы показываются.

По заданному числу зубьев редуктора формируются маркеры
**GMF, 2–3 GMF, GMF±1×…±3×**. Реальные обороты по
датчику TACH никогда не утверждаются.

Справочная историческая диаграмма ISO 10816-3 запускается
**только по инициативе оператора**, требует известного класса
машины, RPM 120–15000 и полного диапазона ВС 10–1000 Гц.
Это не оценка соответствия ISO 20816, не диагноз,
не внешнее эталонное измерение. Класс оборудования не угадывается.

## Графики, история, сохранение

- Временной сигнал ВУ: диапазон развёртки 0,1–30 с, пиково-
  сохраняющая децимация без интерполяции.
- **Заморозить графики** — останавливает только отображение.
  **Приём и RAW-запись продолжаются**. Доступен просмотр
  ранее накопленных отсчётов со сдвигом по времени.
- Спектры с линейным или логарифмическим X,
  дБ или физической линейной Y, курсор, ручные пределы осей.
- Водопад последовательных подтверждённых FFT/PSD;
  тренд СКЗ ВУ по новым порциям данных.
- STFT (частота–время), CWT Morlet (**качественная**),
  реальный кепстр (ось кэфренции, секунды). Тяжёлые
  представления запускаются отдельной кнопкой.
- Признаки: RMS, peak, peak-to-peak, crest, Pearson kurtosis,
  skewness, impulse, shape, clearance; широкополосная ВС СКЗ.
- **Оригинальные AUX4700** полностью отображаются для каждого АЦП
  во вкладке «Оригинальный DSP»: отдельно **43 третьоктавных
  значения СКЗ виброускорения** с известными центрами 0,63–10000 Гц,
  а также **24 исходные позиции × 3 значения** — СКЗ (`band_rms`),
  пик (`band_peak_equiv`), размах/пик-пик
  (`band_span_equiv`). То есть декодер Go передаёт **115 значений
  на канал**. Для 24 позиций исходники пока не подтверждают однозначные
  частоты, единицы и точную физическую трактовку peak/span, поэтому
  интерфейс показывает номера позиций и значения *без выдуманных частот
  и пересчётов*. Состояние «не готово»/NaN отличается от нуля.
  Регистровые смещения в исходном AUX4700 соответственно:
  `base+0x02`, `base+0x60`, `base+0xA0`, `base+0xE0`.
  Оригинальные значения **никогда не подменяются** результатами
  локального расчёта APP_DERIVED.
- «Сохранить окно» — NPZ, проверка локального SHA256;
  «Открыть запись» — OFFLINE анализ без соединения с МВК01;
  «Экспорт спектра» — CSV с физической единицей/шкалой;
  «Сохранить график» — PNG.
  NPZ — не криптографическое доказательство подлинности
  оригинального приёма. IP, токены и регистры не экспортируются.

## Ограничения и приёмка

Автоматические тесты выполняются на синтетических сигналах и
без физического МВК01. Производительность IPC на конкретном ПК,
точность обнаружения 1×, длительная запись, ошибки
сети и рабочие режимы прибора требуют эксплуатационной
проверки **без сверки с отсутствующими эталонными измерениями**.
Успешный GitHub CI и Windows EXE не означают промышленную
метрологическую аттестацию.
