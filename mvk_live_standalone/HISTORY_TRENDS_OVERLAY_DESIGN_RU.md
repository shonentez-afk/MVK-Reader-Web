# Тренды и наложение сохранённых измерений MVK Live

**Рабочая ветка:** `feature/mvk-live-standalone-20261117`.
**Назначение:** анализ истории измерений вибрации МВК01, выбор АЦП и физического показателя, сравнение сохранённых записей разных дат. **Не эталонная база** и не проверка по эталону.

## Почему именно такой интерфейс

У профессиональных виброанализаторов встречаются два основных подхода:

1. **Связанные тренд и спектр**: выбирают канал, измеряемый показатель, дату, затем переходят к соответствующему спектру/осциллограмме. Примеры: SKF @ptitude Analyst (Trend/Spectrum), VibCloud (Single-Point Analysis: date navigator, time waveform and FFT panels).
2. **Сравнение нескольких дат**: выбирают несколько измерений одного канала, затем накладывают графики в общих единицах либо показывают по отдельным связанным панелям. Примеры: SKF Combined Spectrum, VibCloud Multi-Spectra Comparison, AMS Machine Works.
3. **Архив исходных записей и повторный анализ**: библиотека сохранённых измерений, возможность повторно открыть сигнал и рассчитать FFT без повторного измерения. Пример: GitHub `gdipace23/spectrum-analyzer-python`. GitHub `SBG-Systems/sbgECom` сохраняет отдельно временные скалярные RMS/Peak-показатели и полные FFT кадры с временными метками.

Для МВК01 объединены эти принципы. Наложение графиков на одной оси (выбор пользователя) дополняет linked-trend → chosen-measurement workflow. Исторический ряд **не создаётся из числа перерисовок**: исходные пакеты берутся из уже существующего журнала Native Go.

Публичные примеры для справки (код сторонних проектов не копируется):
- SKF @ptitude Analyst manual: https://cdn.skfmediahub.skf.com/api/public/0901d1968048ddc5/pdf_preview_medium/0901d1968048ddc5_pdf_preview_medium.pdf
- VibCloud Online user guide: https://itnnovate.atlassian.net/wiki/spaces/VCH/pages/2741239809/VibCloud+online+-+user+guide
- Dewesoft Condition Monitoring: https://dewesoft.com/applications/condition-monitoring
- GitHub SpectrumAnalyzer: https://github.com/gdipace23/spectrum-analyzer-python
- GitHub SBG BasicLogger: https://github.com/SBG-Systems/sbgECom/tree/main/tools/sbgBasicLogger

## Что происходит с данными в MVK Live

**Вкладка «Тренды».** Выбор общего АЦП 1–8, группы показателя и частоты/номера исходной позиции, затем периода (всё, 7/30/90/365 дней). X — действительная дата/время записи; Y — соответствующая физическая величина, **без перемешивания единиц**. Приборные ряды: 43 третьоктавных СКЗ виброускорения (центры 0,63–10 000 Гц), 24 позиции СКЗ, 24 позиции Пик, 24 позиции Размах с не подтверждёнными единицами. Локальные ряды: ВУ RMS, Пик, Пик-пик, Crest, Kurtosis, Skew, Impulse, Shape, Clearance и ВС RMS 10–1000 Гц при допустимой Fs. Тренд по клику выбирает исходное измерение, откуда можно перейти к сравнению и раскрыть соответствующий график.

**Вкладка «Сравнение».** Выбор конкретных сохранённых дат через таблицу (до 8 линий), цвет и легенда для каждого времени. Режимы: четыре FFT-представления (**логарифмическая ВУ, линейные ВУ/ВС/ВП**); осциллограммы ускорения с общей временной координатой относительно конца сохранённого окна; оригинальный третъоктавный DSP (43 частоты); приборные оригинальные 24 позиции СКЗ/Пик/Размах. Сравниваются **измерения одного выбранного АЦП**. Переключение режима показывает только совместимые архивные записи, а не складывает FFT и размах из прибора в одни неизвестные единицы. Частотные сетки хранятся как есть; если Fs различается, область общего сравнения ограничена меньшей частотой Найквиста. Данные не подгоняются интерполяцией, нормализацией или эталонами.

**Хранение истории.** Каталог `Документы/MVK_Live_Archive` (по умолчанию Windows) либо `--archive-root` / `MVK_LIVE_ARCHIVE_DIR`: индекс `measurements.sqlite`, собственные проверяемые `windows/*.npz`. SQLite хранит происхождение, номер АЦП, исходное время, номер обновления AUX4700 или время сохранения NPZ и SHA. Архив доступен после перезапуска программы, не исчезает при очистке Live-буфера.

**Оригинальный расчётный поток прибора.** Native Go уже создаёт `<сеанс>/aux4700.jsonl` с **каждым** декодированным AUX4700: 8 АЦП на пакет, 43+24+24+24 величины, `time_utc`, `update`. MVK Live читает его инкрементально, сохраняет смещение дочитанного байта, не повторяет один пакет и не читает незавершённую строку. В буферизованном журнале последние строки могут появиться лишь после записи/финализации Go; проверенный Live-статус временно даёт последнее актуальное значение до сброса буфера. Для прежних запусков кнопка **«Импорт AUX4700»** выбирает каталог сеанса, без подключения к прибору.

**Сохранённый временной сигнал АЦП.** Кнопка **«Сохранить окно АЦП в архив»** записывает текущий проверенный канал или выбранный участок frozen history. `.npz` содержит **уже умноженные Native Go на FRange один раз** Float32, Fs, АЦП, счётчик и локальную SHA; дубли не добавляются. При импорте старых NPZ история использует **время добавления файла**, а не сочиняет неизвестную приборную временную метку. FFT в сравнении вычисляется **из сохранённого калиброванного NPZ с выбранным NFFT**, поэтому результат обозначен APP_DERIVED, **а не «оригинально сохранённый прибором FFT»**. Приборные сохранённые 43+24x3 берутся напрямую из AUX4700 без локального спектрального пересчёта.

**Безопасность и пределы:** нет новой связи TCP/10230, передачи команд МВК01 и изменения FRange; без тахометра; без эталонных измерений. Отсутствующие/NaN значения исходного DSP не превращаются в нули. Сравнение до восьми линий, историю на графике ограничиваем последними 15 000 записями в выбранном интервале (весь первичный SQLite-журнал не удаляется). Все файлы остаются на ПК пользователя. 

## Проверки

- Полный оригинальный журнал (8 АЦП и несколько обновлений), хранение между перезапусками, no duplicate, partial JSONL, запрет обрезанного журнала;
- исходные 115 ячеек, null/NaN без подмены, правильные единицы третьоктавных/24 позиций;
- NPZ SHA и уникальность, локальные временные признаки/ВС RMS; просмотр старого файла без прибора;
- Qt: шесть вкладок, выбор метрики по АЦП, смена дат, переход «тренд → выбор измерения», наложение двух/трёх FFT и осциллограмм в физических единицах, приборные 43/24, предупреждение о разных Fs;
- прежние FFT/Оригинальный DSP/сеть/торможение/заморозка не должны ломаться.

**Ограничения приёмки:** GitHub CI проверяет ПО на искусственных данных, но **не подтверждает подключение к реальному прибору МВК01**, метрологию и поведение при длительном промышленном архиве.
