# MVK Reader Web

Локальный веб-интерфейс и Collector Server для приборов МВК01: временные сигналы, оригинальные расчётные данные DSP, спектры и архив.

## Главное архитектурное решение (29.10.2026)

**Получение данных с реального МВК01 решено и подтверждено Native R6.1 на приборе №84 (Stage109, 30-секундный Windows Live).** По TCP/10230 без клиентских прикладных команд принимаются **8 АЦП, 2 тахометрических канала, AUX4700 со штатными расчётами DSP и коэффициенты калибровки текущего сеанса**. После приёма корректно создаются 8 BIN/TSXML, VALUES и TABLE; численные данные сверены с оригинальным потоком.

**Для штатных СКЗ, виброскорости, перемещения, третьоктавных спектров и состояний источник истины — данные, вычисленные DSP прибора, а не независимые приближённые формулы приложения.** Исходные АЦП используем для временных графиков, записей и явно обозначенных *локальных* FFT/аналитики. Разница со старым самостоятельным расчётом до ~25% больше не блокирует основную функциональность.

**Обязательно читать перед любыми изменениями:** [ADR — оригинальные данные МВК как источник истины](docs/ADR_2026_10_29_ORIGINAL_MVK_DSP_DATA_SOURCE_RU.md).

## Состояние версий

- **v0.3.40 CALCULATED MODES OFFLINE** — существующая стабильная основа интерфейса; код не изменять без отдельной приёмки.
- **Native R6.1 / Stage108–109** — автономный проверенный Windows read-only приёмник и экспортёр, **ещё не интегрирован в основной интерфейс**. [Исходный код исследовательской версии](https://github.com/shonentez-afk/MVK-Reader-Web/blob/research/stage41-spectrum-chain-20261028/tools/research/native_tcp10230_stage108_live_recording_r6_1), [отчёт аппаратного испытания](https://github.com/shonentez-afk/MVK-Reader-Web/blob/research/stage41-spectrum-chain-20261028/docs/research/STAGE109_R6_1_FIRST_REAL_LIVE_DEV84_ACCEPTANCE_RU.md).
- **Следующий Stage110:** интеграция проверенного источника данных в UI, отображение оригинальных DSP-значений с происхождением/единицами и статусами, архив, защита от ошибок; затем длительные тесты и сравнение оформления файлов с MVKView.

## Протокол и безопасность

- TCP/10230 — 8 × ADC (256 float32 LE одного канала в 1052 B), 2 TACH, AUX4700, системные регистры и gain. Схема запуска: `TCP Connect → Read`; без отправки прикладной команды.
- TCP/502/FC03 — отдельный **опциональный read-only** путь по согласованию; для чтения DSP-расчётов из подтверждённого TCP/10230 **не обязателен**. Modbus-записи и неподтверждённые команды запрещены.
- Один Collector на прибор, многие браузеры/потребители одного потока. Не подключаться к работающему оборудованию без разрешения пользователя и ответственных.
- Live R6.1 проверен пока на одной модели/приборе и 30 с; многочасовые записи, reconnect и byte-exact MVKView одной сессии остаются незакрытыми. Это **не отменяет факта решения приёма**.
