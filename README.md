# MVK Reader Web

Локальный веб-интерфейс и Collector Server для приборов МВК01: временные сигналы, FFT-спектры, расчётные данные и архив.

## Состояние проекта

- **Последняя собранная базовая версия:** v0.3.40 CALCULATED MODES OFFLINE. Полный исходный пакет находится в подготовленном архиве для локального тестирования; перенос исходников в этот репозиторий **ещё не завершён**.
- **TCP/10230:** поток временных отсчётов восьми АЦП, 65536 отсчётов/с на канал, непрерывное получение при активном соединении.
- **TCP/502:** Modbus TCP FC03, расчётные показатели и параметры калибровки.
- **Автоматическая калибровка подтверждена для АЦП 4 двух приборов:** `acceleration_m_s2 = raw_tcp10230_float32 * conversion_gain_from_modbus`.
- **Ограничение:** прибор, по наблюдению, допускает одного клиента TCP/10230; TCP/502 остаётся доступным SCADA. Проверка подключения пассивного клиента без прикладных команд пока ожидается.
- **Безопасность:** не писать в Modbus; не запускать неподтверждённые команды управления TCP/10230; сервер по умолчанию слушает `127.0.0.1`.

## Назначение веток и релизов

`main` — подтверждённые версии. Версии фиксируются тегами, а архивы для Windows — через GitHub Releases после проверки. Промежуточные исследования и изменения — через отдельные ветки и PR.
