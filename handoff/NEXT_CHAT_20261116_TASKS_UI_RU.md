# MVK — передача новому чату: начальный экран оригинала, 16.11.2026

## Цель
Полностью восстановить **внешний вид и поведение MVKView 1.0.47**, сохраняя отдельное уже реализованное вычислительное ядро Qt-копии. Не возвращаться к поиску BIN/FRange/FFT вместо интерфейса.

## Репозитории
- Основной: `shonentez-afk/MVK-Reader-Web`, ветка `research/stage111-mvkview-desktop-20261029`.
- Компьютерный MCP для оригинала: `shonentez-afk/MVK-GigaCode-Exchange`, версия MVK Research MCP 0.3.4.
- Дополнительный компьютерный плагин DSH: `dsh-computer-use-win`. Текущий агент DSH: **Nemotron 3.5 Super VL**, не GLM.
- Основной статус: `START_NEW_CHAT_RU.md`, `CURRENT_STATUS_RU.md`. Предметный новый аудит: `docs/research/STAGE111Z31CO_ORIGINAL_EMPTY_TASKS_UI_EVIDENCE_20261116_RU.md`.

## Что пользователь предоставил
Три документа первичного осмотра оригинала БЕЗ ИЗМЕРЕНИЙ:
1. `mvk_original_empty_ui_manifest(1).json`
2. `mvk_original_empty_ui_report(1).md`
3. `mvk_original_empty_ui_unknowns(1).md`

Сообщённое состояние: `Tmvkform` открыт/развёрнут, вкладка **«Задачи»** — единственная видимая, запись не загружена. Видимые кнопки: **«Измерение»**, **«Загрузка сигнала из файла»**, **«Настройка параметров измерительных каналов»**, **«Настройка системных параметров»**. Есть поле IP, локальный каталог записей и кнопка обзора, логотип БАСТ. UIA дерево частичное, 10 элементов.

**Ограничение:** оригинальный PNG находится только во временном каталоге рабочего Windows PC, файл в чат не приложен; SHA256 в JSON — `pending`. Отчёт говорит 1920×1020 PNG, а окно имеет Win32 rect 1942×1042 со смещением -11,-11, поэтому абсолютные пиксельные координаты в двух системах нельзя считать единым эталоном без снимка и пересчёта. Сырые IP/пути и изображения НЕ заливать в публичный GitHub.

## Что уже реализовано в текущей Qt-копии
- `source_visual_skin.py::update_runtime_tabs` скрывает шесть из семи корневых внутренних страниц на старте; source mode показывает только `PageStart`; после загрузки отображает `PageStart`, `PageAdc`, `PageSpectrum`.
- `original_task_ui.py` + `original_start_ui.py` + `original_start_workbench.py`: PageStart уже создан по Delphi DFM, 4 видимые кнопки и пятая скрытая калибровочная, IP и каталог, безопасная Core-маршрутизация. Дополнительные Qt-only элементы локальной библиотеки скрываются в обычном source UI.
- Qt-подписи временные и отличаются от живого оригинала: «Подключение к прибору» вместо «Измерение», «Просмотр измерений» вместо «Загрузка сигнала из файла», «Настройка каналов» вместо полной фразы, «Настройка IP» вместо «Настройка системных параметров»; подписи IP/каталога также отличаются.
- Системные Qt-иконки не равны исходным картинкам, хотя приватный DFM-picture loader имеется. Не внедрять проприетарные ресурсы в публичный GitHub.
- Прежние выводы по 8 всегда видимым вкладкам относятся к СТАРОМУ сборочному артефакту, в новом коде уже исправлено. Факт отсутствия восьми ADC вкладок на стартовом экране не означает, что оригинал поддерживает один физический канал.

## Следующий шаг — только парный захват двух стартовых экранов
1. Оригинальную MVKView оставить открытой, развёрнутой, на «Задачи», без измерения. Никаких кликов или приборных действий.
2. В DSH сохранить ранее сделанный PNG из временной папки на постоянный диск; если исчез — один раз переснять `dsh-computer-use-win` и вычислить SHA256.
3. Оператор вручную запускает **актуальную Qt-копию** без измерения (если не запущена), выставляет одинаковые экранные размеры/DPI. Agent только на чтение снимает второй PNG и UIA/Win32 состояния.
4. Подготовить `original_vs_compatible_empty_ui_diff.md` + SHA256 обоих PNG, истинные физические bounds, интерфейсные ошибки с приоритетами. Не считать source DFM logical coordinates физическими px при DPI150 без преобразования.
5. Затем **одним функциональным пакетом** исправить PageStart UI (русские подписи, кнопки, пиктограммы, размеры, поля, логотип, фон), оставить безопасную Core маршрутизацию, добавить тест Qt empty-state и visual regression. Не разрывать GUI/Core.

Для DSH подготовлен файл `MVK_NEMOTRON_EMPTY_UI_COMPARE_PROMPT_20261116_RU.txt`. До явного согласования запрещено: переключения, открытия данных, изменение настроек и любые сетевые команды. UIA `IsEnabled` можно читать без нажатия, если провайдер это поддерживает.

## Принцип достоверности
Разделять наблюдения из исходного PNG/Win32/UIA, DFM/source-derived структуру и гипотезы агента. **Новая версия ядра/GUI или успешные Actions CI не доказывают pixel parity без парного реального снимка оригинала и копии.**
