## Что уже реализовано в текущей Qt-копии
- `source_visual_skin.py::update_runtime_tabs` скрывает шесть из семи корневых внутренних страниц на старте; source mode показывает только `PageStart`; после загрузки отображает `PageStart`, `PageAdc`, `PageSpectrum`.

- Qt-подписи временные и отличаются от живого оригинала: «Подключение к прибору» вместо «Измерение», «Просмотр измерений» вместо «Загрузка сигнала из файла», «Настройка каналов» вместо полной фразы, «Настройка IP» вместо «Настройка системных параметров»; подписи IP/каталога также отличаются.
