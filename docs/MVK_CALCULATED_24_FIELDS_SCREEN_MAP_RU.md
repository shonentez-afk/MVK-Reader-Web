# Карта 24 расчётных параметров по экрану MVKView, АЦП 4

Источник — снимок экрана прибора A, канал АЦП 4, предоставленный пользователем 2026-10-26. Порядок строк непосредственно прочитан со скриншота; привязка к индексам RAW опирается на ранее выполненный структурный разбор кадра длиной 4700 байт.

Индексы указаны относительно 144 чисел float32 каждой записи канала, **не** как глобальные байтовые смещения 4700-байтового сообщения. Физические единицы в интерфейсе: ускорение м/с², скорость мм/с, перемещение мкм.

Ограничения: названия пользовательских полос не раскрывают их фактические границы; для них использованы названия custom1/custom2. На скриншоте все три показателя custom2 равны 0. Эти нули относятся только к показанному состоянию, не обязательно ко всем RAW-кадрам. Значения с экрана и RAW не синхронизированы по времени. Соответствие всех 24 пар физических полос с исходным сигналом не проверено независимо.
