# Unified MVK Decoder — Stage 2, регрессия 3 новых RAW

Дата 2026-10-26. Реальное исполнение Python офлайн на распакованных `results.7z`; дополнительный артефакт: `MVK01_UNIFIED_DECODER_STAGE2_20261026.zip` (поставляется отдельно, не включён в репозиторий). Главная v0.3.40 не затрагивалась, TCP к прибору не открывался.

## Фактические результаты

| Сеанс | ADC | TACH | AUX44 | AUX160 | AUX4700 | AUX76 | ADC gaps | Trailing |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 83 первый | 30700 | 7674 | 3837 | 135 | 30 | 30 | 0 | 0 |
| 84 | 30707 | 7676 | 3838 | 135 | 30 | 30 | 0 | 0 |
| 83 повторно | 61358 | 15340 | 7670 | 270 | 60 | 60 | 0 | 0 |

Только три дескрипторных переключения: 83-первый `ADC2 entry4 C11 -> C15`; 83-повторно `ADC2 entry4 C11 -> C15 -> C11`. У 84 переключений 0. Дополнительные AUX160 changes нельзя путать с изменениями дескрипторов.

Диагностические маски: 83-первый ADC1 `0x800` 30/30, ADC5 `0x400` 30/30; 83-повторно те же 60/60. 84 ADC7 `0x400` 30/30, ADC8 `0x400` 30/30, подтверждённое пользователем отображение «Обрыв кабеля» в штатном MVKView.

## Исправления в независимом прототипе

1. Уникальные имена JSON-аудита по каталогу сеанса (в исходной Stage1 три `capture.raw` перезаписывали один отчет).
2. Отдельное поле `aux160_descriptor_transitions` в сводке, в дополнение к общим изменениям `aux160_events`.
3. Добавлен `collector_offline_adapter.py` для replay **только из файла** в JSONL событий и JSON отчета. Текущий JSONL содержит метаданные/смещения кадров, а не массивы сигналов — это проверка интерфейса, не завершённый Collector.
4. 7/7 локальных unittest PASS; при реальном replay нового RAW №84 получены ожидаемые числа кадров и отсутствие ошибок.

## Ограничения и следующий этап

Требуется API передачи самих отсчётов и калибровки в Collector, потоковые тесты на разных размерах пакетов, логика неполных/потерянных данных. Актуальный прототип не следует объявлять production-ready. Код и архив Stage2 доступны как отдельная выдача пользователю; **в GitHub сейчас только журнал этапа**.
