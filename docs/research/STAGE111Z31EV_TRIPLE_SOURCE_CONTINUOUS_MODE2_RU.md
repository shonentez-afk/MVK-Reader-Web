## Согласованное восстановление Go / Core / Qt

- Go `-seconds=0` работает до команды остановки либо **до лимита RAW**. Разрешается только при явном `-stop-file` и `-approve`, без автоматического TCP. Значения `1..300` остаются рабочими.
- Основной TCP цикл и **цикл source Task2 reconnect** интерпретируют отсутствие срока одинаково; чтение по-прежнему имеет ограниченные ожидания для обработки stop context. Не добавляются новые TCP-сокеты, команды или разрешения.
- Core `CaptureSpec` валидирует нулевую длительность и продолжает создавать уникальный каталог, односессионный stop sentinel, принудительный лимит RAW; статусы `target_seconds=0` проходят строгую проверку.
- Qt по умолчанию показывает «До отключения», при реальном LIVE предоставляет неопределённый progress, время с начала записи и точный исходный лимит. Кнопка «Отключить» применяет ранее существовавшее штатное завершение без `QProcess.kill`; реальная SetRate по-прежнему выключена.
- Go loopback-тест непрерывного TCP без пакетов и с отменой, Core тесты безопасности и настоящие Qt-тесты UI не подключают промышленный прибор.
