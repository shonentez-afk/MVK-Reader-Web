# Stage111Z31CZ — исходные WriteDataStage / WriteValuesStage, Core+Qt

Источник — **локальный архив оператора** `Projects.7z`: 
`Projects/_Unit125.pas`, `Projects/_Unit128.pas`, `Projects/mvkform.dfm`, IDR `mvkview.idp`.
Ни один исходный файл, IP, снимок оператора, EXE или бинарный захват
не коммитился в публичный GitHub.

## Подтверждённые исходные обработчики

- `_Unit128:0084E914 bWriteAdcClick` проверяет, что `MvkThread`
  создан; устанавливает `WriteDataTime`, копирует **10** `cbFileChannels`
  в `ChannelsToWrite[0..9]`, устанавливает/снимает `WriteData`.
- `_Unit128:0084E988 bWriteValuesClick` независимо устанавливает
  `WriteValuesTime`, копирует **43 SPEC, 24 ADC-values, 43 band-values,
  6 TACH-values**, затем копирует те же десять каналов и
  переключает `WriteValues`.
- `_Unit125:008061CD/008061D4`: оба начальных этапа **2 (IDLE)**.
  `00809453..0080980A`: `WriteDataStage: 2 → 0` после успешного
  открытия выбранных десяти файлов, первый обработанный ADC1-блок
  `00808294..008082A3` переводит в **1**, выключение записи закрывает
  файлы и возвращает в **2**. Пишутся реальные блоки в имеющиеся
  `ChannelFile[channel]`, не нарисованные графики.
- `_Unit125:00809811..008099C8`: `WriteValuesStage: 2 → 1 → 2`;
  отдельный `ValuesFile`, строковые CSV значения, закрытие по
  снятию `WriteValues`.
- `_Unit125:00809330` содержит очередь из 12-байтных записей
  (`Cmd,Addr,Data`), `00809364` готовит запрос с `Cmd=1`,
  `Addr=0x0E`, `Data=MvkSampleRate`, а `SetRate 00809400`
  ставит команду только при изменении значения. Исходное меню создаёт
  пять пунктов из `gvar_008D2F7C`. Пять значений в оригинальной таблице
  НЕ извлечены и пользовательский прибор не применялся; отправка
  `SetRate` в Go остаётся запрещённой. Не путать с пятью уже
  принимаемыми Go частотами 512/2048/8192/32768/65536 Гц.

## Реальный совместимый функционал пакета

1. `core/original_live_write_stages.py` — независимый Core-счётчик
   стадий 2/0/1 для DATA и 2/1 для VALUES, точные маски
   10/43/73, 8 ограниченных интервалов. Каждое действие привязывается
   к **одному подтверждённому** `session_id` Native, монотонным
   счётчикам реально полученных ADC/TACH отсчётов, `AUX4700` и
   `frames_decoded`; другой `session_id`, откат, ошибочные кадры,
   просроченный статус или отключение — сбрасывают незавершённый
   интервал, исходный RAW сохраняется.
2. Кнопки **bWriteAdc/bWriteValues** исходной панели `pnMeasure`
   теперь реально начинают/закрывают интервалы по подтверждённому
   Native R6.1 статусу. Они отключены при отсутствии подтверждения
   подключения. Новых исследовательских контролов и вкладок не
   добавлено; старые 96-DPI логические координаты не меняются,
   Qt масштабирует их однократно при 150%.
3. После успешных `captureEnded(True)` и `archiveReady(path)`,
   когда `OfflineSession` повторно проверил SHA-связанность ZIP,
   отдельный `QThread` безопасно экспортирует настоящие выбранные
   интервалы в **НОВЫЙ** `LOCAL_SOURCE_WRITE_WINDOWS_NATIVE`
   рядом с архивом сеанса. ADC Float32 берётся из проверенных
   Native-калиброванных BIN, TACH Float32 из отдельно проверенного
   Native-UNSCALED входного потока. Для VALUES используются только
   проверенные AUX-тиков/числа DSP в том же архиве. Копирование
   потоковое с SHA исходника и экспортируемого интервала.
4. `SOURCE_WRITE_WINDOWS_AUDIT.json` содержит исходный RAW SHA,
   границы каждого из десяти каналов, выбранные маски, SHA каждого
   созданного файла, наличие/отсутствие данных и честные ограничения.
   Исходные `incoming.raw`, ZIP/TSXML/BIN не меняются; существующие
   выходы не перезаписываются. Любая ошибка убирает только
   новый локальный каталог, без фальшивых измерений.

## Важные ограничения

Это **проверенный совместимый локальный экспорт выбранных окон**, а не
заявление о побайтовой реализации Delphi `TMVKThread.ChannelFile` или
точности момента клика 20 мс. Границы выбраны по **последним успешно
проверенным Go JSON-статусам** (период штатного опроса сейчас ~900 мс),
а затем переносятся на точные номера отсчётов в SHA-проверенных файлах.
При задержке опроса возможна разница с оригинальными границами
оператора. У таблиц также исходные, но не оригинальный Win32 CSV-
байтовый формат. TACH-unscaled не подменяет калиброванные физические RPM.

Весь приборный путь **read-only**: нет команд `TMVKThread.SetRate`,
`WriteData`, `WriteValues`, Modbus или управления самим МВК.
Исходный Go пишет FULL RAW полностью и независимо от кнопок Qt.
Проверка Same-run аппаратной идентичности должна проводиться отдельно
на работе с одобрением оператора.
