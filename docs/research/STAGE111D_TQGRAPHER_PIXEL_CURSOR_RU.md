# Stage111D — TQGrapher pixel-cursor reconstruction (2026-10-29)

**Статус:** код исследовательского Desktop, полная оригинальная MVKView ещё НЕ ПРИНЯТА. **Ветка:** `research/stage111-mvkview-desktop-20261029`. Никаких Live подключений/прикладных команд прибору и публикации промышленных данных.

## Задача и подтверждённая оригинальная механика

Из приватного Delphi IDR `Projects.7z` исследованы `_Unit115.pas`, `_Unit128.pas`. В GitHub **не загружены** PAS, DFM, IDP, бинарники или производственные RAW/BIN.

| Оригинальный адрес | Установлено непосредственно по IDR |
|---|---|
| `TQGrapher.UpdateCursor:007CA75C` | Обновляет `CursorPos` **в экранных пикселях**; перерисовка/форматирование при изменении |
| `sub_007CA76C:007CA811–007CA832` | Позиция должна быть **строго внутри** `PixelLeft..PixelRight`; иначе `CursorString` очищается |
| `sub_007CABE4:007CABE4–007CAC12` | `Trunc((pixel-PixelLeft)*stoiM+stoiC)` с ограничением диапазона `[0,DataSize-1]` |
| `007CA84A–007CA870` | Начало диапазона `index(pixel)`, конец `index(pixel+1)-1` |
| `007CA873–007CA8BE` | При `FindPreciseXValue=1` поиск **максимума signed float32 значения**, а не максимума модуля; равные значения сохраняют первый бин |
| `007CA8D4–007CA912` | Выбранный индекс переносит линию курсора по `itosM/C` и X-значение `index*XScale+XStart` |
| `007CA9F3–007CAA42` | При `CursorAveraging<=1`: `Series.Data[index]*YScale` |
| `007CAA47–007CAADA` | При `CursorAveraging>1`: сумма квадратов `float32` на `[max(0,i-floor(A/2)),min(DataSize,i+floor(A/2))]` **включительно**; затем `sqrt(SUM)` * `YScale`; **НЕТ деления на число отсчётов** |
| `_Unit128.pas:00844B90` | Для `SpecGrapher` включён `FindPreciseXValue=1` |
| `_Unit128.pas:00848252–0084828C` | В определённом режиме спектра `CursorAveraging=1`, в других `=3`; в графическом кандидате режима dB — 1, линейных — 3; точная связь всех enum/типов требует испытания оригинала |
| `007B2090` | Форматирование `CursorString` (исходная шкала/округление) открыто для исследования |

**Главная коррекция раннего handoff:** термин «RMS соседних бинов» был неточным. В оригинальном `CursorAveraging=3` используется **sqrt(sum of squares)** без деления на три. Это уже отражено в отдельном ядре и синтетических тестах.

## Реализовано в отдельной Qt Desktop архитектуре

- `mvk_compatible/core/tqgrapher_cursor_candidate.py`: `CursorGeometry`, `pick_tqgrapher_cursor()`, `cursor_from_spectrum()`. Никаких Qt, HTTP, TCP, сетевых соединений; исполняются только от заданного спектрального массива/экранной геометрии. Проверка границ, non-finite, неверных масштабов. Особое внимание: **максимум signed**, выбор первого при совпадении, ограничение краёв, корень суммы квадратов.
- `mvk_compatible/core/offline_export.py`: `OfflineSession.pixel_spectrum_cursor()` для вычисления курсора по **полному N/2 FFT**, не по прореженным графическим точкам.
- `mvk_compatible/desktop/main_window.py`: полный непрореженный спектр хранится в `_full_spectrum` и подаётся в курсор; Qt/pyqtgraph отображает только выбранный диапазон и при необходимости **прореживает линию отдельно**. Позиция мыши в пикселях ViewBox конвертируется в `stoiM/C` текущего масштаба. Настройки «Пик в пикселе (IDR)» и `CursorAveraging` 1/3; отрисовка курсора переносится к выбранной частоте FFT. Значение и provenance подписаны «кандидат TQGrapher».
- `mvk_compatible/tests/test_tqgrapher_cursor_candidate.py`: автономные проверки многобинного пикселя, signed-пика, первых равных пиков, низкой плотности FFT, разрешённых значений 1/3, точного `sqrt(sum squares)`, краёв, пустых/нечисловых параметров, запрета decimated spectra, реального синтетического FFT и меток источника.
- `mvk_compatible/tests/test_desktop_qt.py`: Windows offscreen Qt проверяет наличие двух режимов усреднения, полный буфер FFT, переключение log/linear и выбор курсора по реальным координатам сцены.

## Граница доказательств

Численный и визуальный parity с оригинальной Delphi **не доказан**. В текущем Qt-переводе пиксельной геометрии используется текущий `ViewBox`, а `TQGrapher` вычисляет свои `stoiM,C`/`itosM,C` с отступами/масштабами. Остались различия x87 округлений, выбора абсциссы при зуме/скролле, форматирования `CursorString`, серия 2, графических цветов и сетки. Для итоговой приёмки нужны скриншоты и оригинальный экспорт курсора при одинаковом BIN/N/mode и пиксельной ширине.

Спектр и AC по-прежнему `APP_DERIVED_*_CANDIDATE`, штатные приборные СКЗ, третьоктавы, Peak и статусы берутся **только из AUX4700/VALUES**, а не из пиксельного курсора.
