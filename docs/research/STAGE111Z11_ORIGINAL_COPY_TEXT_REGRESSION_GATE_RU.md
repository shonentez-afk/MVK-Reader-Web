# Stage111Z.11 — отдельная сверка текста «Копировать» без повторного BIN/FFT

**Дата:** 01.11.2026. **Ветка:** `research/stage111-mvkview-desktop-20261029`. **Основной продукт:** автономная Windows MVKView Compatible.

## 1. Почему можно проверять только текст

На Stage111Z.10 пользователь через x32dbg в original MVKView прочёл **три исходных Single**:

- `OutputMean=40DC8F5E` → 6.892500877380371;
- `OutputPeakX=466D8095` → 15200.1455078125 **FFT bins**;
- `OutputPeakY=3F475279` → 0.7786021828651428.

Режим `Tag0`, N=262144, Fs=65536, XScale=Fs/N=0.25. Расчётная частота PeakX × XScale = **3800.036376953125 Гц**. Все три значения уже **побитово совпали 3/3** с нашим source-derived `core/spectrum_metrics_idr_candidate.py`, но оригинальный текст кнопки «Копировать» `bSpecCopyValueClick` ещё **НЕ ПРЕДОСТАВЛЕН**.

Согласно приватному Delphi source `_Unit128 0084BC28`, исходная программа подаёт в `007B2090` (Delphi FormatFloat-подобный helper) три значения с указанными точностями/масками 3 / 4 / 4 и соединяет их TAB. Исходный helper вычисляет маску количеством *значащих цифр*, а не всегда просто 3 или 4 десятичных знака после запятой.

**Прогноз существующего кандидата** при десятичной запятой (не оригинальный runtime golden):

```text
6,89<TAB>3800<TAB>0,7786
```

При десятичной точке: `6.89<TAB>3800<TAB>0.7786`. Запись `<TAB>` в примере обозначает один настоящий символ табуляции, не буквальную последовательность. Возможные ошибки RTL/регионального формата выявлять сравнением с оригиналом; **не подменять** исходный текст этим прогнозом.

## 2. Новый приватный локальный компаратор

Добавлен `mvk_compatible/private_spectrum_copy_runtime_compare.py`, который использует **только оригинальные три Single hex + Fs/N** из Stage111Z.10 `summary_capture.json` и отдельную оригинальную строку Copy. Повторно выполнять FFT, читать закрытый BIN, угадывать FRange, менять прибор или просматривать исходный IDP ему не требуется.

Сравнивает три текстовых поля индивидуально с `spectrum_triplet_text` / `format_cursor_idr_candidate`. Выдаёт только SHA256 оригинального локального текста, bool для Mean/Frequency/PeakY и общий bool; **не выдаёт на stdout реальную строку или конфиденциальные значения**. Отказывается от испорченного UTF8/CP1251, файлов-ссылок, лишних полей/неправильного N/Float32, нескольких строк и неподдерживаемых локалей. При несовпадении вернёт exit code 1, при недопустимом вводе — 2.

Добавлен `mvk_compatible/tests/test_stage111z11_original_copy_runtime_compare.py`: только искусственные source-derived clipboard строки и явная замена одного поля; НЕ тест с оригинальной Delphi.

## 3. Что сделать в оригинальной MVKView

1. Открыть тот же локальный офлайн архив, тот же канал, **логарифмический режим** и тот же спектр N262144 с Fs65536.
2. Нажать в оригинальной программе кнопку **«Копировать»** значения спектра (Delphi `bSpecCopyValueClick`).
3. Вставить в Блокнот одной строкой: там должны быть **три числа, разделённые TAB**; сохранить как `C:\MVK_CAPTURE\copy_original.txt` (UTF-8 или CP1251; если доступен UTF-8, предпочесть его). Если файл сохранился из Блокнота со скрытым BOM, формат `utf-8-sig` учтён.
4. Если сохраняется приватно, в локальной копии репозитория запустить:

```powershell
python -m mvk_compatible.private_spectrum_copy_runtime_compare --summary-manifest "C:\MVK_CAPTURE\summary_capture.json" --reference "C:\MVK_CAPTURE\copy_original.txt" --decimal ","
```

При английской локали использовать `--decimal "."`, для CP1251 `--encoding cp1251`. Или передать только содержимое строки в чат для сравнения, но **не** отправлять исходный BIN/IDP в публичный репозиторий.

## 4. Граница результата и далее

- **VERIFIED 3/3**: оригинальная numeric summary для одной operator-reported сессии, Stage111Z.10.
- **PREDICTED ONLY**: видимый Delphi Copy текст, форматирование 007B2090 и региональные разделители.
- **SOURCE STRUCTURE**: Clipboard TAB и три поля + XScale; настоящий оригинальный Clipboard пока не сравнивался.
- **Далее Stage111Z.12:** `CursorString`, точные GDI/Qt подписи и координаты графика TQGrapher/TPaintBox при реальном reference с локальным архивом. Другие режимы Tag1/2/3 и независимые N/каналы требуют отдельного numeric golden.

Стабильную `main`, Web v0.3.40, закрытые оригинальные архивы, прибор и источники EXE/IDP не трогать.
