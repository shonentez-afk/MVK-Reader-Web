# Stage111Z31BJ — первый законченный пакет «Core + видимый интерфейс»

Дата: 2026-11-11. Ветка: research/stage111-mvkview-desktop-20261029.
Принятая база BH: source 9d5f6b3ec5503d52753ed7e6041609ea33996278; GitHub Actions #43002778865 SUCCESS. Статус BJ и точный Windows Artifact записывать по фактическому успешному CI.

## Почему прошлый вариант почти не менялся

В BD–BH изменения шли главным образом в автономный Core, а файл основной Qt-формы почти не изменялся. На оригинальной PageFile оставались одна-две заглушки, хотя OfflineMeasurementFlow уже отдавал Native VALUES/AUX, 24 расчётных показателя и 43 третьоктавных полосы. Успешный CI не подтверждал ни реальное пользовательское поведение, ни 1:1 оригинал.

## Реализовано в BJ

1. Автономный Core: mvk_compatible/core/original_file_workbench.py. Один неизменяемый FileWorkbench из проверенного OfflineMeasurementFlow.source_record и, отдельно, из актуального MVK_DSP snapshot только того же serial/tick/ADC. Никаких новых FFT/калибровки/устройства. Реальные sample count, Fs, длительность, source BIN SHA256, ADC, тик; при Native ZIP — 24 показателя RMS/PEAK/PEAK-PEAK и 43 третьоктавные полосы. Отсутствующий пик или AUX не подменяется RMS. Для BIN/TSXML показывается явное отсутствие приборных AUX/VALUES/третьоктав/физической калибровки.
2. Реальный экран: mvk_compatible/desktop/original_shell.py. Исходная PageFile с двумя tcFileActions вкладками, tcFileChannels, cbFileSpec, cbFileValues и original splitter сохранена; списки теперь содержат измеренные данные вместо заглушек. Дополнительная вкладка «Источник (офлайн)» показывает таблицу метаданных, а безопасные кнопки fileGoSignal/fileGoSpectrum/fileGoStatus ведут в существующие рабочие окна PageAdc/PageSpectrum/PageStatus с тем же источником. Новая диагностическая панель — это OFFLINE дополнение, не утверждение оригинальной DFM pixel parity.
3. Основное окно: mvk_compatible/desktop/main_window.py очищает старый VALUES/AUX snapshot до загрузки нового сеанса, а после проверки текущего тика синхронно передаёт данные в PageFile. Переход ZIP→BIN очищает 24/43 прошлых значений. Исходные FFT/FIR/LOG и Native R6.1 не переписываются.
4. PageStart: mvk_compatible/desktop/original_task_ui.py. Кнопка bTaskView действительно открывает PageFile, откуда доступна загрузка локального измерения. Исходные logical размеры DFM сохранены, добавлены системные временные Qt иконки (не закрытые оригинальные bitmap ресурсы). Config/Calib/device writes не разблокированы.
5. Сквозные тесты Core+Qt: test_stage111z31bj_original_file_workbench.py и test_stage111z31bj_qt_visible_file_workbench.py. ZIP/ADC/tick/24/43/реальные графики, затем BIN/ADC4/отсутствие фальшивого DSP и очищение состояния. Обновлены старые тесты, предполагавшие одну строку-заглушку. Windows DPI150 дополнительно сохраняет шесть реальных PNG скриншотов Qt, которые генерируются ТОЛЬКО на синтетических fixture и публикуются в отдельный CI Artifact. Приватные оригинальные EXE/IDP/PAS/DFM/BIN/PNG/измерения не передавать в CI.

## Как оператору увидеть разницу

Открыть EXE -> главный экран -> «Просмотр измерений» -> PageFile -> «Открыть локальную запись…» -> выбрать Native ZIP либо BIN+TSXML. У Native ZIP увидеть 24 реальных VALUES и 43 полосы; во вкладке «Источник (офлайн)» — provenance BIN. Нажатия на «Временной сигнал», «Спектр», «Расчётные данные» переключают реальные рабочие страницы без нового сеанса. Если открыть BIN вместо ZIP, предыдущие приборные показатели исчезнут, графики строятся только по реальным Single.

## Новое ОБЯЗАТЕЛЬНОЕ правило всех дальнейших этапов

НЕ делать новые длинные Core-only исследования без переноса в интерфейс. Один крупный функциональный пакет = проверенный исходный алгоритм + автономный Core + работающий видимый экран + проверки на одном источнике/ADC/тике + Qt end-to-end/Windows DPI150 + синтетические screenshot QA. Называть 1:1 совместимостью только то, что дополнительно сверено на одном файле с реально запущенным оригинальным Win32-процессом. Объединять взаимосвязанные изменения, без микро-PR.

## Не завершено

Оригинальные изображения ilPages/ilTasks, реальные локализации, полная семантика PageFile как оригинального экспорта и аппаратные команды; калибровка; весь спектр режимов/62 обработчика; Pixel/численная paired Win32 runtime parity. Следующий большой пакет: единая оригинальная PageAdc+PageSpectrum+PageStatus с настоящим рисунком графиков, шкалами, курсорами и всеми данными, одновременно Core+UI. Нельзя считать только сборку EXE или synthetic UI скриншоты доказательством полного восстановления.
