# Stage 55 — декодирование расчётных измерений AUX4700
Дата: 2026-10-28. Работа с прошивкой отделена от проекта, здесь только измерения по TCP/10230.

Офлайн разобраны `83 первый(1).pcapng` и `84 отдельно(1).pcapng`: соответственно **42410** и **42430** полных кадров, по **30** кадров `0xFF800C0D` длиной 4700 байт. Оба захвата заканчиваются 816 байтами незаконченного 1052-байтного кадра без ошибки синхронизации.

Каждый 4700-байтный блок: 28 байт общего заголовка + 8 записей ×584 байта. Каждая запись содержит u32 заголовка `(290 << 16) | (0x2000 + 0x200*n)`, 144 float32 LE и последний u32 статус. Идентификаторы восьми записей: `0x2000`, `0x2200`, `0x2400`, `0x2600`, `0x2800`, `0x2A00`, `0x2C00`, `0x2E00`.

По прибору .83 слово float32 №47 для АЦП4 имеет диапазон 0.356649–0.379193, для АЦП6 10.265–10.983335. По прибору .84 поле №47 равно **0 во всех 240 записях** (30×8), хотя многие другие поля ненулевые. **Не считать это отсутствие вибрации** без проверки назначений КП и конфигурации. Старый парсер `cap_parse.py` предварительно называет слово 47 RMS ВУ до 25 кГц, но точное значение требуется перепроверить с TABLE/VALUES.

Локальный пакет воспроизводимости `MVKVIEW_STAGE55_MEASUREMENTS_20261028.zip` содержит `analyze_aux4700.py`, `STAGE55_AUX4700_CHANNELS.csv` (16 строк каналов двух приборов) и полный отчёт. Новые измерения на оборудовании не делались. Stable v0.3.40 не менялась.
