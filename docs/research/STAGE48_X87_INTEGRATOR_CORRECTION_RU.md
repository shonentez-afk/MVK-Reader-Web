# Stage 48 — исправление трактовки инструкции x87 fdivrp

Дата: 2026-10-28. Источник: IDR экспорт `_Unit115.pas`, процедура `0x007D2164`.

**Исправление ошибки Stage 46–47:** после `fild [ebp-4]` стек ST0=k; после `fld [7D219C]` стек ST0=C=159.154943091895, ST1=k. Инструкция `fdivrp st(1),st` вычисляет **C/k**, а не k/C. Умножение на аргумент N/fs даёт

`K=C*N/(k*fs)=1000/(2*pi*f_k)`, где `f_k=k*fs/N`.

Таким образом, для `k>=1` процедура умножает спектральную мощность на `K²`. Один вызов соответствует переходу м/с² в мм/с, два — м/с² в мкм при сохранении единиц на промежуточном шаге. Нулевая частота обнуляется.

**FRange:** ветвь чтения отсчётов `0x007D22C8` при определённом `FAdcDataType` делит на FRange, а ветви линейного результата `0x007D1667`, `0x007D16F1`, `0x007D17B0` умножают на FRange. Безусловное сокращение FRange во всех путях пока не доказано.

**Проверено:** 11/11 опорных инструкций и три контрольные частоты: 5 Гц => 31.8309886184, 25 Гц => 6.36619772368, 100 Гц => 1.59154943092. Сравнения с UI или реальным прибором не выполнялись.

Использовать **исправленную** формулу Stage 48; Stage 46 содержит неверную формулу, Stage 47 фиксирует обнаруженное противоречие. Стабильная версия v0.3.40 не изменена.
