# Stage111Z31A — эталон оригинальных Power/Y на том же графике Qt без FFT и без обязательного архива

**Дата:** 03.11.2026. **Ветка:** `research/stage111-mvkview-desktop-20261029`.
Назначение: автономная Windows MVKView Compatible; source-derived оригинальный спектр 4 режимов numeric accepted на пользовательских исходных захватах Stage111Z30C; **пиксельный паритет оригинальной TQGrapher ещё НЕ принят**.

## Исходный незакрытый дефект

В старой схеме оператор должен был открыть BIN/ZIP архив в Qt и самостоятельно выставить канал, оконную позицию, FRange, N, Fs, Tag, надеясь, что они совпадают с оригинальной MVKView. Для Captures Tag2/3 оригинальные значения `[EBX+20]` даже различались при идентичном pre-mode Power SHA. Следовательно, несовпадение Qt↔оригинал на картинке было нельзя однозначно отнести к графическому слою.

**Решение Stage31A:** отдельно показать в том же `pbSpectrum` действительные исходные Power/Y Float32, сохранённые оператором на реальной оригинальной остановке `007D17E7`, без GetSignal, без FFT, без дополнительной интеграции, без фиктивной калибровки и без обязательного открытия другого архива. Это **режим сравнения отрисовки**, не новая запись/измерение и не новая копия исходных данных в GitHub.

## Реализовано в ветке

1. `core/original_spectrum_x32dbg_reference.py` — строгая локальная загрузка JSON-манифеста `MVKVIEW_X32DBG_SPECTRUM_POWERY_REFERENCE_V1` + `power_after_mode.bin` + `display_y.bin`. Проверяются точный original stop VA `007D17E7`, valid N/Fs/mode/FRange Single bits, размеры N/2×4, SHA256 каждого файла, относительные безопасные имена, отсутствие symlink/path traversal, конечные Float32/неотрицательная Power, 0 два нижних бина. Затем существующий **неизменённый** `source_derived_mode_display` вычисляет full Y из оригинального Power и сверяет все Float32 биты. При единственном несоответствии манифест REJECT. Опционально сравнение 3 original summary HEX с текущим source-derived Summary. Копирования/saving raw массивов нет.
2. `desktop/main_window.py` — действие `Файл → Эталон графика MVKView · Power/Y x32dbg…`, две дополнительные кнопки в инженерной вкладке «Исследование»: открыть и вернуться к архивному спектру. Эталон отображается в **существующем Qt `spec_plot`**, а не в другом временном/веб-приложении. Отключены оригинально звучащие Copy/Save и сравнение с Clipboard, чтобы пользователь не принял график-эталон за вычисленный приборный DSP. Внутренняя `self.session` и исходный BIN архив не заменяются. Локально подготовленный reference можно показать **даже без открытого BIN/ZIP**; после закрытия вернуться на исходный пустой экран или, если архив был открыт, восстановить его обычный FFT.
3. Графический тракт: все N/2 original Float32 доступны source-derived `cursor_from_spectrum` без повторного FFT; на видимый график помещается строго `TRUNC((N/2)/1.28)` бинов, правая ось `DataSize*Fs/N`, чёрный след на белом фоне, пользовательский XOR cursor overlay candidate. Для N262144/Fs65536: **131072 Y в памяти / 102400 отображаемых FFT-бинов / ось 25600 Гц, последний отсчёт 25599.75 Гц**. Tag0 Y default 0…−150dB. Для режимов с исходным Single FRange vertical source-derived scroll model получает именно **слово из оригинального манифеста**, не guessed local BIN FRange; x87/Canvas runtime parity остаётся непроверенной.
4. `tests/test_stage111z31a_x32dbg_visual_reference.py` — синтетические 4 режима, размер/контрольные суммы/отказ на 1 ULP, валидация метаданных/путей/случая бин102400.
5. `tests/test_stage111z31a_qt_original_reference.py` — Windows offscreen тесты импортирования исходного synthetic Y в тот же `spec_plot`, курсора с original source, кнопок Copy/Save, отката на прежний FFT и **самостоятельного просмотра без архива** с восстановлением пустой страницы.

## Действия оператора

1. Установить только **проверенную после Stage31A Windows EXE сборку** из исследовательской ветки, не старую Qt/веб-программу; проверить Green CI перед использованием.
2. Поместить JSON `MVK_TAG0_x32dbg_reference.json` из локального ZIP к ранее сохранённым оригинальным Power/Y Tag0 в одной Windows папке.
3. Открыть в новой Qt `Файл → Эталон графика MVKView · Power/Y x32dbg…` и выбрать JSON, даже когда обычный архив не открыт.
4. Сверить исходный полный Tag0 Y, `25600 Гц`, `150 дБ`, перепад по оси, курсор в районе 3800 Гц/−55.32 дБ. Это **не** пиксельная сертификация; координаты подписей/размеры окна/шрифты ещё могут различаться.
5. Получить ОДИН скриншот нового Qt 1920×1080 при той же шкале, что прежний оригинал Stage111Z14; отдельно фиксировать actual Qt viewport rectangle, курсор, DPI, scaling и sample origin. Новый оригинальный x32dbg FFT/Power/Y/summary снимать НЕ требуется.
6. При открытом архиве нажать «Вернуться к архивному спектру», чтобы восстановить вычисленный спектр. Без архива — возврат к пустому начальному экрану.

## Граница доказательств

- **Подтверждено:** все четыре оригинальных операторами предоставленных численных Y на N262144/Fs65536/FRange43FF4853 совпали с existing source math 131072/131072 (Stage30C). Новый проверенный на synthetic mode loader готовит единый фиксированный источник Y для UI-сравнения.
- **НЕ подтверждено:** реальное исполнение оператора нового UI с оригинальным JSON+BIN на пользовательской Windows, равенство DPI, Qt ↔ TPaintBox PixelRect, подписи и grid, полная эквивалентность GDI XOR в native Canvas, same-thread EIP/EBX/EBP для прежних V6 capture logs, другой N/канал/FRange, идентичность архивных временных окон. Не подменять это проходом синтетических тестов.
- **Не делали:** не меняли вычислительное ядро, оригинальные захваты, Native Go R6.1, физический прибор, firmware RE, stable main и старый Web. Никакие приватные BIN, PCAPNG, TSXML, оригинальный screenshot или EXE не публиковались в GitHub.
