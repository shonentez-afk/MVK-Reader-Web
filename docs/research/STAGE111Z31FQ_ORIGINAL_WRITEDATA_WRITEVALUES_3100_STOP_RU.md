# Stage111Z31FQ — исходные WriteData/WriteValues после «Измерить»

Дата: 2026-11-18. Ветка `research/stage111-mvkview-desktop-20261029`. Это **реальная кодовая реализация с синтетическими тестами**, не заявление о проверенном 1:1 физическом приборе.

## Три совместно проверенных оригинальных источника (приватные, не публиковать)

- `/mnt/data/mvkview.idp` — SHA256 `77e59f98febdd7df94e71cb538a2df69ea4de4624f15b088a81c86e61bb5a438`, IDR v3;
- `/mnt/data/Projects.7z` — извлечённые локально `_Unit114.pas`, `_Unit115.pas`, `_Unit125.pas`, `_Unit128.pas`, `mvkform.dfm`: 5/5 совпадений размер+SHA с SQLite `source_files`; весь набор **не выгружен** в GitHub;
- `/mnt/data/mvk_idr(1).sqlite` — `PRAGMA quick_check=ok`, индекс процедур, событий и вызовов сверялся с этими Pascal/DFM.

Прямая исходная последовательность:
- `_Unit128:0084E914` / `0084E988`: кнопки записи копируют 10 флагов каналов, 43 флага спектральных составляющих и 73 флага значений в рабочий поток `TMVKThread`;
- `_Unit125:00809414..008099CF`: `WriteDataStage=2` без записи → `0` открыто → `1` поступают кадры → `2` закрыто; `WriteValuesStage=2` без записи → `1` открыт CSV → `2` закрыт. Старт и остановка зависят от штатных флагов записи, независимо от команды SetRate;
- `_Unit125:008085A5..008085BD`: исходный `WriteValues` вызывается при настоящем PARAM-дескрипторе **с адресом начала 0x3100**, когда `ValuesFile` уже открыт. AUX4700 — отдельная ветка DSP-данных, а не сигнал создания строки;
- `_Unit125:008066F0..00806915`: оригинал формирует строку времени `hh:nn:ss.zzz` и выбранные поля через `TMvkCellList.GetValueText`, разделитель `|`; `00806334` создаёт исходные заголовки. Пока нет байтового доказательства всего оригинального `GetValueText` для одного и того же сеанса — **не называть восстановленный локальный CSV исходным Delphi CSV**;
- `_Unit125:008089A8` завершает thread с вызовом `00809414(...,True)`, закрывая ещё открытые писатели даже без второго нажатия на кнопку.

## Изменения production

1. **SHA-bound оригинальные VALUES события:** новый `mvk_compatible/core/original_values_3100_timeline.py` независимо и потоково читает исходный `incoming.raw`, проверяет длину/тип и DWORD-границы кадров, регистровые PARAM-блоки, SHA256 и размер RAW, общее число настоящих `0x3100`, отдельных AUX4700 и фреймов, сохранность хвоста. Отмечает только значения между проверенными операторскими Go-маркерами. Коммит [`7a9c343`](https://github.com/shonentez-afk/MVK-Reader-Web/commit/7a9c34354c08ab9556432c1877a82baa479dc7bb).
2. **Запись при исходных событиях, не при AUX:** `original_live_write_stages.py` при подтверждённом Go frame-mark берёт настоящие `0x3100` и создаёт локальные `VALUES##_SOURCE_3100_EVENTS.csv` с исходными байтами дескриптора, SHA и номером кадра. Дополнительная `VALUES##_NATIVE_VERIFIED_SELECTED.csv` записывает числа из **последнего предшествующего** независимо проверенного AUX-снимка по одному событию `0x3100`, явно помечая это как реконструкцию. Если AUX ещё не пришёл, чисел не выдумывает. Файлы Delphi как побайтно равные **не заявлены**. Для исторических тестов неотмеченного/офлайн режима отдельный AUX-приближённый путь остаётся с явным provenance. [`6dc5085`](https://github.com/shonentez-afk/MVK-Reader-Web/commit/6dc50859258a079220881d9c7d56337a91d24029), [`0bbd632`](https://github.com/shonentez-afk/MVK-Reader-Web/commit/0bbd632b271aec964521b68d86210ae9a4117990).
3. **Переменная длина ADC/TACH:** Core более не требует `256`/`64` samples на каждый frame — это распространённые размеры PCAP, но оригинал и Native Go получают корректные переменные размеры, включая пустые кадры. Проверяется общая физическая граница `0x20000`, отсутствие отрицательных счётчиков и длина каждого читаемого frame.
4. **Штатное завершение открытых файлов:** Go `frame_marks.go` в `Finalize(STOPPED_BY_USER/DURATION_REACHED/SIZE_LIMIT_REACHED)` отдельно фиксирует истинные окончательные счётчики открытых WriteData/WriteValues. `AutoClosed` **не выдаётся за операторскую команду**, не создаёт фиктивный network-frame, и SHA защищает весь audit. Аномальный обрыв, некорректный поток и смешанные сокеты не получают ложного clean close. [`ed66986`](https://github.com/shonentez-afk/MVK-Reader-Web/commit/ed66986d871a81f586a179231b54f0f79710f50f).
5. **Проверка финальной границы:** Python `source_frame_mark_protocol.py` разрешает использовать `AutoClosed` только после независимой проверки SHA аудита, run ID, конечного `Go summary.json` (включая end reason/time, frames, AUX, 10 counters, 0x3100) и исходных 10/43/73 масок. Иначе не сохраняет каталог результата. [`5499093`](https://github.com/shonentez-afk/MVK-Reader-Web/commit/549909314c8da960d70b7697127a4b79b6df65c0).
6. **Qt + Core одновременно:** итоговый локальный отчёт и UI статус указывают подлинное число `0x3100`-событий и число штатно закрытых writer-сессий, при этом явно говорят, что результат — **не оригинальный Delphi BIN/CSV**. [`d08e7d0`](https://github.com/shonentez-afk/MVK-Reader-Web/commit/d08e7d02f9c646bd21bdb6b481e17ef6653ff7e8), [`05e1285`](https://github.com/shonentez-afk/MVK-Reader-Web/commit/05e12850e7cba7ba6b13d52e92c7c7488b53c197).

**CI:** проверять точный последний кодовый SHA, не интерпретировать отменённые из-за новых коммитов запуски как PASS. Первое отклонение FQ было ошибкой тестового мутирования (`X→X`) и исправлено; второе было использованием неверного ключа `requested_utc` вместо `operator_requested_utc` в тестовой фикстуре и исправлено. Физическая приёмка 1:1 отсутствует.

## Действительно открытые оставшиеся вопросы

- Оригинальный побайтный формат `TMvkCellList.GetValueText`, отдельные файлы и точные Delphi `WriteData` BIN/TSXML/спектр/тахо; нужно сверить на одном реальном сеансе.
- Полная запись с многочастотным SetRate, раздельными RAW TCP-сокетами и неполным/ошибочным финалом. Эти случаи нельзя тихо конкатенировать в один BIN.
- Завершение принимаемого оригинального кода (исключения, UI и DSP) без утверждения аппаратного 1:1 по одним синтетическим тестам.
- Приватные оригиналы/EXE/операторские PCAP/RAW/SQLite/IDP/PAS не публиковались; опасные аппаратные Flash/IP/Reboot автоматически не передаются.
