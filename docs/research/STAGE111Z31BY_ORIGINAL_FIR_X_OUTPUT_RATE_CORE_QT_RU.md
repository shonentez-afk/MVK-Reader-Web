## Доказанные правила по предоставленным оператором закрытым исходникам

Из локальных приватных \`Projects.7z/_Unit115.pas\` и \`_Unit128.pas\`:
- \`_Unit128:00847F0D..00847F2F\` — число **сырых** отсчётов GetSignal = целочисленное \`FSampleRate * H_ms // 1000\`, где H — один из 14 оригинальных пунктов PageAdc.
- \`_Unit115:007D0C8D..007D0C9A\` — при \`EnvelopeCode>0\` исходная \`GetAdjustedEnvelopeLength\` расширяет запрашиваемое окно до реальной FIR-истории; \`007D0D12..007D0D55\` устанавливает настоящие \`OutputLength/OutputSampleRate\` после фильтрации; \`007D0D86..007D0D9D\` заполняет результирующий \`GetSignal\` **в обратном порядке**.
- \`_Unit128:00848033..00848079\` — XScale рассчитывается по **выходной** частоте, т.е. \`Single(1000/OutputSampleRate)\` при H < 10000 мс либо \`Single(1/OutputSampleRate)\` при H >= 10000 мс. Использование исходного Fs вместо выходного было ошибкой.
- \`_Unit128:0084B2F8..0084B409\` — и при FIR исходный PageAdc оставляет \`ScrLeft=H\`, \`ScrWidth=-H\` и единицы «мс/с». Расширенная история может дать больше выходных точек, чем помещается на выбранном H: **клиппинг**, не изменение выбранной шкалы и не дорисовка нулями.
- \`_Unit115:007CA75C\`, \`_Unit128:0084B4AC\` — курсор принимает целый X и выбирает полный \`TQGRSeries\`. Действительное округление Win32 X→индекс, режим precise/averaging и исходный \`CursorString\` всё ещё требуют независимой runtime-аттестации.

## Реализовано совместно

- В автономном \`core/original_adc_source_axes.py\` добавлены \`source_adc_envelope_axes\` и \`source_adc_envelope_cursor\`: входная реальная история проверяется по оригинальному \`envelope_plan\`, SHA исходного Float32 окна, сохранённой текущей BIN/ADC, исходному \`OutputSampleRate\`, полному SHA выходного буфера, \`EnvelopeCode\` и диапазону H. Вход и рассчитанный сигнал не мутируются; возвращаются метаданные source-scale с \`original_win32_gdi_pixel_parity_verified=False\` и \`historical_fir_latency_to_archive_time_verified=False\`.
- В действующем Qt \`desktop/main_window.py\`: для исходного режима и выбранного H теперь **тот же** инвертированный X и ms/s применяется к GetSignal **с FIR**. ViewBox ограничен реальным исходным \`ScrLeft/ScrWidth\`, кривая рисуется из неизменённого прореженного LOD, а курсор из **полного** Float32 после FIR. Контроль берёт источник из того же Core и проверяет индекс и SHA, не подставляя физическую абсолютную временную метку, пока не известна FIR-фазовая задержка.
- Восстановен двусторонний жизненный цикл исходного \`mEnvelopeType1Click\`: изменение кода в PageAdc обновляет соответствующий \`Tag\` PageSpectrum и активный спектральный фильтр независимо от видимости; изменение кода в PageSpectrum немедленно пересчитывает скрытый PageAdc и при выбранной огибающей также спектр. Исходный Tag0 выключает фильтры, не оставляя старые кривые и численные показатели.
- Два исследовательских режима остаются отдельно и не объявляются source parity. Для настоящего коэффициентного профиля нужен локально предоставленный пользователем IDP с проверенным SHA; в CI используются только синтетические коэффициенты.
