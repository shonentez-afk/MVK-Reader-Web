## НОВЫЕ source-derived выводы (без копирования проприетарного текста)

1. Оригинал конструирует **32 позиции меню фильтра, коды 0–31**, при запуске, а не хранит этот список в DFM: `_Unit128:0084587D..0084594B`. `mvkform.dfm`: единый `popEnvelopeType` подключён и к `bAdcEnvelopeType`, и к `bSpecEnvelopeType`. Код 0 — без фильтра.
2. `_Unit128:0084B274..0084B2C7` при одном выборе **присваивает один и тот же Tag обоим кнопкам** временного сигнала и спектра; не хранит два независимых EnvelopeCode. Наши два Qt combo ранее могли разойтись. Это новый предметный баг интерфейса/расчётного режима, а не повторное изучение FIR.
3. `_Unit128:0084B2C8..0084B2F5` после выбора фильтра вызывает `00846AB4`, где сбрасывается длина **обеих** графических серий, после чего `00847248` обновляет **активную** страницу. Это предотвращает ошибочное представление старой огибающей как результата нового кода или режима «без фильтра».
4. `_Unit128:00848148..00848210` перед `GetSpectrum` дополнительно проверяет, что `Storage.FSampleRate` выбранного канала равен `SelectedSampleRate`; при несовпадении очищает спектральную серию и подпись. Это отдельное будущее условие для неоднородных многоканальных записей. Текущий `DirectBinSession` уже отклоняет смешанные sample-rate группы, поэтому новым универсальным runtime доказательством это **не** является.
5. `_Unit115:007D13D4..007D150F` подтверждает ранние проверки наличия данных, предельного N и вызов `GetAdjustedEnvelopeLength` для кода больше 0; эти правила уже исследованы ранее. Не повторять FFT/x87/Power/Y.

## Изменение нашей реализации

- `main_window.py`: явные пользовательские изменения кода фильтра зеркалируются между панелями, без циклических Qt сигналов. Режим оригинального x32dbg Power/Y остаётся неизменным.
- После смены фильтра неактивная вкладка отмечается устаревшей и перерасчитывается при открытии; график не остаётся результатом старого EnvelopeCode.
- При выборе кода 0 с активной огибающей кнопка переключается в «Без фильтра» **с реальным пересчётом обычного FFT**. При недостатке исходной истории FIR кнопка также выключается, обычный FFT восстанавливается; при невозможности построить сигнал/спектр прежняя кривая не выдаётся за актуальную.
- **Оставлено намеренно:** отдельный checkbox для пользовательского локального IDP — исследовательская защитная граница, её **нет** в оригинальном DFM. Ранее существовавший код 20 при загрузке IDP — Qt исследовательский default, а **не** утверждение об оригинальном стартовом Tag; его установка не запускает автоматически фильтрацию сигнала. Полная original GUI parity не заявлена.
- Численные FFT, исходный FIR, FRange, Native R6.1, main/Web, оригинальные Golden 4×131072 и приватные измерения не изменены.
