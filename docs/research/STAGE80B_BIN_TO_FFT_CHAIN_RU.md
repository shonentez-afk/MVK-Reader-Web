# Stage 80b — BIN -> storage -> signal/spectrum (offline IDR)

Дата: 2026-10-28. Источники: оригинальные `_Unit128.pas` и `_Unit115.pas` из локального `Projects.7z`. Без подключения к оборудованию.

## Установлено по адресам
- `_Unit128.pas:0x0084F947–0x0084F951`: `ViewedFile:TFileStream` позиционируется через `TStream.Seek` в требуемое смещение.
- `0x0084F954–0x0084F96E`: `TMvkChannelStorage.InvalidateData` и `AllocBufferChunk`; выходной указатель и размер буфера задают чтение.
- `0x0084F974–0x0084F98F`: `THandleStream.Read` -> `TMvkChannelStorage.ProcessBufferChunk(size, ViewedFileIsNormalized)`. Цикл повторяется, пока остаются данные. Читается **архив**, не сетевой прибор.
- `_Unit115.pas:0x007D2398` — `ProcessBufferChunk` обновляет `FRxPos`. При float-типе и установленном `ApplyRange` умножает буфер на `FRange` (`0x007D23D1–0x007D23E1`); при отсутствии флага такого умножения нет. Для float число отсчётов вычисляется из числа байт /4. **Внимание к потенциальному повторному умножению при повторной загрузке.**
- `_Unit128.pas:0x00847FCF` — график времени вызывает `TMvkChannelStorage.GetSignal`. `0x00848200` — график спектра вызывает `TMvkChannelStorage.GetSpectrum`. Вторая пара вызовов в `0x0084FAA7/0x0084FB03` также найдена. Точная причинно-временная последовательность UI обновления требует отдельной трассировки.
- `_Unit115.pas:0x007D13D4` — вход `GetSpectrum`. Проверяется `FFT length <= 0x40000` (262144), иначе строка `Invalid FFT length`; далее `CheckDataAvailability`, выделяется буфер по длине *4, вызываются `sub_007D2228` и `sub_007D2344`, затем опциональные функции огибающей `0x007D1C48` и `0x007D1E70`.

## Вывод
**Главный статический мост BIN -> хранилище -> временной сигнал/спектр найден.** Это НЕ эквивалентно численной верификации: открыты нормировка амплитуд, оконная функция, частотная шкала и сравнение с оригинальной MVKView по одному и тому же BIN. Также не установлено, как именно формируется `ViewedFileIsNormalized` и соответствует ли флаг `ApplyRange` ожидаемой физической размерности для всех режимов.
