## 2. Что именно найдено в оригинальной Delphi

Источник: приватные локальные восстановленные `_Unit128.pas` (`Projects.7z`) и `_Unit115.pas` из оригинала, сами файлы ни в GitHub, ни в CircleCI НЕ передавать.

Важное уточнение: ранее обнаруженный `sub_0084AB98` формирует **шкалы временного сигнала (ADC)**. Спектральный `GraphDefaultVScale` вычисляется в **`sub_0084B4E8`**:

- `_Unit128:0084B5D3–0084B631`: выбранный `bSpecType.Tag` определяет исходный множитель перед округлением: 0=дБ → ×1; 1=ускорение → ×1; 2=скорость → ×10; 3=перемещение → ×100. Исходное значение берётся не из графика, а из **`TMvkChannelStorage.FRange` выбранного канала**, offset `+0x04`, после умножения сохраняется в Single.
- `_Unit115:007D0A61`: конструктор нового канала **по умолчанию** записывает `FRange=1.0f`, но фактический FRange работающей MVKView мог измениться и **не подтверждён** по имеющемуся офлайн-архиву.
- `_Unit128:0084B631–0084B882`: оригинал вычисляет `log10(x)`, целочисленный `TRUNC` к нулю, остаток с явным `FSTP Single`, затем сравнивает с `log10(2)` и `log10(5)`. Отдельные ветви для отрицательного/нулевого и положительного остатка формируют удобные десятичные ступени **1–2–5–10 × 10^k**; окончательный результат снова записывается в Single.
- `_Unit128:0084B890–0084B95D`: исходное меню вертикальных физических единиц показывает значения `GraphDefaultVScale / divisor` (делители из уже восстановленной таблицы `008D3468`), а дБ — отдельные фиксированные ступени.
- Реальные `00447DB8`, `00447DF0`, `00447EF8` связаны с десятичным логарифмом и степенью; **точное x87 округление этих вспомогательных реализаций, пограничные равенства и фактические параметры канала ещё не измерены**. Совпадение структуры исходника не означает численный битовый паритет.

## 3. Что реализовано

1. `mvk_compatible/core/spectrum_graph_default_vscale_idr_candidate.py`: независимый арифметический **IDR-кандидат** по исходным инструкциям. Содержит явное преобразование в IEEE float32/Single после требуемых операций, log10/TRUNC к нулю, два компаратора log10(2)/log10(5), десятичные ступени, независимое идеальное Decimal-округление для диагностики, отказы при неверных/переполненных значениях. Все внешние значения передаются явно.
2. `desktop/main_window.py`: на вкладке «Спектр» показана отдельная диагностическая строка `GraphDefaultVScale` рядом с **вручную заданным** FRange. Для выбранного оригинального вертикального меню рассчитаны две разные модели: исходная `ScrBottom/ScrHeight` **при гипотезе FRange** и существующая **видимая Qt-ось Y, построенная по локальному спектру**. Они не подменяют друг друга, в словаре указано `local_manual_frange_is_original_verified=False`, `original_delphi_y_canvas_parity_verified=False`. Прямого принудительного включения неаттестованного оригинального Y в Qt нет.
3. `mvk_compatible/graph_vscale_reference_compare.py`: приватный **офлайн-компаратор** пользовательских пар `mode/FRange/исходный GraphDefaultVScale`. Выводит только число совпадений, агрегированные относительные ошибки и provenance флаги; **не выводит исходные значения, локальные пути, скриншоты и содержимое приватного JSON**, не обращается к сети. Результат одной сверки НЕ может утверждать `original_delphi_x87_parity_verified`.
4. Новые synthetic unit tests и отдельный Windows offscreen Qt-тест проверяют строку, source mode multipliers, `ScrHeight` при делителе 1000, приватный компаратор и ложную аттестацию.

## 4. Границы точности и важный выявленный случай

Локальная реализация выдерживает 37 синтетических тестов (28 для модели + 9 для компаратора), включая ошибки входов, переполнение Single, негативные/положительные порядки десятичного логарифма и непубликацию оригинальных чисел в отчёте. Оригинального операционного golden trace нет. Обращать внимание на границы **2 и 5**: из-за хранения дробной части log10 в `Single` наш кандидат может дать, например, **5 вместо 2** или **10 вместо 5**, тогда как независимое идеальное округление даёт 2 и 5. Это **не доказательство**, что оригинальная x87 MVKView так же округляет: требуется захват точных чисел и исходных helper semantics. `original_math_helpers_x87_rounding_verified=False` намеренно сохраняется.

Пример (полностью **синтетический**, НЕ исходное измерение) приватного JSON для оператора:

```json
[
  {"mode": 1, "f_range": 1.1, "original_graph_default_vscale": 2.0},
  {"mode": 2, "f_range": 0.31, "original_graph_default_vscale": 5.0}
]
```

Запуск локально, без сети:

```powershell
python -m mvk_compatible.graph_vscale_reference_compare "C:\Private\graph_vscale_reference.json" --tolerance-relative 0.00001
```

Файл должен оставаться на локальной рабочей машине оператора. Никакого оригинального DFM/IDP/PAS/BIN/коэффициентов в GitHub и CI.
