# Stage 83 — независимый сравнитель архивных спектров (2026-10-28)

## Реально выполнено
Stage82 впервые воспроизведён в текущей среде: синтетический BIN+TSXML (Single, 8192 Гц, N=8192, тон в бине 37), проверены чтение, отсутствие повторного gain, пик, нулевой сигнал и экспериментальная ветка gain. **PASS**. Настоящие промышленные измерения и экспорт спектра MVKView не предоставлены для независимого сравнения.

Созданы `tools/research/stage83_compare_spectra.py` и `tools/research/stage83_compare_selftest.py`. Сравнитель принимает два CSV (частота, линейное значение или dB), строго проверяет сетки без интерполяции и подгонки, вычисляет ошибку по точкам, максимум относительной ошибки (выше порога), положения/значения пиков. Требует локальный JSON provenance manifest: `channel`, `source`, `time_range`, `n_fft`, `window`, `units`, `spectrum_mode`, `same_measurement_confirmed: true`. Без подтверждения общего измерения сравнение отклоняется.

Синтетические проверки метода сравнения (идентичный спектр, искажение одного бина, несовместимая сетка) пройдены локально. Это **не означает**, что восстановленный FFT численно совпадает с оригинальной MVKView.

## Запуск (офлайн)
`python tools/research/stage82_archive_fft_selftest.py`

`python tools/research/stage83_compare_selftest.py`

`python tools/research/stage83_compare_spectra.py --candidate candidate.csv --reference original.csv --reference-column amplitude --manifest provenance.json --out metrics.json`

Для сравнения dB используйте `--candidate-column db_candidate` и действительную колонку оригинального спектра. Названия и единицы должны согласовываться; инструмент не выбирает их автоматически.

## Ограничения
В окружении отсутствуют синхронные настоящие `BIN+TSXML+экспорт спектра` одного измерения и оригинальный `mvkview.exe` с телом log-helper `0x00447DB8`. Без них нельзя утверждать восстановление десятичного логарифма, амплитуд и всего спектрального тракта. NumPy не гарантирует побитового совпадения с Delphi FFT.
