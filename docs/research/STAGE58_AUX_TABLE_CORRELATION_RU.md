# Stage 58 — сопоставление AUX4700 и TABLE (2026-10-28)

Проверка выполнена офлайн по `83 первый(1).pcapng`, `84 отдельно(1).pcapng` и 21 CSV TABLE (10 для .83 и 11 для .84), используя локальный `cap_parse.py`. 30 расчётных блоков AUX4700 в каждом захвате. Оригинальные измерения не публикуются.

## Привязка полей
Структура AUX4700: 8 записей ×584 байта, в записи 144 float32 + финальный uint32 status. Индекс слова 0 соответствует напряжению на датчике. Индексы 1–43 — дольоктавным ВУ; 47 — ВУ X..25 кГц; 48/49/50 — ВУ/ВС/ВП 10..3000 Гц; 51/52/53 — 10..2000 Гц; 54/55/56 — 10..1000 Гц. Привязка согласуется с существующим парсером `cap_parse.py` и TABLE; полную атрибуцию всех 144 полей ещё не завершили.

## Сравнение
Для каждого TABLE-значения выбрано ближайшее по абсолютной величине из 30 AUX значений того же канала/поля, далее медиана таких отклонений. **Это НЕ синхронизация и метод систематически оптимистичен.**

Для .83 ADC4: медианная абсолютная разница TABLE vs nearest AUX: напряжение 0.00876 В; ВУ X..25 кГц 0.00751 м/с²; ВУ 10..3000 Гц 0.01274 м/с²; ВС 10..3000 Гц 0.00242 мм/с; ВП 10..3000 Гц 0.00645 мкм. Данные согласуются.

Для .84 ADC1: ВУ 10..3000 0.13403 м/с²; ВС 10..3000 0.97519 мм/с; ВП 10..3000 7.74124 мкм. Для .84 ADC6: ВС 10..3000 1.12676 мм/с и ВП 12.53697 мкм. Совпадение по режимам и единицам нельзя считать доказанным одними числами; вероятен разрыв между временем PCAPNG и TABLE или иной измерительный режим. Поле №47 равно 0 и в .84 AUX, и в TABLE, но это не говорит о нулевой вибрации.

## Неустановленное
Семантика 128-байтных сообщений ID 0x2130–0x2F30 и статусных слов 13/15 не доказана. Для привязки КП нужны контрольные параметры из DefaultConfig и синхронная таблица/сессия. Нельзя превращать найденные значения в готовые названия дефектов.
