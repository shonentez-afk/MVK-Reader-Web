# Mode1: ремонт офлайн-просмотра после сравнения с MVKView 1.0.47

- Только для согласованного именованного ADC BIN/TSXML Mode1 с полными полями и положительным FRange: выбирается исходный домен чтения FFT; сохраняются исходные байты и запрет выдавать аппаратную калибровку за проверенную. Аналогичная нормализация на входе FIR временного сигнала и обратный масштаб по исходному контракту. TACH, неполные пары и Native ZIP не переключаются в этот режим.
- Ползунок штатного Mode1 задаёт правую границу разных окон временного сигнала и спектра. Начальный выбор: последняя отметка, длительность сигнала 500 мс, самое подробное доступное разрешение FFT (0,25 Гц/линию на эталоне). Последнее полное FFT можно выбрать явно. В начале записи нулевая предыстория только отображается; синтетические отсчёты не попадают в курсорный массив, summary и CSV.
- Для Mode1 ширина оси X и край фактически рассчитанной линии независимы. Тестовый переход FIR 2 окт / 400 Гц → без фильтра больше не оставляет ось на 800 Гц. Нет вымышленных спектральных бинов за пределами линии.
- Локальный совместимый SPEC-FREQ с файлом проверенного происхождения учитывает числовую локаль, не смешивает разделители и не дописывает в чужой CSV. Диалог сохранения повторно проверяет исходный сеанс. Маркировка/подтверждение одиночного некалиброванного BIN сохранены. Заголовки и кодировка Delphi на русской Windows ещё не аттестованы; совместимый экспорт использует свой UTF-8 заголовок.
- На приватном эталоне при открытии штатным Qt путём подтверждено по 131 072/131 072 значений в каждом из четырёх режимов GetSpectrum; контрольный FIR 400 Гц совпал по 4096/4096. Опоры: восстановленные _Unit128 / DFM, IDP, SQLite и Atlas v32; рабочие снимки памяти и оригинальные входы не входят в Git.
- Прибор, LIVE-согласие, основная ветка и формат сырых записей не менялись. Сквозное сравнение с оригиналом под штатной Windows на одном PCAPNG, образцы TACH/0x3100 и живой Stop остаются отдельной приёмкой.

Локальная регрессия: 139 PASS, включая исходный маршрут Qt и синтетический тест параметров открытия, границ окон, оси после FIR и локали CSV.
