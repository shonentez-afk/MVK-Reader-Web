# Stage 41 — локальный спектральный тракт MVKView

Дата: 2026-10-28. База: v0.3.40 **не изменена**.

## Подтверждено по экспорту IDR (Projects.7z)

- `_Unit125.pas`: `TMVKThread.Execute` читает данные через `TIdIOHandler.ReadStream` (0x00808229), сверяет частоту кадра с `MvkSampleRate` (0x00808232–0x0080823B), проверяет `FreezeUpdate` (0x00808244–0x0080824B), вызывает `TMvkChannelStorage.ProcessBufferChunk` (0x0080828C). Для тахоканалов 8–9 выполняется дополнительная процедура 0x00806030.
- `_Unit115.pas`: `ProcessBufferChunk` (0x007D2398) при определённом типе данных и `ApplyRange` умножает `float32` отсчёты на `FRange` (0x007D23D1–0x007D23E1), после чего увеличивает 64-битную позицию `FRxPos`. Масштабирование не следует считать безусловным для всех режимов.
- `_Unit115.pas`: `GetSpectrum` (0x007D13D4) проверяет наличие данных, создаёт рабочий буфер, вызывает внутренние подпрограммы спектральной обработки. Проверка `cmp eax,40000` (0x007D1404) ограничивает длину FFT **262144 отсчётами**.
- `_Unit115.pas`: инициализация 0x008C1064–0x008C10C9 строит таблицу из 262144 значений с косинусом и корнем. Назначение окна/нормировка ещё не доказаны.
- `_Unit128.pas`: `TBackgroundProcessThread.Execute` (0x0084FA6C) вызывает `GetSignal` при задаче 1 (0x0084FAA7) и `GetSpectrum` при задаче 2 (0x0084FB03); готовые данные передаются в UI через `TThread.Synchronize`. Прямой вызов `GetSpectrum` также есть в коде формы (0x00848200).

## Исправление прежнего вывода

Прибор передаёт собственные расчётные показатели, **но MVKView выполняет и локальную спектральную обработку сырых отсчётов**. Нельзя утверждать, что весь DSP исключительно в приборе. Нельзя считать прежний режим FFT 2^20 длиной FFT оригинальной MVKView: локальный `GetSpectrum` ограничивает N значением 2^18.

## Следующие задачи

1. Проследить `GetSpectrum` до `DSXFastFourier.fft`, установить оконную функцию, нормирование и преобразование ВУ/ВС/ВП.
2. Отделить приборные дольоктавные показатели от локального графика FFT.
3. Сверить масштабирование `FRange` с BIN и PCAPNG.
4. Подготовить автономные спектральные регрессионные тесты, не затрагивая стабильную версию.
