## Подтверждено непосредственно по _Unit125.pas
Процедура `sub_00806A8C(TMVKThread, channel_index)` начинает построение TSXML **только если соответствующий `ChannelFile` не null** (`0x00806AB1–0x00806ABA`). Имя образуется из имени существующего канального файла с добавлением суффикса `.tsxml` (`0x00806AC0–0x00806AC9`). Создание текста через `@RewritText` (`0x00806AFF`), исключение создания перехватывается и выход происходит без записи (`0x00806B13–0x00806B1D`). Текст начинается с `<?xml version="1.0" encoding="windows-1251"?>`, затем `<MainRoot>`.

Найдены статические поля `DateTime` (формат `mm/dd/yyyy hh:nn:ss AM/PM`), `Culture=en-US`, `From Units="ms"=0`, `To Units="ms"`, `ChannelsQuantity=1`, `FrequencyPerChannel`, `DataFileName`, блок `Channels/Channel Index="0"`, `ChannelName`, `ChannelNumber`, `ChannelFrequency`, `Units`, `RealDataType`, `DataLength`, `DataOffset=0`, `InternalChannelGain`; закрытие через `@Close` (`0x00807111`). Для канала с индексом >=8 найден тип `Units=Count`, `RealDataType=Byte`, иначе `RealDataType=Single` (`0x00806F4E–0x00806FCE`). В ветвлении `To` для индексных групп <8 и >=8 используются разные выражения длины: обе включают отношение размера файла к параметру `[TMVKThread+0x400D0]` и множитель 1000, но ветвь АЦП дополнительно делит размер на 4. **Точная интерпретация частоты требует трассировки происхождения этого параметра.**

Вызов генератора найден по `0x00809719`, внутри ветви управления записью BIN. В `_Unit128.pas` имеются обращения к `.tsxml` `0x0084605C` и `0x00846084`: путь чтения/импорта пока не прослежен полностью.

## Проверки и ограничения
Реально просмотрены 23 структурных маркера внутри функции, все обнаружены; отдельно подтверждено место вызова. Добавлен `tools/research/stage79_verify_tsxml_idr.py` для воспроизводимого статического контроля. **Это проверка наличия адресов и строк, не гарантия корректности всего алгоритма.** Не проверены реальная TSXML на точное совпадение, ошибки в середине записи, авто-чтение, источник `InternalChannelGain`, коэффициенты сохранения и связь BIN/TSXML в архиве. Не приписывать обратному чтению подтверждённый статус. EXE в текущем каталоге не обнаружен, но исходный IDR достаточен для этой статической части.
