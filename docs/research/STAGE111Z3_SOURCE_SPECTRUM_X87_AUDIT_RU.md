# Stage111Z.3 — приватный source-аудит исходного x87 пути спектрального масштаба

**Дата:** 30.10.2026  
**Ветка:** `research/stage111-mvkview-desktop-20261029`  
**Цель:** автономная Windows MVKView Compatible; не Web v0.3.40.

## 1. Исходная проверка без публикации закрытого материала

Локально проверена оригинальная приватная база `mvkview.idp` (IDR v3) в условиях offline Linux. Сохранено общее доказательство Stage111Y: сравнение оригинальных EXE↔IDP по .text/.itext/.data уже выполнялось на предыдущем этапе; в этом отчёте EXE заново не извлекался и не сравнивался.

Исходный сегмент `.text` по VA 0084B5D3..0084B882 (687 B) и три helper-диапазона:
- `00447DB8–00447DC7`: логарифм Single `FLDLG2; FLD Single; FYL2X`;
- `00447DF0–00447E72`: Power Extended (целочисленная/нецелочисленная ветви);
- `00447EF8–00447F7A`: Power Single (целочисленная/нецелочисленная ветви)

сверены по приватно вычисленным SHA256 *отдельных окон машинного кода*. В GitHub сохранены только хеши и допустимые производные факты, не исходные байты, EXE, IDP или Delphi PAS/DFM.

## 2. Подтверждённая структура

| Helper | VA | Code-aligned E8 rel32 candidates within Spectrum handler |
|---|---|---:|
| `log10 Single` | 00447DB8 | **16** |
| `TRUNC` | 00407C74 | **7** |
| `Power Extended` | 00447DF0 | **4** |
| `Power Single` | 00447EF8 | **2** |

*Счётчики*: кандидаты E8 в **точно верифицированном** исходном обработчике, НЕ глобальный граф вызовов всего EXE. Обнаружен сохранённый промежуточный `Single` остаток `log10(x)-TRUNC(log10(x))` и восемь инструкций сохранения `Single [ESI+0x62C]` (два входных умножения и шесть выходных ветвей).

Константы из code `.text`: `0084BBCC` = **10.0 Single**, `0084BBD0` = **100.0 Single**. Исходное `FRange` выбирается через объект выбранного канала. Режимы Tag0/1/2/3 исходно масштабируют его как **×1, ×1, ×10, ×100** соответственно. Это согласуется с пользовательскими offline x32dbg наблюдениями Stage111Z.

Исходная x87 архитектура **не эквивалентна по определению** `math.pow()` и идеальному округлению 1/2/5; между операциями имеются промежуточные записи Single и разные Power helper ветви.

## 3. Новый безопасный воспроизводимый аудитор

- `mvk_compatible/private_spectrum_x87_path_audit.py`: проверяет исходную локальную базу IDP, базовое FPU и четыре code-range SHA, 4 группы E8 calls, исходные Single stores и множители. При ошибке идентичности — fail-closed. На stdout только структурные флаги и агрегаты, без абсолютных путей, оригинальных байтов или измерений. Не запускает EXE и не подключается к прибору.
- `mvk_compatible/tests/test_private_spectrum_x87_path_audit.py`: synthetic-only тесты fingerprint, смещения/счётчики, порча подписи, неполный E8 и отсутствие приватного IDP. Оригинальные данные не попадают в CI.

Локальный независимый read-only скрипт проверил те же 4 оригинальных SHA, количество вызовов, 8 Single stores и множители **PASS** непосредственно на доступном приватном IDP. Новый инструмент дополнительно подтверждает на таком же приватном файле базовые подписи `@FpuInit`/CW, но его запуск именно на оригинале в CI невозможен и не утверждается.

Локальный запуск через Python из корня репозитория:

```powershell
python -m mvk_compatible.private_spectrum_x87_path_audit "C:\\Private\\mvkview.idp"
python -m pytest -q mvk_compatible/tests/test_private_spectrum_x87_path_audit.py
```

## 4. Действительные оригинальные golden-значения

Результаты x32dbg (сообщены пользователем, самостоятельно переснять оригинальный runtime здесь невозможно):

| Spectrum Tag | Before @log10 Float32 bits | After GraphDefaultVScale Float32 bits |
|---:|---|---|
| 0 | `43FF4853` | `447A0000` |
| 1 | `43FF4853` | `447A0000` |
| 2 | `459F8D34` | `461C4000` |
| 3 | `47477081` | `47C35000` |

CW `0x1372` на границах **Tag=0** до/после расчёта, для остальных режимов не зафиксирован отдельно. Нативный GNU x87 source-derived replayer Stage111Z.2 совпал с этими 4 выходами побитово при принудительном CW1372, но это НЕ общий Delphi-bitwise сертификат.

**Остаточная численная неопределённость:** на синтетической границе `FRange=1000.0` native x87 CW1372 и Python-кандидат могут дать разные ступени (2000 / 1000). Исходная Delphi на этой границе не измерена, нельзя автоматически заменять текущую формулу.

## 5. Приёмка и следующий этап

CI проверяет новую исследовательскую ветку на Linux/Windows. Для каждого SHA проверять именно свой статус, не переносить успех старого SHA. Не подключать реальный МВК. В основном Qt-приложении нет подмены осей по ещё не принятому оригинальному x87 кандидату.

**Следующий Stage111Z.4:** построить исходные граничные golden по реальному сохранённому архиву с другим FRange либо расширить локальный offline оригинальный runtime x32dbg, затем продолжить source-vs-runtime FFT/GetSpectrum/FormatFloat/Canvas и подготовить точное визуальное сравнение. `main`, Web v0.3.40, приватные PAS/DFM/IDP/EXE/BIN/PCAPNG не публиковать.
