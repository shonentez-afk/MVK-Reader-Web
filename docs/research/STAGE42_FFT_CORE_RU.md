# Stage 42 — FFT-ядро MVKView
Дата 2026-10-28; анализ только по экспорту IDR, без запуска прибора.

В `_Unit115.pas` найдены:
- `TDSXFastFourier.fft` по `0x007CC3F8`: передаёт константу `0x40C90FDB` в общий алгоритм `0x007CC198`.
- `TDSXFastFourier.ifft` по `0x007CC404`: передаёт `0xC0C90FDB` в тот же алгоритм, затем делит выход на `FNumSamples`.
- `FInBuffer` и `FOutBuffer` — комплексные массивы, каждый `8*N` байт.
- `TMvkChannelStorage.GetSpectrum` по `0x007D13D4`; лимит FFT `N <= 262144` в данной процедуре.

Константа `0x40C90FDB` в float32 примерно равна `2*pi`, а `0xC0C90FDB` — `-2*pi`. Это согласуется с разными направлениями FFT и IFFT. **Пока не доказаны** оконная функция, нормировка амплитудного спектра, вызов ядра из всех ветвей `GetSpectrum`, соответствие отображения режимам ВУ/ВС/ВП.

Локальный пакет `MVKVIEW_STAGE42_FFT_CORE_20261028.zip`: `REPORT_RU.md`, `analyze.py`, `evidence.csv`; поиск 6/6 опор. Коммерческий код и двоичные файлы в публичную ветку не выгружаются.
