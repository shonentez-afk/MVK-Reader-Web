## Проверка обязательных трёх оригинальных источников

Приватные оригиналы анализировались **совместно и только локально**, без публикации их содержимого в репозитории:

- `mvkview.idp`: исходный IDR project v3, полный SHA256 и размер совпали с `mvk_idr(1).sqlite/meta.idp_header`; символы `Tmvkform`, `bTaskConnectClick` и `TMvkChannelStorage` присутствуют.
- `Projects.7z`: локальным `libarchive` прочитаны `_Unit125.pas`, `_Unit128.pas`, `_Unit115.pas`, `mvkform.dfm`; все **4/4** совпали с `sqlite.source_files` по размеру и SHA256.
- `mvk_idr(1).sqlite`: `PRAGMA quick_check = ok`; проверены `events/functions/calls` для `bTaskConnectClick 00848E78`, `sub_00846AD4`, `sub_00847040`, `bFreezeUpdateClick 0084DEA4`, `tmInterfaceUpdateTimer 0084F7C8` и диспетчера `00847248`.

## Доказанная последовательность оригинала

1. `mvkform.dfm` связывает `bTaskConnect.OnClick` с `00848E78`. В `_Unit128.pas` обработчик переводит в `00846AD4`.
2. В `00846AD4:00846B48..00846B61` повторное нажатие при `Mode=2` вызывает `00847040` для сброса. Вход в Mode2 выделяет **8 ADC + 2 TACH**, исходное хранилище по `0x200000` элементов, открывает дополнительные страницы и `pnMeasure` **до** `TMVKThread.Create 00846DCC`.
3. После создания потока выбирается `PageStatus`, активируется `tmInterfaceUpdate`. Исходный `0084F7C8 → 00847248` обновляет активную страницу и затем `pnMeasure`, но не синтезирует новые отсчёты.
4. Для `PageAdc` `00847F0D..00847F2F` читает Tag кнопки **bAdcHScale** из таблицы и вычисляет `Fs * milliseconds // 1000`; `00847FCF` вызывает `TMvkChannelStorage.GetSignal`. `PageSpectrum` `0084819A..00848200` читает Tag **bSpecLines** и вызывает `GetSpectrum`. Это исходные **действия оператора в Mode2**, а не элементы только offline-архива.
5. `bFreezeUpdateClick 0084DEA4` переключает поле `TMVKThread.FreezeUpdate +400CD` и обновляет `pnMeasure`. Ни новые TCP-команды, ни отдельные инженерные панели этим не создаются.

## Исправления кода Go/Core/Qt

- Qt `MainWindow._begin_live_capture` больше **не отключает** `bAdcHScale` и `bAdcEnvelopeType`: ранее источник HScale уже был восстановлен, но живой пользователь не мог вызвать его на отключённой кнопке.
- `bSpecLinesPresenter` продолжает принимать оригинальные меню в реальном Mode2; архивная модель `spec_n` служит источником значения N для текущего обработчика. В операторском меню Mode2 скрыты неоригинальные исследовательские FFT 1024/4096, входившие в прежний офлайн-анализ.
- При входе в Mode2 скрыты `Исследование`-кнопки и открытые dock-inspectors; исходные инструменты остаются доступными. При выходе из Mode2 видимость исследовательских контролов восстанавливается.
- При входе с ранее выбранным неоригинальным исследовательским N выставляется оригинальный N=65536. Проверки достаточности **реально захваченной** истории, SHA-гейты, запрет повторного FRange и масштабов по неподтверждённым отсчётам не ослаблены.
- Go TCP/RAW, командный протокол, аппаратное TX-разрешение, Flash/Write-IP/Reboot **не изменены**.

## Остаётся открытым

- Сравнение с **физическим** МВК01: IP → Measure → входящие PARAM/ADC/TACH/ACK/DENIED → Stop → reconnect.
- Byte-exact поведение оригинального Delphi для всех аппаратных исходящих команд и `WriteData/WriteValues`; source DAC/SetRate командный паритет и безопасное разрешение аппаратных команд.
- Полный `2^21` ring на канал, x87/TQGrapher pixel parity и сверка `GetSignal/GetSpectrum` на одинаковом физическом потоке.
- Все семь страниц и три формы в операционном Live: предметный функциональный прогон кнопок, ошибок и сохранений без подмены исследовательскими элементами.
- `original_delphi_compatibility_verified=false` до реальной аппаратной и численной приёмки.
