## Исправлена содержательная ошибка старого интерфейса

В предыдущей версии CA 31 пункт исходного `popEnvelopeType` выводился как приблизительный исследовательский текст `Огибающая <Tag> · <output Fs>`. Это было неверно по смыслу: в оригинальном MVKView названия — **полосы** третьоктавной, октавной и двухоктавной фильтрации. При просмотре спектра пользователь видел номер кода вместо полосы.

В **пользовательском локальном** `mvkview.idp` (проверен оригинальный отпечаток исходного профиля) восстановлена таблица указателей 32 UnicodeString `0x008CD900`, используемая `_Unit128.pas:0084587D..0084594B`. Tag0 равен null и вычисляется через `TLanguage.localize('xNoEnvelope')`; его конкретная русская локализация в рабочей оригинальной программе **не доказана** — используется честный fallback «Без фильтра». **Tag1..31 извлечены строго как исходные статические строки UTF-16, без переименования.**

Таблица содержит Tag1 `1/3окт 25 кГц`, Tag2 `1/3окт 20 кГц`, … Tag19 `1/3окт 400 Гц`; Tag20 `1окт 16 кГц`, … Tag25 `1окт 500 Гц`; Tag26 `2окт 13 кГц`, … Tag31 `2окт 400 Гц`. Полные точные 31 значения сохранены **как короткие UI-подписи** в `core/original_envelope_shared_menu.py`. Никакие исходные BIN/PAS/DFM/IDP байты, внутренние FIR-банки и исходный executable не размещены на GitHub.

Критическое различие: **Tag20 подписан «1окт 16 кГц», но целевая выходная частота его FIR — 65536 Гц.** И это не одно и то же; источниковая таблица `ENVELOPE_RATES` продолжает отдельно проверять допустимость Code20 для выбранного АЦП.

### Реальное размещение в оригинале

Реверсированная `_Unit128:008458FC..00845913`: для каждой записи выполняется `Tag div 0x14` с `SetBreak` на tag 0 и 20. Первая колонка **Tag0–19** (20 строк), вторая **Tag20–31** (12 строк). Ранее стандартный `QMenu` показывал все 32 строки вертикально и прокручивался/переносился по усмотрению Windows DPI. Теперь `desktop/source_envelope_popup.py` создаёт *одно настоящее* `QMenu popEnvelopeType` с `QWidgetAction` и двухколоночным `QGridLayout` из 32 `QRadioButton`, реальной уникальной радиогруппой. Все 32 исходных `QAction` остаются доступными из `OriginalSourceEnvelopeMenu.actions()` в прежнем порядке: `data(Tag)`, `checked`, `enabled`, `triggered`. В Qt нельзя `setVisible(False)` на добавленных в меню source-`QAction`: это **также отключает действие**. Поэтому реальный `QMenu` содержит **один** native-`QWidgetAction` (двухколоночный виджет), а все **32** source-`QAction` принадлежат этому же QMenu как QObject-модели, но не зарегистрированы как отдельные строки. Публичный Python-метод `actions()` возвращает оригинальные 32 модели; `native_actions()` показывает единственный **отдельный host-widget**. Qt требует `QWidgetAction.setDefaultWidget(palette)` выполнить **до** `QMenu.addAction(host)` — иначе контейнер не создаёт видимую панель. Оба вида действий активны по независимой проверке Core и не имеют отключённых скрытых дублей. Так можно проверить один и тот же popup и из `bAdcEnvelopeType`, и из `bSpecEnvelopeType`.

Нажатие на исходную кнопку только открывает popup, а выбор конкретной видимой радиостроки вызывает старый принятый Core транзакционный выбор, *сначала закрывая popup*, затем рассчитывая оба графика. Это исключает блокирование меню во время долгого FIR/FFT. Отдельные исследовательские ComboBox тоже используют те же точные исходные подписи (вместо `Код огибающей 20`). Две первичные DFM-кнопки теперь показывают настоящую подпись полосы. Исходное DFM `popAdcType` подтверждает `AC` и `AC+DC`; в первичной ADC-кнопке восстановлен именно `AC`, вместо прежнего длинного «AC · без DC».

### Работа без приватных коэффициентов

Внутри `PageSpectrum` исходная split-кнопка теперь **видна и открывает общий popup** при наличии измерения, даже если локальный IDP ещё не загружен. Тогда Tag0 включён, а Tag1..31 видимы с реальными названиями, **но недоступны**; причины есть в подсказке. После явной загрузки проверенного операторского IDP пункты становятся доступными только при допустимом `source Fs >= target Fs`. Ни один disabled code не может примениться даже программно: Core проверяет частоту и банк FIR независимо от Qt. При смене измерения/АЦП прежний Source Tag автоматически сбрасывается, если неподдерживаем.

Эта версия **не объявляет** готовой точную полную копию интерфейса оригинала: поля других страниц, пиксельное окно TQGrapher/GDI, текст Tag0 на выбранной локали, оригинальные значки bitmap, оси/курсор и полные расчёты source x87/Win32 ещё должны проходить одну парную проверку на реальном BIN.
