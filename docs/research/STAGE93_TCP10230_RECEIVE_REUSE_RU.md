# Stage93 — TCP/10230 и повторное использование расчётного приёмника

Проверен оригинальный IDR `_Unit125.pas` и сохранённые исследования GitHub Stage59–63, 77. **MVK Reader Web использует только TCP/10230.** Спецификация Modbus 502 полезна как справочник регистров, не как требование к сетевой реализации.

Прямые факты IDR:
- `0x00807C12` задаёт `0x27F6` (=10230) для `TIdTCPClient`, подключение с тайм-аутом 1000 мс и чтение 5000 мс.
- `0x0080841B–0x00808443` читает служебные 32-битные слова сообщения; `0x00808464` выделяет адрес маской 0xFFFF, `0x0080846F` выделяет длину сдвигом на 16 бит. Проверяется чётность и ограничение <=0x4000.
- `0x00808544–0x0080856D` размещает полученный блок по смещению address*2 (байт) в локальном образе регистров и читает length*2 байт.
- `0x0080857C–0x0080859A`: при задаче 2 вызывает `sub_00805D08` для 14 групп отображения (семантику всех групп ещё уточнять).
- `0x008085A5–0x008085BD`: блок 0x3100 запускает очередную строку VALUES при активной записи.
- `0x0080827F–0x0080828C`: отдельный путь отсчётов через `TMvkChannelStorage.ProcessBufferChunk`.

УЖЕ РАНЕЕ ВОССТАНОВЛЕНО в GitHub:
- `docs/PROTOCOL_CALIBRATION_RU.md`: ADC кадр TCP/10230 1052 байта, заголовок 28 байт и 256 float32 LE; raw*K, BIN уже в физических единицах.
- `docs/research/STAGE60_CONTROL_RECORDS_RU.md`: 160-байтные сообщения состояния и 8 слотов на каждый АЦП; состояние слота не устанавливает его физический ID.
- `docs/research/STAGE63_CONFIG_CONTROL_MAP_RU.md`: карта A=0x2000+0x200*N; конфигурация параметров отдельно.
- В ранних этапах восстановлен AUX4700 как восемь наборов 144 float32 плюс статусы. Дальше переиспользовать существующий декодер вместо восстановления заново.
- Stage59 и пользователь подтвердили, что PCAPNG и BIN/VALUES №43 относятся к разным сессиям; нельзя синхронизировать их между собой.
- Stage71–72: дополнительная конфигурация тоже использует собственный TCP/10230; в реальной проверке запрещены команды записи без разрешения.

Статическая проверка оригинального IDR локально: **7/7 групп PASS**. Скрипт `tools/research/stage93_verify_tcp10230_idr.py`.
