# MVK TCP/10230 — подтверждённая спецификация (Stages 31–40)
Дата 2026-10-28. Режим: **только чтение**, подключение к реальному прибору новой версией клиента не испытано.

## Транспорт
`TCP port 10230`. Indy MVKView: подключение 1000 мс, чтение 5000 мс. В исследованных PCAPNG на направлении ПК→МВК имеется только TCP ACK, полезной нагрузки нет. Поэтому захваты не доказывают отправку конкретных команд, но показывают, что прибор **может сам передавать поток после подключения**.

## Граница кадров
`<u32le type><u32le length><body[length-8]>`; длина 8..131072 включительно, кратна 4. Нельзя считать, что границы вызовов socket.recv совпадают с границами кадров.

| Type | Назначение | Формы |
|---|---|---|
| `0x00000001` | идентификация | стартовый пакет 264 байта |
| `0xFF800ADC` | кадр АЦП 0–7 | 1052 байта; 256 значений float32 |
| `0xFF8001AC` | тахометрические данные каналы 8–9 | 284 байта; 64 float32 |
| `0xFF800C0D` | универсальный структурированный блок | 44/76/160/4700/32800 и другие |
| `0x00010FF1` | ответ/подтверждение (наименование проверять по вызову) | не наблюдался в пассивных записях |
| `0x00011000` | ошибка операции `errOperationDenied` | не наблюдалась в пассивных записях |

Для каналов оба ADC типа используют пять u32 в начале тела: первые 3 служебные, далее `channel` и `fs`; полезная часть — float32 LE. Для `fs=65536` накопление на каждом из восьми каналов непрерывно независимо от открытой страницы UI.

## Вложенные структурированные блоки
После внешних 8 байт идут 4 зарезервированных u32 и `count:u32`, затем `count` записей: `header:u32`, `W*2` байт данных. `header = (W<<16)|ID`, `W` — число 16-битных слов. Проверенная длина `L=28+sum(4+2W)`. Не называть каждую вложенную запись VALUES: её назначение зависит от ID и контекста.

## Управление
Оригинальная MVKView имеет код формирования исходящих кадров `0xFF800C0D` и короткую очередь `QueueCommand`. Команда частоты использует ID `0x000E` и 32-битное значение fs; общий размер кадра 36 байт. Меню частот: 512,2048,8192,32768,65536 Гц. **Никогда не отправлять команды записи настроек или перезагрузки в режиме просмотра.** Успех команд на устройстве не проверен.

## Проверки
Stage 34: `1111(1).pcapng`, 239626 кадров (включая 173469 ADC, 43368 тахо). Stage 40: `83 первый(1).pcapng`, 42410 кадров без ошибки рассинхронизации, оставшиеся 816 байт конца незавершённого кадра. Произведённые тесты офлайн, не прямой live-тест.
