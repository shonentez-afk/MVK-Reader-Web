# Stage 57 — структура канальных сообщений 160 байт

28.10.2026. Офлайн-проверка архивных захватов приборов №83/№84, без подключения к оборудованию.

В каждом захвате 8 канальных вложенных записей (ID 0x2130, 0x2330, 0x2530, 0x2730, 0x2930, 0x2B30, 0x2D30, 0x2F30), по 15 повторений каждого ID. Каждая запись имеет полезную область 128 байт, которая рассматривается как 32 слова u32.

По прибору №83 из 256 позиций (8 каналов × 32 слова) **38 изменяются**, а 92 хотя бы раз ненулевые. По прибору №84 **все 256 позиций нулевые** в соответствующих 15 повторениях. Отдельные АЦП и AUX4700 данные при этом поступают; нельзя трактовать нули как отсутствие вибрации.

Наиболее часто динамические позиции: 0,4,8,12,28. При reinterpret float32 значения выглядят конечными: первое слово 28 канала ID 0x2130 ~0.072058, ID 0x2330 ~10.844768. Позиции 13 и 15 местами изменяются как целочисленные флаги. **Идентификация физического смысла не выполнена**.

Локальный полный пакет `MVKVIEW_STAGE57_CHANNEL_FIELD_MAP_20261028.zip`: `FIELD_VARIABILITY.csv` (576 строк), `AUX_NEAREST.csv` (240 строк), `stage57_analysis.py`, полный отчёт. Близость AUX4700 по байтовому смещению не равна доказанной синхронности по времени. Следующий этап — сверка смещений с TABLE/VALUES и картой КП; восстановление семантики статусов.
