# Copy/Save штатных архивов Mode1

- В оригинале 1.0.47 сохранение спектра подтверждено для исходного ADC1 BIN/TSXML: три числа и дневной SPEC-FREQ, заголовок один. В изолированной VM также сохранён спектр тестовой пары Byte TACH; строка при 1 Гц/линию совпала с расчётом Compatible. Это не запись физического тахометра.
- Подтверждённый формат: три поля через TAB в Copy; `sep=|`, локализованный заголовок и строки через `|`, CRLF. Русский выход Compatible — Windows-1251 без BOM. Оригинал использует Windows ANSI, поэтому байты из старой VM с иной ACP не доказывают попарное равенство всего файла на русской Windows. Основание: восстановленные обработчики Copy/Save, локализация и сохранённая трасса.
- Штатный экспорт разрешается для полной согласованной пары исходного вида и текущего реального окна. Для ADC проверяются положительный FRange, FUnits, Fs и режим исходного хранения; для TACH из имени/TSXML подтверждаются канал, Count, Byte, gain 1, Fs и нормализация Byte/255. Совместимый формат не утверждает независимо проверенную физическую калибровку. TACH здесь не RPM. Неполная локальная пара остаётся с явной маркировкой; отсутствие, повреждение или противоречие обязательной TSXML блокирует импорт. Не повторяем оригинальное угадывание метаданных.
- Заголовок использует FUnits активного канала с исходными правилами `Count → пусто`, `1 → м/с2`, `м/с2 → мм/с / мкм` или `~ / ~~` для иных единиц. Дневной файл при смене режима или канала сохраняет первую шапку; статус сообщает, если новые единицы отличаются. Чужую шапку, смешение числовых локалей, повреждённые строки и UTF-8 не дописываем. Границы окна и SHA BIN/TSXML не дают сохранить старый результат после смены источника.
- Для исходных FIR допустим валидный пост-FIR FFT короче 1024; поправлена проверка экспорта, FIR/FFT не менялись. Native ZIP сохраняет свою политику, LIVE не менялся.
- Приватный оригинальный набор: ADC1/3/6; покрытие ADC1–8, TACH1/2, режимов и локалей в регрессии синтетическое. Полное сравнение на физическом приборе/Windows OEM живого потока сюда не входит.
