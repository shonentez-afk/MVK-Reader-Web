### Контроль FIR при Fs=65536 Гц
| Filter | PRE-FIR выбранное N | RAW с историей | FFT N после FIR | Fs после FIR | Δf |
|---|---:|---:|---:|---:|---:|
| Code20 | 4096 | 4147 | 2048 | 32768 | 16 Гц |
| Code20 | 1024 | 1075 | 512 | 32768 | 64 Гц |
| Code4 | 4096 | 4289 | 512 | 8192 | 16 Гц |
| Code1 | 8192 | 8289 | 2048 | 16384 | 8 Гц |

Примеры `N=1024/4096` могут относиться к исследовательскому API и **не доказывают наличие таких пунктов в исходном шестиэлементном меню**. Все примеры проверяют только длины, а не численную x87 идентичность спектра.

Матрица допустимых original-условий `ratio = Fs/target` для 31 фильтра из IDP (не UI pixel parity):
- Fs512: 0 допустимых ненулевых кодов; Fs2048: 5; Fs8192: 15; Fs32768: 20; Fs65536: 21.
- В исследованном наборе для шести штатных bSpecLines размеры N/Fs после FIR соответствовали целым radix-2 FFT для всех допустимых кодов.
- Наличие пунктов в меню не означает, что текущая Fs делает все FIR-коды допустимыми.

## Аппаратный P0 без косметического дробления

Подлинный полный оригинальный запуск **НЕ АТТЕСТОВАН**:
`IP → Измерить → Task2 → TCP RX → GetSignal → GetSpectrum/FIR/Hann/FFT/Power → Tag0/1/2/3 → WriteData + WriteValues → Stop`.

Для закрытия P0 нужен **один физический RX одного MVK01** с записью исходного Win32 в тех же фазах, перенося только локальные SHA/Float32 стадии и поля (Fs, АЦП, FRange, окно, исходный индекс), фиксируя границу Stop и writer-ы. Разные BIN/VALUES/TABLE из разных измерений не являются доказательством same-run. Не публиковать пользовательский RAW, IDP, 7z, SQLite; не посылать команды прибору без оператора. CI Go loopback и Python synthetic не заменяют реального прибора.
