# Статус реверс-инжиниринга MVKView (2026-10-28)

**Stable:** MVK Reader Web v0.3.40 (не менять до регрессии).

- Stage 30–34: проект IDR, `TMVKThread`, протокол TCP/10230, типы кадров и непрерывный поток 8 АЦП + 2 тахометра.
- Stage 35–39: структура исходящих запросов, конфигурационные диапазоны, `QueueCommand/SetRate`, меню частот 512 / 2048 / 8192 / 32768 / 65536 Гц.
- Stage 40: автономный TCP-декодер, офлайн-проверка на захвате №83; подключения к реальному прибору не было.
- **Stage 41:** доказана локальная спектральная обработка MVKView через `TMvkChannelStorage.GetSpectrum` (лимит FFT 262144), фоновый `TBackgroundProcessThread` и условное масштабирование отсчётов `FRange`. Отчёт: [Stage 41](STAGE41_SPECTRUM_CHAIN_RU.md).

**Приоритет:** ядро `DSXFastFourier`, окно/нормирование спектра, преобразования ВУ/ВС/ВП, независимая проверка по PCAPNG/BIN. Отдельно сохранить различие приборных расчётных значений и локального FFT.
