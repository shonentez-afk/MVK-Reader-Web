# STAGE111Z31CI — единый полный PaintBox bitmap: grid, TCanvas.TextOut, TQGRSeries, frame

**13.11.2026. Приёмка: ПРИНЯТ крупный пакет Core + действующий Qt + Windows EXE. НЕ полная MVKView 1.0.47 1:1.**

## Источник

Операторский приватный `Projects.7z` изучен локально, НЕ закоммичен: `_Unit115.pas`, `_Unit128.pas`, `mvkform.dfm`. Оригинальный `TQGrapher.Draw` от `007CAC68`: TCo2Draw белый 32-bit raster; горизонтальная/вертикальная серые линии software AA; копирование реального `PaintBox.Canvas.Font` в memory bitmap (`007CACEF..007CACF9`); `TCanvas.TextOut` на этом bitmap; source full-column min/max серия (`007CB12F`), frame (`007CB3FF`); transfer to PaintBox (`007CB4AA`). Формы DFM указывают Tahoma с Font.Height=-13 / design PPI96; конкретный рабочий DPI/font исходного EXE не измерен. Точное оригинальное **порядковое переплетение** TickLine/TextOut находится внутри отдельных grid loops: CI использует высокоуровневые стадии **все линии grid → все события TextOut → series → frame**, так что это *источниковый кандидат*, не source-execution pixel 0-ULP parity. Для исходного PageAdc `ScrWidth<0` и source TQGRSeries reversed-X сохраняются.

## Что реально изменено вместе в ядре и интерфейсе

1. Новый автономный `mvk_compatible/core/original_live_whole_paintbox.py`: `prepare_whole_paintbox_plan` на исходных `source_live_paintbox_text_plan` и 10×10 grid Single, с тем же измеренным source PixelRect для сетки/текстовых координат/полного TQGRSeries.DataSize. Отдельный `WholePaintboxTask` пишет **один 32-bit RGBA buffer**: горизонтальная сетка → вертикальная → ровно один вызов TextOut callback на том же изображении → source minmax strokes → четыре frame strokes. Все операции bounded, до 256 strokes/step, без публикации незавершённого изображения. Детерминированный RGBA SHA при разных размерах slices, входной Float32 сверяется SHA и не меняется. Нет зависимости от PySide6/Win32/прибора/хранилища.
2. Новый `mvk_compatible/desktop/source_whole_canvas_adapter.py`: из живого PlotWidget извлекаются текущий размер полного PaintBox, SourceGDI/Qt TextWidth/TextHeight, источник signed ScrWidth, осевые названия и Full Float32. Сверяются координаты PlotRect с зарегистрированным `source_canvas_model`; отклонения более 2 логических px отклоняются вместо неверной подмены. Windows вызывает существующий Native `Win32SourceTextCanvas.GetTextExtentPoint32W/TextOutW`; non-Windows — явно неопределённый по GDI Qt rendering.
3. `desktop/source_live_composite.py`, `source_plot_geometry.py`, `source_paintbox_text_overlay.py`: **обычные PageAdc и PageSpectrum** автоматически используют новый full source PaintBox, если принят data binding. Единственное полноцветное RGBA изображение затем разделяется **только для Qt presentation**: plot crop рисуется QGraphicsObject поверх Qt/CG curve, margin crop с тем же `rgba_sha256` представлен прозрачным mouse-pass-through QWidget, не перерисовывая GDI. Источник не пересчитывается в отдельном потоке/модели. Текущие 10x10 оси и GDI Tahoma -13 общие. Старый Qt/CG source bitmap и старый CH TextOut остаются **fail closed** fallback. Source mouse cursor, XOR и `_wave_hover_window` не переписываются. Выбор другого архива, фильтра, zoom, pan, reset/исследовательского original mode инвалидируют изображение и не могут оставить старые подписи. Фиксированный source DFM font metric GDI кешируется как **словарь**, не как GDI DC/HWND.
4. Новые `tests/test_stage111z31ci_core_whole_paintbox.py` и `test_stage111z31ci_qt_whole_paintbox.py`, обновление accepted-CG QA, обязательный Windows Qt DPI150 workflow. Core проверяет Float32 SHA, reversed-ADC geometry, стадию текстового callback ровно один раз **до** серии, границы и несовместимые input, одинаковый RGBA при разном размере порций; Qt на синтетическом ZIP проверяет именно **один source RGBA digest у plot и captions**, две страницы, реальные native Win32 GDI vs Qt candidate, защиту от старого диапазона, неизменный полный FFT, XOR и отказ невалидного source, контролируемый research fallback. Семь страниц и три формы сохранены прежними интеграционными тестами, но НЕ объявлены исчерпывающе восстановленными.
