# Stage111Z31EK: диапазон и единицы АЦП после повторного подключения

**Дата:** 24.11.2026. **База:** EJ в черновике PR #17.

## Что изменилось

После повторного подключения диапазон мог подменяться единицей, а единицы измерения пропадали, если первый пакет параметров был неполным или пришёл при Freeze. Теперь Go хранит последние принятые Range/Units каждого из восьми АЦП отдельно от регистров текущего сокета. Первый непустой пакет фиксирует эту конфигурацию для новой попытки, а Freeze не меняет её входные данные. Предыдущие отсчёты не пересчитываются.

Свежесть Status0, PageStatus и VALUES проверяется как раньше, по сокету. Исходные данные по-прежнему сохраняются отдельными RAW-сегментами; многосокетный сеанс не выдаётся за один сертифицированный замер. Сетевые команды и разрешения не изменены.

## Что проверено

- До исправления новый тест воспроизводил потерю диапазона и единиц. После исправления он проверяет пустой пакет, Freeze, частичные обновления, порядок первого дескриптора и независимость двух АЦП. Отдельный тест открывает два локальных TCP-соединения и проверяет реальный путь повторного подключения без SetRate.
- Полный Go suite, go vet и кросс-сборка Go для Windows amd64 прошли. Python Core: 2827 passed, 156 skipped, 30 subtests passed. Кросс-сборка не заменяет оконную проверку Windows.
