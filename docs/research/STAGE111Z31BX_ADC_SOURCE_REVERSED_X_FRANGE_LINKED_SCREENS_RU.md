## Новая восстановленная исходная логика

По приватным операторским _Unit128.pas + _Unit115.pas + mvkview.idp (не публикуются):

- \`0084B2F8..0084B409\`: PageAdc TQGrapher.ScrLeft равен H duration из \`008D33BC\` (секунды при H>=10000ms, иначе миллисекунды), ScrWidth отрицательный; \`00848033..00848079\`: Series.XScale = Single(1/Fs) или Single(1000/Fs). Исходный GetSignal возвращает обратный буфер, а отрицательная X-ось размещает более старые отсчёты слева, новые справа. Численный источник — полный \`TMvkChannelStorage.GetSignal\`.
- \`0084ACAD..0084AF26\`: для типа Single (\`TMvkChannelStorage.FAdcDataType=1\`), \`GraphDefaultVScale\` выводится из текущего \`TMvkChannelStorage.FRange\` через ступени 1/2/5/10 (Log10 + trunc + pow10, Single); \`0084B321..0084B350\`: ScrBottom=-GraphDefaultVScale/divisor, ScrHeight=2*GraphDefaultVScale/divisor. Byte/счётный канал исходно другой и не должен считаться Float32 ускорением.
- \`0084655B\`: только положительный текущий \`InternalChannelGain\` из TSXML попадает в исходный FRange по статически восстановленной ветке; этот статус **не** подтверждает физическую калибровку/аппаратный runtime.

## Что реально соединено

- В новом независимом \`core/original_adc_source_axes.py\` реализованы рассчитанная Float32 XScale, ScrLeft/ScrWidth, два режима подписей ms/s, инверсия исходного буфера и преобразование Source X → индекс GetSignal → физический индекс BIN, с проверкой текущего АЦП/SHA и окна. Данные сигнала не пересчитываются из прореженного LOD.
- В \`core/original_adc_view_controls.py\` источник Y для Direct BIN с положительным ChannelGain теперь соответствует независимой 1/2/5-модели спектрального FRange, а не максимуму нарисованной линии. Для Native ZIP или отсутствующего FRange остаётся **явно локальный** full-waveform peak; оригинальный GraphDefaultVScale не имитируется. Метки отсутствия Win32/x87 и физической калибровки сохранены.
- Реальный \`desktop/main_window.py\` делает исходную обратную X-ось GetSignal без FIR доступной непосредственно на PageAdc и выбирает её по умолчанию; две прежние исследовательские визуализации сохранены отдельно. Курсор по X сверяется с полным исходным буфером и самостоятельным \`WaveformHoverWindow\`. Смена режима, АЦП и архива сбрасывает source X/Y/cross-page receipts. FIR не маскируется под доказанный оригинальный абсолютный X.
- \`source_adc_spectrum_joint_receipt\` проверяет фактическую связность текущих PageAdc и PageSpectrum по оригинальному BIN SHA, выбранному ADC, исходным Float32 окнам и настоящим N/2 FFT бинам; не требует ложного «одного окна», когда Spectrum берёт конец архива, а GetSignal — выбранную область. В Qt источник/числа отображаются в доступной подсказке к сводке спектра; графические пиксели не используются для расчётов.
- Синтетические Core тесты исследуют инвертированный буфер, 20 ms→1310 отсчётов при Fs=65536, переход X единиц при 10 секунд, усечение короткого архива, отсутствие FRange при чужом АЦП, положительный TSXML FRange 6.25 → кандидат GraphDefault 10 → вертикальный делитель 5 → [-2;2], отличие полного N/2 FFT от LOD. Windows Qt/DPI150 проверяет видимые X/Y, исходный MouseMove, переход в PageSpectrum, перезапуск и закрытие сеанса. Ранее принятый семистраничный/трёхформенный E2E остаётся в CI.
