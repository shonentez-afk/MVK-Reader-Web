
# Сверка меню «Спектр» MVKView 1.0.47 по прежним пользовательским PNG (23.11.2026)

В ChatGPT Library текущего проекта найдены и визуально прочитаны реальные оригинальные скриншоты. Приватные PNG не копировать в публичный GitHub. Источники дополнительно сверены с оригинальными Source Tag из mvkview.idp и Projects.7z/_Unit128.pas.

- image(20261021-051445).png и image(20261021-051618).png: меню «Без фильтра», два столбца 20+12 (32 пункта, включая без фильтра).
- image(20261021-051502).png: четыре режима «Логарифмич.», «Линейный ВУ», «Линейный ВС», «Линейный ВП».
- image(20261021-051524).png: шесть значений 1/4,1/2,1,2,4,8 Гц/лин при Fs=65536. Исходные NFFT 262144,131072,65536,32768,16384,8192. Исследовательские N1024/4096 НЕ являются исходными пунктами.
- image(20261021-051533).png: шкала X 25600,12800,6400,3200,1600,800,400,200,100,50 Гц.
- image(20261021-051544).png: шкала Y в режиме ВС, 10000,1000,100,10,1,0,1 мм/с, из исходного Y-default и делителей 1,10,100,1000,10000,100000.
- image(20261021-050846).png и image(20261021-051314).png: исходная страница со всеми пятью меню, курсор, СКЗ, пик, «Копировать», «Сохранить», график и scroll.

Исправления: bSpecLinesPresenter теперь отображает ТОЛЬКО 6 исходных Tag-пунктов (без исследовательских суффиксов и размеров); внутри технического инспектора выбор 1024/4096 сохранён. Ярлык bSpecSaveValue: «Сохранить» вместо «Сохранить CSV»; экспорт не менялся. Подписи Y при наличии source GraphDefaultVScale используют единицы выбранного режима ВУ/ВС/ВП и русскую десятичную запятую, но в tooltip сохраняется предупреждение о НЕподтверждённой калибровке. При НЕизвестном FRange остаётся честный исследовательский «÷ N (лок.)».

Добавлены core и Qt тесты для исходных 6/10/4/32 пунктов и номинальных единиц Y. Никаких изменений к DSP, Go TCP, GetSignal/GetSpectrum, WriteValues/WriteData/Stop. Синтетический CI не является доказательством Win32 pixel parity. Полная оригинальная аппаратная приёмка остаётся открытой.
