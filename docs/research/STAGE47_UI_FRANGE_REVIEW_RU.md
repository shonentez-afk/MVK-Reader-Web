# Stage 47 — режимы спектра, FRange и проверка формулы (2026-10-28)

По локализации оригинальной MVKView четыре пункта: 0 «Логарифмич.», 1 «Линейный ВУ», 2 «Линейный ВС», 3 «Линейный ВП». Метод формы `mSpecType1Click` (0x0084C514) переносит `TMenuItem.FTag` в `bSpecType.FTag` (0x0084C541–0x0084C54A). Точное соответствие всех Tag индексам меню ещё требует проверки DFM.

`TMvkChannelStorage.GetSpectrum` имеет четыре ветви: 0x007D15DD — log, 0x007D1652 — линейная без интегрирования, 0x007D16A7 — один вызов 0x007D2164, 0x007D1731 — два вызова 0x007D2164. Линейные ветви содержат множитель `FRange` на выходе, но чтение сигнала по 0x007D22C8 **делит** на `FRange` в отдельном пути. Нельзя игнорировать условия этого пути.

**Критическая поправка к Stage 46:** в `0x007D2164` по видимым инструкциям получается амплитудный коэффициент `2π/(1000f)`, тогда как стандартный переход из м/с² в мм/с — `1000/(2πf)`. Ветвь действительно изменяет квадрат амплитуды, но пока нельзя объявлять её физически верным интегрированием без проверки остальных промежуточных масштабов и смысла аргументов. Прежнюю трактовку считать **неподтверждённой**.

Локальный автономный тест: 8/8 адресных опор, сравнение коэффициентов на 5, 25, 100 Гц. Команды прибору не отправлялись. Stable v0.3.40 не изменена. Полный локальный пакет: `MVKVIEW_STAGE47_UI_FRANGE_REVIEW_20261028.zip`.
