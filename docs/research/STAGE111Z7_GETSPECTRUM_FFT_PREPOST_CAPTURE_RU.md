# Stage111Z.7 — ORIGINAL GetSpectrum: точные pre/post FFT границы и локальный побитовый компаратор

**Дата:** 30 октября 2026. **Рабочая ветка:** `research/stage111-mvkview-desktop-20261029`. **Цель:** полностью автономная Windows MVKView Compatible (Qt/PySide6), без Web-сервера.

## 1. Подтверждённая структура оригинального GetSpectrum

В приватном пользовательском архиве Projects.7z локально прочитан восстановленный Delphi-код `_Unit115.pas`, затем независимо сверены реальные инструкции в `mvkview.idp` (IDR v3): **4 оригинальных окна .text SHA256 совпали**. Исходный код, IDP и их машинные байты НЕ опубликованы.

| Исходный диапазон | Назначение | Длина |
|---|---|---:|
| `007D1472–007D14B8` | GetSignal/исходный буфер и одно вычитание среднего | 70 B |
| `007D1518–007D1558` | Два контрольных адреса до/после FFT и общий указатель | 64 B |
| `007D2080–007D20B6` | вызов FFT, N/2, pow Re²+Im² в Single | 54 B |
| `007D15A5–007D15E1` | Param field SpectrumMode и последующая обработка | 60 B |

Локальная сверка SHA каждого окна выполнена на приватном оригинальном IDP. Публикуемый `private_getspectrum_capture_source_audit.py` хранит только SHA/адреса/форматы инструкций, никогда не передаёт исходные байты в отчёт.

Внутренние шаги:

1. `007D14A5` — GetSignal получает `N` Float32 из хранилища выбранного канала в буфер на `[EBP-2C]`.
2. `007D14B3` — удаляет постоянную составляющую **один раз**; при envelope code>0 до FFT идут оригинальные FIR/IQ операции.
3. **`007D153D`** — первая точка: уже подготовленный `N×Float32` массив, но ещё до Hann/FFT.
4. `007D1546` вызывает `007D1FE8`: применяет Hann, выполняет положительный FFT `007CC3F8`, считает `Re²+Im²`, сохраняет первые **N/2** мощностей как Float32 в тот же рабочий буфер.
5. **`007D154B`** — вторая точка: после FFT и преобразования в power, но ещё до нижнего обнуления бинов, логарифмических единиц, физической интеграции для ВС/ВП и расчёта `OutputMean/Peak`.

Это означает, что **для численного сравнения FFT-ядра не нужно угадывать исходный BIN-контент или повторять калибровку/FRange**: можно читать уже подготовленный оригиналом input и результат в одной функции. Любые расхождения сравнения локализуются между этими двумя точками (Hann/FFT/Power), а не в чтении архива или масштабировании осей.

## 2. x32dbg: подтверждённые поля одного вызова

При остановке на pre/post:

| Выражение | Смысл |
|---|---|
| `dword:[ebp-2C]` | адрес того же рабочего буфера до и после FFT |
| `dword:[ebx+4]` | N, длина FFT |
| `dword:[ebx+8]` | код огибающей |
| `dword:[ebx+18]` | SpectrumType Tag (0/1/2/3) |
| `dword:[ebx+2C]` | итоговая Fs, Гц |
| `dword:[dword:[ebp-4]+4]` | FRange исходного канала, битовый Single |

Полная инструкция с точной командой **read-only x32dbg `savedata`** и образцом локального JSON:
[STAGE111Z7_X32DBG_FFT_POWER_CAPTURE_RU.md](STAGE111Z7_X32DBG_FFT_POWER_CAPTURE_RU.md).

Два дампа имеют размеры: `before_fft.bin` = **4×N байт** и `after_power.bin` = **2×N байт** (N/2 Single). Дампить нужно в одном и том же вызове GetSpectrum. После выхода из процедуры рабочий буфер может быть освобождён; адреса использовать только на остановке.

## 3. Разработан полностью локальный сравнитель

**`mvk_compatible/private_getspectrum_power_compare.py`**:

- Читает строгий частный manifest schema `MVKVIEW_ORIGINAL_FFT_POWER_PAIR_V1`, требует контрольные VA 007D153D/007D154B, power-of-two N=1024..262144, режим 0..3, Fs, канал, код огибающей, положительный FRange IEEE754 Single.
- Проверяет **ровно** 4N/2N байт двух локальных little-endian Float32 файлов, конечность чисел и неотрицательные исходные мощности. Запрещает произвольные абсолютные/родительские пути, symlink и лишние поля.
- Вызывает уже существующий source-derived `idr_power_spectrum(before_fft, backend="idr_float32", remove_dc=False)`. Повторное вычитание DC было бы ошибкой! Дополнительно вычисляет NumPy reference FFT без изменения исходных файлов; выход сравнивается после явного приведения к Single.
- Выдаёт только **агрегаты**: число exact bitwise equal, число mismatches, <=1 ULP, max/mean positive float32 ULP и максимальную относительную ошибку. Не выводит сырые данные, отдельные значения бинов, адреса дампов, локальные пути, FRange и названия приватных файлов.
- Отмечает, что происхождение файлов и их принадлежность одному оригинальному вызову нельзя аутентифицировать программно. Любое 100% совпадение одного дампа **не аттестует** всю оригинальную Delphi FFT.

**`mvk_compatible/tests/test_stage111z7_private_getspectrum_power_compare.py`** содержит только синтетические тестовые сигналы: нулевые расхождения при идентичных power, контроль 1 ULP в конкретном изменённом бине, невозможность двойного DC removal, отрицательные/NaN/Inf, опасные имена и symlink, разные spectrum mode и отказ при некорректной JSON-схеме.

**`mvk_compatible/private_getspectrum_capture_source_audit.py`** — приватный SHA source verifier всех 4 диапазонов, дополнительно проверяет реальные `GetSignal`, `RemoveMean`, вызов FFT, поле `N`, указатель `[EBP-2C]`, `N/2` и `FSTP Single`. Synthetic-only тест: `test_private_getspectrum_capture_source_audit.py`.

## 5. Следующий этап Stage111Z.8 — одна реальная power пара

1. В Windows оригинальной MVKView открыть один **офлайн** измерительный архив на одном канале (предпочтительно простая «Линейный ВУ» без огибающей).
2. Выполнить инструкцию двух breakpoint из указанного Stage111Z.7 guide. Желательно N=4096 или 8192 для компактности; если оригинал работает с другим N, не менять его ради удобства без понимания.
3. Проверить, что это один и тот же `EBX`, `N`, `[EBP-2C]`, канал. Сохранить pre/post и локальный JSON. Данные не публиковать в GitHub или CircleCI.
4. Запустить `python -m mvk_compatible.private_getspectrum_power_compare "C:\\MVK_CAPTURE\\capture.json"`. Прислать **только агрегированный JSON**; для подробного локального исследования конкретных бинов при необходимости сделать расширение компаратора без утечки исходных данных.
5. Если получено расхождение, локализовать в Hann, исходной x87 SIN/FFT twiddle, butterfly или single-store. При частичном/100% совпадении не переносить заключение на другие архивы, каналы и CW.
6. После FFT перейти к оригинальным RMS/Peak/XScale и курсору без приборного доступа.

Стабильная `main`, Web v0.3.40, закрытые EXE/IDP/PAS/DFM/BIN/RAW/PCAPNG и промышленная сеть не тронуты.
