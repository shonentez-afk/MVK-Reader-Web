# Stage 79c — загрузка TSXML и открытие архивного BIN (2026-10-28)

Источник: извлечённый из локального `Projects.7z` оригинальный IDR `_Unit128.pas`. Исследование **только статическое, без прибора**.

## Подтверждено непосредственно
- `0x00846EB5`: после `TOpenDialog.GetFileName` вызывается `sub_00846008` с выбранным файлом.
- `0x0084605C–0x008460BD`: поиск `selected_filename+'.tsxml'`, проверка существования, `@ResetText`.
- `0x008460F8–0x00846266`: построчное чтение до EOF. Внутри извлекаются `ChannelFrequency` и сверяется по массиву из пяти допустимых значений, `Units` (включая `Count`), `RealDataType` (`Byte` => код 2; `Single` => код 0), `InternalChannelGain` через `StrToFloat`.
- `0x008462CE–0x008463DF`: при отсутствии необходимой тройки параметров (частота, единицы, тип) запускается `queryDefaultFileParams`; при отказе генерируется `errOperationCanceled`. Используемая по умолчанию частота берётся из локального списка. Отсутствие TSXML **не означает безусловный отказ от чтения BIN**.
- `0x008463DF–0x00846529`: если коэффициент не положителен, для `Byte` устанавливается 1; для остальных типов прослеживается попытка получить значение из `DefaultConfig.txt`/параметров программы. Детальная семантика масштабирования ещё требует проверки.
- `0x00846535–0x00846591`: `TMvkChannelStorage.Create`, запись коэффициента в `[storage+4]`, единиц измерения в `[storage+8]`, задание частоты и `InitParams`.
- `0x00846596–0x00846665`: `TFileStream.Create` с режимом `0x20`; вычисление числа отсчётов: при типе 2 размер в байтах, иначе размер / 4; установка `TTrackBar` для навигации.

## Важные ограничения
Установлен **маршрут вызовов** к открытию и подготовке просмотра, а не полная семантика BIN. Не проверены все значения частот, длина длительности, поведение при повреждённом файле, фактическое преобразование единиц и полная численная трасса из хранилища к FFT. Для этих выводов нужен дальнейший анализ `TMvkChannelStorage` и контроль по паре реальных BIN+TSXML.

Скрипт воспроизведения: `python tools/research/stage79c_verify_bin_open.py /path/to/_Unit128.pas`. Скрипт проверяет только статические опоры, не воспроизводит программу.
