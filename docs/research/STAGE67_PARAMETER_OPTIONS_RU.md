# Stage 67 — точное сопоставление пунктов выбора с номерами параметров

Проверено по IDR оригинальной MVKView, `_Unit125.pas`, функция `0x00803FB4`: 9/9 опорных инструкций. `TMvkAdvancedCell.Add` получает в `edx` реальный номер расчётного параметра (не индекс пункта). Дольоктавные полосы: **2–44** (43 позиции). Три семейства по 8 диапазонов × 3 величины (ускорение/скорость/перемещение): **49–72**, **81–104**, **113–136**. Всего **115 уникальных выбираемых параметров**. По официальному протоколу 1.0.39 это СКЗ, эквивалентные пики и эквивалентные размахи. Доступные подписи строятся из локализационных ключей `xVibroAccelerationShort`, `xVibroVelocityShort`, `xVibroDisplacementShort`, `xParamOption`, `Band` и массивов частот.

**Важно:** номер параметра по официальной таблице начинается с 1; индекс в массиве 144 `float32` — `parameter_number-1`. Номера фактически выбранных КП у устройств 83/84 из этого кода не следуют. Полный локальный архив `MVKVIEW_STAGE67_PARAMETER_OPTIONS_20261028.zip` содержит `REPORT_RU.md`, `PARAMETER_OPTIONS.csv`, `verify.py`.

Следующий этап — восстановить частотные подписи восьми диапазонов и проверить точную структуру `TMvkAdvancedCell.Add`. Stable v0.3.40 не менялась.
