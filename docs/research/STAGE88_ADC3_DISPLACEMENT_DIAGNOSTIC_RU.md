# Stage88 — ADC3 displacement low-frequency sensitivity, 2026-10-29

Real MVK43 BIN+VALUES, separate recording triggers, PCAP not same session. Butterworth-3 10..3000Hz, half-second windows, displacement integration. Diagnostic cutoff candidate 10,12,14,16,18,20 Hz, fit on first 30 cycles only, evaluate last 33. Holdout baseline 10Hz error / training-selected cutoff error: ADC1 2.0718% / 2.0718% (selected 10Hz); ADC3 11.7601% / 5.0703% (selected 18Hz), corr 0.1348 / 0.5179; ADC6 1.6715% / 1.6715% (selected 10Hz). Common 18Hz cutoff would worsen ADC1 to 2.3750% and ADC6 to 1.6933%. Not evidence original device uses 18Hz cutoff; never change physical filtering based on this test. The result localizes discrepancy to ADC3 lower-frequency contribution, potentially transition/blanking and differing filter/window response (hypotheses).
