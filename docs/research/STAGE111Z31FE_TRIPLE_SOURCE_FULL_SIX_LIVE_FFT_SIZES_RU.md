# Stage111Z31FE — восстановление всех шести исходных bSpecLines в Live-измерении

Дата: 17.11.2026. Ветка `research/stage111-mvkview-desktop-20261029`.

## Обязательное совместное подтверждение оригинала из трёх приватных источников

Независимо проверены файлы `mvkview.idp`, `Projects.7z` и `mvk_idr(1).sqlite` из приватного проекта. `sqlite quick_check(1) = ok`, SHA-256 и длины четырёх извлечённых PAS/DFM совпадают с таблицей `source_files`; IDP содержит совпадающие оригинальные символы `TMvkChannelStorage.GetSpectrum`, `TMvkChannelStorage.CheckDataAvailability`, `TMvkChannelStorage.GetSignal`.

- Оригинальная `_Unit128.pas`, PageSpectrum `0084819A..00848200`: `bSpecLines.Tag` обращается к `gvar_008D3450`, а результат записывается в `TMvkChannelStorageCalcParams.Count` перед вызовом `TMvkChannelStorage.GetSpectrum`.
- Таблица оригинальных NFFT: **262144, 131072, 65536, 32768, 16384, 8192**. Остальные 1024/4096 — только локальные исследовательские размеры, не оригинальные меню.
- Оригинальная `_Unit115.pas`, `GetSpectrum 007D13D4`: `007D1404..007D1417` отвергает `Count > 0x40000`; `007D1421..007D142D` вызывает `CheckDataAvailability 007D1998` до FFT; `007D144C..007D1458` использует фактический кольцевой `FRxPos:UInt64`; `007D149A` читает реальные Float32; `007D14B3` выполняет Float32 DC-вычитание; `007D1546` запускает исходную FFT; `007D1591..007D15B9` подавляет низкие частоты. Никакого молчаливого выбора меньшего N по длине доступного окна нет.

## Сквозное изменение Go → Python Core → Qt

1. Native Go, `live_preview.go`: вторичный, **неуправляющий прибором** буфер расширен с 65536 до 262144 уже откалиброванных Float32 отсчётов на каждый из 8 ADC. Максимум **8 МиБ** оперативной памяти; данные поступают только **после** принятой записи в родной spool, не заменяя источник RAW/BIN. Для атомарного локального sidecar ZIP используется `zip.Store` вместо Deflate, чтобы не расходовать CPU единственного TCP-reader goroutine. Все 8 ADC имеют индивидуальные SHA-256, Fs, абсолютные first/next SampleIndex. Неиспользуемые каналы не выдумываются.
2. Core `native_r6_live_preview.py`: границы sidecar обновлены до 262144 точек/канал, 9MB на диске, не более 8МиБ распакованных ADC +16КиБ JSON; сохранены проверка источника, абсолютных индексов, Fs, меток времени и SHA. `provisional_spectrum` теперь реально считает все шесть исходных NFFT при наличии такого объёма данных; **никаких нулевых отсчётов**, изменения Fs или повторной калибровки FRange. На экране отображается не более 5000 peak-preserving точек, но FFT/СКЗ/максимум вычисляются по полному N/2. Это **кандидат** исходного DSP/Delphi, не численный паритет.
3. `GetSignal` из того же увеличенного буфера: временной график показывает **реальные последние 30 секунд** (старый контракт `waveform_for_zip`). При Fs=512 полные 262144 отсчёта охватывают 512 с, и прежний вызов падал на длительности >30 с; теперь не теряется абсолютная привязка сегмента и не портится 262144-точечный FFT.
4. Qt `main_window.py`: `bSpecLines` по-прежнему выбирает точный оригинальный N, включая 131072/262144. При высоких N пересчёт выполняется при открытии PageSpectrum и смене N/ADC/режима, но не чаще одного раза за 2.5 с при неизменном выборе. Это ограничение рендеринга, а **не** подмена алгоритма или 20ms исходного таймера интерфейса. Уже неактуальные спектры очищаются, когда очередной кадр не прошёл проверку целостности.
5. Регрессии: Go ring wrap и точные Float32/SHA + zip.Store; Python SHA/freshness/FFT 131072 и 262144, Δf, peak-preserving проекция и исторический вариант с 65536; реальный Qt QWidget тест выбора всех больших FFT и возврата к 65536. Не нужны сеть, IP, прибор или приватные дампы в CI.

## Непринято / открыто

Полная **битовая** идентичность исходного Win32 x87 / исходных Hann/FFT и `GetSignal/GetSpectrum` не аттестована; независимого same-run захвата исходного Delphi оригинала нет. Большой local preview — 262144, тогда как оригинальная измерительная ring storage использует 0x200000 отсчётов; абсолютная семантика 64-битного FRxPos, переполнение uint32 Sample.Index и фильтры Envelope требуют последующей проверки. Отправка IP/Flash/Reboot, исходные WriteData/WriteValues и реальные измерения на подключённом МВК01 также OPEN. `original_delphi_compatibility_verified=false`.

Ни приватный `mvkview.idp`, ни `Projects.7z`, ни `mvk_idr(1).sqlite`, ни PAS/DFM/RAW/PCAP не передавались в репозиторий.
