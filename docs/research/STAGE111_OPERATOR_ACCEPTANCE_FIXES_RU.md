# MVKView Compatible: операторская приёмка, пакет 1

## Новый операторский пакет приёмки (25.11.2026)

Релиз 815ea99 **не принят** по реестру MVK-01–21. Dot подготовил новый пакет из 12 файлов на основе e4d0a44, 79 локальных тестов по его отчёту. [Точный импорт пакета b7fbe6c](https://github.com/shonentez-afk/MVK-Reader-Web/commit/b7fbe6c95333d60d70885a775ed8c7d82f160cad); все контексты hunks и 12 Git blob SHA проверены. SHA256 переданного патча: f7de887af06ce3d710572597f7152a234fb38440d2e119726df963bb79ff1dbf. Следующий кодовый коммит включает защиту от Count→физической шапки и корректную коллекцию Qt-тестов без Qt. Не считать предыдущую portable 815ea99 исправленной.

| ID | Реализованный объём, требующий проверки готового кандидата |
|---|---|
| MVK-01, 03 | Штатное открытие графиков без resize, строго проверенная выбранная пара, предупреждение о пропущенных соседях. Не ослаблять проверку выбранного BIN/TSXML. |
| MVK-05 | Синхронная транзакция одного проверенного чтения на изменение времени; перед экспортом новое независимое чтение. GUI latency и отмена устаревших пересчётов ещё требуют измерений. |
| MVK-07, 08 | Ранний предпросмотр ADC с левым дополнением нулями только для нефильтрованного окна, экспорт заблокирован. FIR-история не реконструирована этим пакетом. |
| MVK-09, 10, 11 | Позиция TACH, ограничение частотной области, отметка подходящего пункта; короткий канал и шкалы проверить отдельно. Byte/255 не RPM. |
| MVK-12, 13, 14 | Отмена ожидания до TCP и видимая ошибка IPv4, исследовательские кнопки скрыты в обычном режиме. Отдельное окно, активный Stop и полное исключение диагностических входов ещё открыты. |
| MVK-15, 16 | Ширина таблиц, сетка, сохранение элементов, splitter и курсора при обновлении; требуется экранная/потоковая приёмка. |
| MVK-17–21 | Видимый отказ Copy, штатный Save As не меняет формат; пустая корректная шапка, append без запроса замены; физические единицы не смешиваются, Count сохраняет только свою семью шапок; известные единицы отдельно от факта калибровки. LIVE-экспорт и Win32-числа ещё не приняты. |

MVK-02, 04, 06 не закрыты этим пакетом. По решению владельца стандартные коэффициенты можно встраивать в приложение, без публикации IDP/приватных источников. Штатные FIR ещё не встроены. Полные окна FIR/FFT не менять без численного контрпримера. Оригинальный SAME-RX, реальный прибор, 40 исторических кандидатов и 5 диспетчеризаций остаются открытыми. PR #17 Draft; main/research не сливать ради сборки. Новые CI и Portable ожидают подтверждения, packaging выполнять в отдельной QA-ветке по точному SHA.
