# Stage111 — открытие записи и имена файлов (QA)

База d15e25a, отдельный кандидат. Не объединять в main или research ради сборки.

- Оконная сборка и модуль Python принимают один BIN, TSXML или ZIP Native как аргумент; запуск без аргумента и самопроверка встроенного FIR не изменили назначение. Путь со пробелами передаётся одним аргументом. Перетаскивание одного локального файла ведёт в ту же проверенную загрузку. Не принимать веб-ссылки и множественный drop; при активной записи архив не заменяется.
- Автоматически найти пару с разным регистром только расширений. Основное имя, номер канала, обязательные метаданные и размеры по-прежнему проверяются. При конфликте BIN программа не выбирает случайный. В операторском режиме два поддерживаемых имени TSXML допустимы только при полных побайтово одинаковых файлах; разные или неоднозначные метаданные отклоняются. Строгий программный импорт требует единственный TSXML.
- Локально на Linux прошли 65 тестов, включая шесть новых сценариев. Результат не означает полную приёмку второй таблицы: активное измерение на приборе, оконный диалог и остальные UI-сценарии всё ещё проверяются отдельно.
