# Stage 82 — офлайн-инструмент сравнения BIN/TSXML и кандидатной FFT

Дата: 2026-10-28. Возврат к основному исследовательскому пути MVKView. Приложенный ранее внешний клон используется **только как информационный источник**; его код и недоказанные утверждения не интегрированы.

## Проверка источников
В текущей рабочей среде присутствуют `Projects.7z`, извлечённые `_Unit115.pas` и `_Unit128.pas`, база `mvkview.idp`. Файла `mvkview.exe` нет. Поиск в доступных PAS не дал тела помощника `0x00447DB8`: его основание логарифма остаётся открытым, `log10` — гипотеза.

## Реализовано
- `tools/research/stage82_archive_fft_candidate.py` — **offline-only** чтение BIN с необязательным TSXML: тип Single (float32 little endian) или Byte, частота из `ChannelFrequency`/`FrequencyPerChannel`, метаданные `InternalChannelGain`.
- По умолчанию множитель `InternalChannelGain` **не применяется повторно**. Экспериментальный `--apply-gain` предусмотрен лишь для тестов ветви, описанной в Stage80c; его нельзя безусловно включать для архивов MVKView.
- Для одного окна реализованы периодический Hann с RMS нормировкой Stage81c, кандидат `|FFT|²` и расчёт кандидатов mode 1 и log mode 0. Вывод CSV содержит частоту, линейную амплитуду, гипотетический dB и мощность.
- Ограничение `N`: степень двойки и не более 262144. Программный код не содержит сетевых операций, не запускает прибор и не модифицирует входной BIN.
- `tools/research/stage82_archive_fft_selftest.py` создаёт временный синтетический BIN+TSXML, проверяет частоту, gain-политику, частоту пика, нулевой спектр. **Тест добавлен как воспроизводимое средство; независимый CI-прогон именно этого файла пока не зафиксирован.**

## Границы
Это **кандидатный инструмент для будущей сравнительной регрессии**, не полная модель всех режимов и не «готовая FFT MVKView». NumPy FFT не гарантирует float32 побитовую эквивалентность `TDSXFastFourier`, log10 не доказан оригинальным телом `0x00447DB8`; политика Byte и тракт огибающей требуют отдельного исследования. CSV-экспорт инструмента не равен исходным TABLE/VALUES и не выдаётся за них.

## Минимальные команды (без сети)
`python tools/research/stage82_archive_fft_selftest.py`

`python tools/research/stage82_archive_fft_candidate.py --bin /secure/measurement.bin --tsxml /secure/measurement.bin.tsxml --n 8192 --out /secure/stage82_spectrum.csv`

Для исходных данных используйте защищённую локальную папку. Никакие промышленные файлы и IP не публиковать.

## Stage83 — следующий шаг
1. Получить **одну** настоящую пару BIN+TSXML и эталонный спектр оригинальной MVKView, измеренные в одной сессии, желательно при известных длине FFT, окне, единицах, диапазоне и канале; в противном случае сравнение помечать как несинхронное.
2. Добавить сравнитель для общего набора частотных точек с ошибками частоты, пиков и уровней, без подгонки коэффициентов к эталону.
3. Если доступен оригинальный EXE, дизассемблировать только участок `0x00447DB8` и проверить основание логарифма.
4. Отдельно проверить Byte/Single TSXML и границы физического усиления.
5. Запустить воспроизводимые тесты, фиксировать команды и результаты. Не менять стабильную v0.3.40 и не подключаться к приборам.
