# Stage 81c — точная нормировка окна и частотный множитель (2026-10-28)

**Тип проверки:** офлайн, оригинальный IDR `_Unit115.pas` из `Projects.7z`; 6/6 структурных групп PASS. Независимые синтетические численные тесты также PASS. Реальные BIN/TSXML и эталонные спектры MVKView **ещё не сравнивались**.

## Окно (0x008C1064)
По x87-командам `Cos`, `fld1`, `fsubrp`, `Sqrt`, `fdivrp` восстанавливается таблица `w[j]=(1-cos(2*pi*j/262144))/sqrt(1.5)`. Перед `Sqrt` передаётся 80-битная константа с экспонентой `3FFF` и мантиссой `C000000000000000` — это **1.5**. Таким образом, используется периодическое окно Ханна с **RMS-нормировкой**, а не стандартное `(1-cos)/2`. Таблица состоит из 262144 `float32` значений.

В `0x007D1FE8` коэффициенты выбираются индексами `j=i*(262144//N)`, умножаются на входные `float32`, после `TDSXFastFourier.fft` сохраняется `Re²+Im²` для первых `N/2` частотных ячеек. Для всех N, делящих 262144 (256,1024,8192,262144), синтетическая проверка `mean(w²)=1` прошла (отклонение менее 1e-10). Это **не** доказывает идентичность с алгоритмом FFT внутри библиотеки.

## Частотное преобразование (0x007D2164)
Входной массив мощности: `P[0]=0`, `P[k] *= (159.154943091895*(fs/N)/k)^2` при `k>=1`. Константа приближённо равна `1000/(2*pi)`, поэтому формула эквивалентна `P[k]*(1000/(2*pi*k*df))²`, где `df=fs/N`. В режимах 2 и 3 `GetSpectrum` применяет преобразование соответственно один и два раза. Синтетическая проверка степеней 2 и 4 прошла. Интерпретация физической величины (скорость/перемещение) и итоговые единицы требуют дополнительного подтверждения.

## Важно
Окно нормировано по **энергии (RMS)**, не по когерентной амплитуде синусоиды. Прямое сравнение высоты пиков без учёта этого различия некорректно. Проверка `Stage81b` ранее охватывала только наличие опор; нынешняя проверка уточняет точную константу x87 и формулу. Нет ещё подтверждения backend `TDSXFastFourier.fft`, логарифмической шкалы, обработки начальных бинов и численной эквивалентности.

Скрипты: `tools/research/stage81c_verify_idr.py`, `tools/research/stage81c_numeric_selftest.py`; оба не обращаются к приборам.
