# Stage 44 — окно спектра MVKView

Дата: 2026-10-28. Источник: `_Unit115.pas` (экспорт IDR), процедура `0x008C1064–0x008C10C9`, применение по `0x007D2044–0x007D207E`.

**Подтверждённая формула:** `w[i]=(1-cos(2*pi*i/262144))/sqrt(1.5)`. Таблица 262144 вещественных коэффициентов Single. При FFT длины N оригинал выбирает таблицу с шагом `262144/N`. Для размеров N, делящих 262144, получается `w_N[i]=(1-cos(2*pi*i/N))/sqrt(1.5)`. Это периодический Hann, **RMS-нормированный**. Десятибайтовая x87-константа `3FFF C0000000 00000000` соответствует **1.5**, не 2.

Средний коэффициент `sqrt(2/3)` ≈ 0.81649658, среднеквадратичный — 1; максимум `2/sqrt(1.5)` ≈ 1.63299316. Локальная проверка float32 для N=512,2048,8192,32768,65536,262144 прошла 6/6. Числовое совпадение с UI оригинальной MVKView, компенсация амплитуды, особенности DC/Nyquist и расчёт ВУ/ВС/ВП всё ещё требуют отдельной проверки. Не вносить эти выводы в production без регрессии.
