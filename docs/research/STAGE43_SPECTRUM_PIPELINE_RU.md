# Stage 43 — спектральный тракт MVKView (2026-10-28)

Основание: экспорт IDR, `_Unit115.pas`; **9/9 проверенных адресных маркеров**. Полный локальный отчёт в архиве `MVKVIEW_STAGE43_SPECTRUM_PIPELINE_20261028.zip`.

## Машинный код
1. `GetSpectrum` `0x007D13D4`: N>0 и N<=262144 (`0x007D1404`), проверка наличия данных.
2. `0x007D2228` вызывается по `0x007D14A5` для получения отсчётов.
3. `0x007D2344` вызывается по `0x007D14B3`: вычисляет среднее и **вычитает DC** из каждого отсчёта (`0x007D2387`).
4. `0x007D1FE8` (`0x007D1546`) создаёт объект FFT. Перед FFT умножает отсчёты на таблицу коэффициентов `gvar_0096DA48` с индексным шагом `262144/N` (`0x007D2065`).
5. Вызывает `TDSXFastFourier.fft` (`0x007D2083`), сохраняет **Re²+Im²**, а не готовый модуль, для первых N/2 спектральных значений.
6. `GetSpectrum` выполняет дополнительную обработку результата по выбранному режиму: ветви `0x007D15DD`, `0x007D1652`, `0x007D16A7`, `0x007D1731`. Для двух ветвей видна операция `sqrt(power/2)` и масштабирование `FRange/(N/2)`; логарифмическая ветвь использует `10*log10`. Точное соответствие ВУ/ВС/ВП ещё исследуется.

## Следствия и ограничения
- **Оригинальная MVKView сама вычисляет FFT**, помимо отображения приборных расчётных показателей.
- При fs=65536 и ограничении локального N<=262144 минимальный шаг её `GetSpectrum` равен 0.25 Гц. Ранее применявшийся офлайн FFT N=1048576 и 0.0625 Гц нельзя автоматически выдавать за режим оригинальной программы.
- Название и формула окна, правила нормировки и преобразования физических величин ещё не восстановлены до уровня численного теста.
- Работа офлайн; команды прибору не отправлялись, production v0.3.40 не менялась.
