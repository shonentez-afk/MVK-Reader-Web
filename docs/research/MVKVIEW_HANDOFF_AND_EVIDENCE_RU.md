# MVKView — контроль преемственности и исследовательская карта

## Назначение
Реверс-инжиниринг настольной Delphi MVKView для совместимости независимого MVK Reader Web с прибором МВК01. Не путать с восстановлением исходных прав разработчика. Все операции с прибором, способные изменить настройки, **пока запрещены в тестовом клиенте**.

## Исходники и артефакты (ресурсы проекта, не загружать в публичный GitHub)
- `mvkview.exe` — оригинальный PE32 Delphi; `Projects.7z` — экспорт IDR; `mvkview.idp` — база IDR.
- `DefaultConfig.txt` — карта конфигурации; XML приложения; PCAPNG №83, №84, `1111(1).pcapng`; BIN и TSV/CSV для проверки.
- Декомпилятор IDR и исходники undelphi доступны локально; Rust 1.99.1 установлен, но сборку undelphi блокируют отсутствующие зависимости Cargo.
- Локальные архивы Stage 25–42 содержат отчёты, адресные таблицы, методы проверки и отрывки IDR, не предназначенные для публичной загрузки.

## Техническая карта
1. Transport: TCP/10230, little-endian, `T:u32,L:u32,payload`; `8<=L<=131072`, кратно 4. Прибор посылает данные непрерывно.
2. Incoming: `0xFF800ADC` (8 АЦП), `0xFF8001AC` (2 тахо), `0xFF800C0D` (структурированные записи). Подтипы различать по вложенным ID/длине, а не только по внешнему маркеру.
3. Outgoing: короткие управляющие команды через `TMVKThread.QueueCommand`; изменение частоты `Addr=0x000E`; отдельные блоки конфигурации. Не включать посылку команд при обычном чтении.
4. UI: формы, события и базовые адреса из Stage 25–26.
5. DSP: различать приборные готовые значения и **локальную** FFT MVKView через `GetSpectrum`, `TBackgroundProcessThread` (Stage 41); FFT-ядро `TDSXFastFourier` (Stage 42).
6. Quality: прибор №84 АЦП4 **исключён** из проверки точности из-за помех. Проверочные ADC: №83/АЦП4 и №84/АЦП1,3,6. НЧ 0.8–2 Гц пока не подгонять без новых данных.
