Проверки: полный N/2 Float32, текущий проверенный файл SHA, канал, индексы исходного окна, SHA исходных отсчётов, FFT N/Tag, EnvelopeCode, исходный домен/FRange Single, физическая частота исходного BIN, частота выхода FIR и непрореженная частотная сетка. При отличии источника — отказ, при отличии отдельного бина — НЕ PASS с номером бина и ULP. Данные графика, источник, прибор и файловая система не изменяются.

На PageSpectrum в отдельной исследовательской панели добавлены кнопка «Сверить этот спектр с оригиналом…» и текст исхода. Выбираются локальные x32dbg JSON + SHA-валидированные Power/Y и отдельный JSON-аттестат оператора для того же RAW окна. Для огибающей нужен локальный исходный IDP. Выбор другого FFT/режима/файла сбрасывает результат; только масштаб X/Y не меняет численное сравнение.

В GitHub нет приватных IDP/BIN/PNG/сигналов. В CI используется исключительно синтетика, включая все четыре режима, Mode20/FIR, негативные сценарии, Qt кнопку, 0 ULP и сброс stale-состояния.
