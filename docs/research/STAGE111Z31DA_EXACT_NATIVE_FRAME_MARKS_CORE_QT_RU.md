# Stage111Z31DA — фиксация начала/конца локальной записи на границе кадра Go

Дата: 16 ноября 2026. Исходник оператора: приватные `Projects.7z` 
(`_Unit125.pas`, `_Unit128.pas`), `mvkview.idp` и source DFM.
Не включать эти файлы, исходные captures, скриншоты или сетевые адреса в публичный репозиторий.

## Причина исправления

В принятом CZ две исходные кнопки `bWriteAdc`/`bWriteValues`
работали через SourceWriteLedger по последнему проверенному JSON-статусу,
который Go Native R6.1 публиковал с интервалом не меньше 750 мс,
а окно Qt опрашивало примерно каждые 900 мс. Хотя данные в конце
копировались из проверенного ZIP, граница интервала могла отличаться
от реального состояния входящего TCP-потока.

## Новая граница: ближайший полный кадр исходного протокола

- Кнопка Qt записывает атомарный **локальный** файл
  `<approved_run_root>/.mvk_frame_marks_inbox/0001.json`,
  затем `0002.json` и т.д. До 64 запросов, один `session_id`,
  маски `10/43/73`, типы `data_begin/end`, `values_begin/end`.
  Новая очередь не находится в приборе, не вызывает исходную
  `TMVKThread.QueueCommand` и не формирует сетевой пакет.
- Единственный разрешённый TCP/10230 Go-приёмник при очередном
  `ProcessChunk`, в котором `Framer.Feed` уже восстановил хотя бы один
  полный пакет, забирает ожидающие запросы строго по порядку
  **до обработки первого полного кадра этого read batch**. Он фиксирует
  в записи `FramesDecoded`, `Aux4700` и 10 точных счётчиков исходных
  Float32-отсчётов. Это граница декодированного *application frame*,
  не искусственная проекция прежнего статусного счётчика.
- После `Finalize` при наличии запросов Go сохраняет
  `SOURCE_FRAME_MARKS_NATIVE.json` в исходный диагностический каталог;
  записывает его SHA-256 и число запросов в `summary.json`. Без
  запросов файл и дополнительные поля **не создаются** — исторический
  формат остаётся совместимым. В диагностический ZIP попадает журнал
  границ, но экспорт 8 ADC/TACH BIN/TSXML не меняется.
- Python проверяет SHA файла границ против `summary.json`,
  `source_raw_sha256` против самого независимо принятого Native ZIP,
  точный `session_id`, размер и последовательность каждого запроса,
  неизменность исходных 10+43+73 масок, отсутствие аппаратных команд,
  монотонность кадров, AUX и отсчётов, все подтверждённые begin/end.
  Только затем заменяет прежние приблизительные границы в
  `OriginalLiveWriteLedger` на авторитетные значения Go и создаёт
  новую директорию `LOCAL_SOURCE_WRITE_WINDOWS_NATIVE`. Пропуск
  ACK/потеря кадров, повреждение JSON, новая сессия или отсутствие
  завершающего кадра запрещают экспорт — **без возврата к ~900 мс**.
- Для независимых синтетических тестов без физического Go и для старого
  локального режима CZ сохранён явно обозначенный `LEGACY_STATUS_POLL`.
  В настоящем режиме работы новой Windows сборки он не является
  допустимым fallback.

## Ограничения, которые нельзя скрывать

Граница — перед следующим завершённым кадром, поступившим **после
обработки локального запроса Go**, а не точный момент нажатия мыши
и не временная метка внутри пакета прибора. Из-за задержек GUI, файловой
системы, TCP и буферизации Go возможна небольшая задержка применения;
для точного Win32 Delphi 20-ms и SourceWriteData нужен другой отдельный
паритетный тест. Несколько запросов до одного кадра имеют одну общую
границу, но сохраняют порядок.

Original `TMVKThread.WriteDataStage`, `WriteValuesStage` и маски
проанализированы, но исходные **приборные** QueueCommand/SetRate остаются
неактивными: source `MvkSampleRate=309` — внутренний код;
таблица из пяти пунктов оригинального `gvar_008D2F7C` всё ещё требует
проверки, пять принимаемых Go частот НЕ считаются автоматически этими
исходными пятью кодами. Никаких WriteData/WriteValues/SetRate/Modbus
пакетов на МВК не отправляется, полный Go RAW пишется независимо.

## Приёмка

Go: синтетические complete-frame boundaries, TACH, отсутствие запросов,
повреждённые запросы, отказ от незавершённых запросов без новых кадров,
SHA-256. Python Core: независимый ZIP/summary/AUDIT SAME-RAW SHA,
разное число отсчётов между прошлым статусом и реальной кадр-границей,
маски, foreign-run, rollback, отказ без новых выходных каталогов.
Qt: настоящие кнопки pnMeasure при 100% и 150% DPI, запись в локальный
inbox без устройства. Тесты не содержат частных промышленных данных.
