# Аудит двух RAW-потоков МВК01 — 2026-10-26

## Метод
Офлайн-анализ записей пассивного теста без обращения к приборам. Искались маркеры `dc0a80ff`, проверялась длина блока 1052, канал (uint32 LE по смещению +20), счётчик отсчётов (uint32 LE по смещению +12). Отсчёты начинаются со смещения +28: 256 float32 LE.

| Параметр | Прибор A | Прибор B |
|---|---:|---:|
| RAW байт | 27874004 | 27862260 |
| Валидных блоков по 1052 байта | 24554 | 24544 |
| Каналов обнаружено | 8/8 | 8/8 |
| Неправильных шагов счётчика среди соседних блоков одного канала (ожидается +256) | 0 | 0 |
| Первый маркер на байте | 33064 | 33064 |
| Интервал 1052 между соседними маркерами (количество) | 21474 | 21466 |
| Интервал 1664 (количество) | 3043 | 3041 |

### Количество блоков по каналам (1–8)

- Прибор A: 3069, 3069, 3069, 3069, 3070, 3070, 3069, 3069.
- Прибор B: 3068, 3068, 3068, 3068, 3068, 3068, 3068, 3068.

## Проверенные выводы
1. Все восемь каналов присутствуют и имеют устойчиво последовательные счётчики с шагом 256.
2. Потери **по счётчикам внутри каждого канала** в данном 12-секундном наблюдении не выявлены.
3. Поток содержит другие сегменты между блоками: расстояния 1664, 6440, 2492, 3104 и начальные 33064 байта. Не следует автоматически считать их пропусками сигнала.
4. Снято ограничение о необходимости обязательной прикладной команды старта потока: отдельный пассивный тест подтвердил автоматическую передачу после TCP connect.

## Ограничения
Не доказаны корректность физической амплитуды, применённая калибровка, точность временных меток и семантика всех вспомогательных пакетов. Этот тест — проверка структуры и непрерывности **зафиксированного** потока, не интеграционный запуск программы. Исходные RAW и PCAPNG не добавлены в репозиторий.

Автономный воспроизводимый скрипт: `tools/raw_offline_audit/audit_raw.py`.
