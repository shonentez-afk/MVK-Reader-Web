# Диагностика МВК01: session.json и сопоставление с PCAPNG

В Windows BAT-пакете `MVK01_DIAGNOSTIC_WINDOWS_BAT_SESSION_LOG_20261026.zip` добавлена запись метаданных каждого сеанса. Пакет выдан пользователю отдельно; содержимое ZIP не является релизом MVK Reader Web.

На каждую запись создаются четыре файла: `capture.raw`, `recv_times.csv`, `summary.json` и новый `session.json`.

`session.json` фиксирует UTC-время начала попытки соединения, установления TCP, первого и последнего полученного блока, закрытия сокета, фактические локальный и удалённый IP/порты, число блоков/байт, SHA256 и ошибку при неуспехе. Даже при ошибке подключения создаётся отчет.

`recv_times.csv` дополнен временем получения каждого блока в UTC. Это время вызова recv на клиенте, не точная временная метка пакета в сети. Для синхронизации PCAPNG и RAW лучше записывать Wireshark на том же ПК, начав захват перед подключением и завершив после отключения.

Новые тесты пакета: 5/5 PASS, включая симулированную ошибку TCP; формат архива проверен. Реального подключения к устройству во время этой проверки нет. Базовая v0.3.40 не затрагивалась.
