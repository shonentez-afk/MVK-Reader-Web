# Stage 10 — испытательный веб-Collector (26.10.2026)

В отдельном ZIP `MVK01_STAGE10_WEB_COLLECTOR_TEST_20261026.zip` подготовлен автономный Python 3 сервер на `127.0.0.1:8765` со случайным токеном входа, HTML-панелью и поддержкой приборов №83 и №84. Данная версия **не импортируется в production**, MVK Reader Web v0.3.40 не менялась.

## Функции
- Прибор 83/84; источник реальный TCP/10230 либо существующий RAW для симуляции.
- Режим «Запись»: RAM-процессинг, SQLite для графиков, AUX4700 и событий, без RAW; экспорт завершённого сеанса ZIP с `session.json` и SQLite.
- Режим «Реальное время»: обновление графика и состояний АЦП, без сохранения SQLite.
- Кнопка остановки, интервал 2–600 секунд, автоматическое закрытие TCP сокета, ограничение одного активного сеанса, явное подтверждение сетевого подключения.
- Журнал событий, графики СКЗ, числовые показатели, диагностические биты и каталог сеансов.
- Остановку посреди неполного TCP кадра отличает от настоящей ошибки формата (частичный последний кадр отбрасывается при штатном stop/time-limit).
- Локальное прослушивание web-сервера, токен доступа, контроль Origin для POST, белый список приборов; нет веб-доступа с других машин.

## Проверки
- 50/50 unittest PASS, включая HTTP auth/safety и тесты из Stage1–9.
- Реальная офлайн RAW №84 (часть файла): state complete, 17 600 кадров, 56 графиков, 96 метрик, SQLite 466944 байт, создан только processed.sqlite и session.json.
- Ни одно реальное TCP-подключение из нового web-Collector не выполнялось. Нет гарантии промышленной надёжности. Нет автоматической записи PCAPNG.

## План выездного тестирования
Последовательно: №83 запись 30 с → №83 повторная запись → №83 Live → №84 запись 30 с → №84 Live → ручная остановка → отдельная проверка повторного подключения MVKView. Проверять времена UTC, отсутствие RAW, целостность БД, диагностические ADC7/8 №84 (0x400), распределение AUX4700, счетчики ADC и работоспособность после переподключения. Не запускать MVKView параллельно тестовому TCP.

## Ограничения
Проверка оборудования ещё впереди; UI не показывает детальную архивную спектрограмму после перезапуска; относительное время из sample_counter не означает UTC; no production TLS/multiuser auth; возможна разница между прерыванием TCP и нормальным stop. Не оставлять программу работающей без контроля на промышленном оборудовании.
