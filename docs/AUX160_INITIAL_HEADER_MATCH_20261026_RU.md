# Сопоставление постоянных полей AUX160 с начальным заголовком

В двух офлайн-записях проверены по 12 кадров на восемь каналов. Поля AUX160 +40, +56, +72, +88 соответствуют смещениям 17296, 17312, 17328, 17344 в заголовке VAST_MVK с шагом 1024 байта на канал (индекс 0–7).

Результат побайтовой проверки: устройство A — 384 из 384 совпадений, устройство B — 384 из 384. Всего 768/768, несовпадений 0. Из них 288 ненулевых сравнений на устройстве A, остальные — нулевые поля.

АЦП4 устройства A: +40=4.6668158, +56=4.6520534, +72=0.3638401, +88=7.9638128. Предыдущая публикация величины 4.1746297 для АЦП4 +88 противоречит короткому RAW и требует перепроверки длинного файла.

Это подтверждает происхождение полей, но не их физическое значение. Независимые уставки или сохранённые опорные величины пока не установлены. Скрипт: tools/raw_offline_audit/verify_aux160_header_fields.py. Работа только офлайн, основная программа не изменялась.
