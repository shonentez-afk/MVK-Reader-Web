## Восстановленный поток измерений
- TCP/10230, 8 АЦП, 256 отсчётов float32 LE в 1052-байтном кадре; отдельные тахоканалы.
- FC03/Modbus на TCP/502 читает по каналу готовый коэффициент `A+0x0E`, чувствительность `A+0x02` и калибровку АЦП `0x0020`. Базовое соотношение: `accel = raw_tcp * K`. BIN содержит уже масштабированный сигнал.
- IP .83 ↔ `MVK00000050`; IP .84 ↔ `MVK00000043`, подтверждено серийными строками в захвате.
- Live-коэффициент FRange из `+0x0E` (Stage 52). Archive с TSXML предпочитает `InternalChannelGain`, при необходимости fallback к calibration/sensitivity (Stage 62).
- Производительский протокол v1.0.39 — опорная карта Modbus, не описание проприетарного TCP/10230.
- AUX4700 содержит восемь × 144 f32 расчётных величин + статус, адреса `0x2000+0x200*N`; 160-байтные сообщения содержат 8×16-байтных состояний контроля, код зоны в младшем байте `0,0x11..0x15`, события в битах 9–11.
- На приборе .84 канальные 128-байтные блоки состояний нулевые; измерение АЦП продолжается. Значения TABLE и PCAPNG из разных дат не считать синхронными (Stage 59).
