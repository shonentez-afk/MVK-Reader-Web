# Численный анализ сообщений 4700 байт (2026-10-26)

Исходники: два RAW пассивных тестов, обработанные **локально, офлайн**, без подключения к прибору. В Git не загружаются.

## Подтверждённые факты

- Оба RAW содержат по **24** сообщения длиной 4700 байт с маркером `0d0c80ff`.
- Поле +20 (`uint32 LE`) между соседними такими сообщениями увеличивается на **130**; поле +24 равно **8**, поле +28 равно **19013632**.
- Байты +32..+4699 дают ровно **1167 float32 little-endian** (4700 - 32 = 4668; 4668 / 4 = 1167).
- Значения в основном конечны и неотрицательны, многие позиции — устойчивые нули.
- Начиная с приблизительно 48-го float32 наблюдаются многочисленные **повторяющиеся тройки значений** и группы нулевых разделителей. Эти закономерности встречаются в обеих записях.
- Значения отличаются у двух устройств и между последовательными кадрами, то есть пакет не является постоянной конфигурацией.
- В первом кадре прибора B первый float32 равен приблизительно 10.5782, а прибора A — 0.072286; это показывает устройство-зависимые расчётные данные, но пока не раскрывает физическое значение.
- В некоторых позициях прибора A значения достигают приблизительно 36293.7, а B — 122.73; запрещено без расшифровки трактовать это как вибрацию в физических единицах.

## Рабочая гипотеза
**Вероятнее массив расчётных показателей, чем один классический FFT-спектр**: много повторяющихся 3-компонентных троек, заполненные и нулевые зоны, короткая фиксированная длина при наличии восьми каналов. Это гипотеза, не декодирование метрических полей.

## Критерии подтверждения
1. Проверить периодичность и границы групп в 1167 float32, сопоставить со схемой данных Modbus и документированными диапазонами/СКЗ.
2. По времени сопоставить каждый 4700-байтовый кадр с АЦП блоками и вычислить независимые FFT/RMS для окон вокруг его появления.
3. Проверить, какие поля масштабируются с Modbus калибровкой, какие представляют частоты, и есть ли фиксированная схема из 8 сегментов.
4. Только после подтверждения зафиксировать формальную структуру декодера с тестовыми фикстурами.
