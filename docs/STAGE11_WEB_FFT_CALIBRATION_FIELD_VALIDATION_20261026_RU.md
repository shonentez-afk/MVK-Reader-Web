# MVK Stage 11: веб-Collector с независимым FFT и расширенным отчётом — 26.10.2026

Подготовлен самостоятельный испытательный пакет `MVK01_STAGE11_WEB_FFT_FIELD_TEST_20261026.zip`. Код автономен от основной версии Reader Web v0.3.40, она не менялась. Реального подключения этой сборкой ещё не выполнялось.

## Изменения относительно Stage 10

- Добавлен `spectrum_validation.py` (требуется NumPy). На каждое оконное содержимое ADC выполняется умножение сырого сигнала на индивидуальный `raw_to_acceleration_gain`, удаление DC, Hann, `rfft` с поправкой coherent gain, перевод синусоидальной амплитуды в RMS, отдельные оценки ускорения м/с², скорости мм/с и перемещения мкм путём частотного интегрирования.
- Сохраняется таблица SQLite `fft` с параметрами расчёта, FFT-полосами 5 Гц до 3000 Гц; краткие FFT-графики — в веб-интерфейсе отдельно от трендов.
- Исходные AUX4700 показатели хранятся как получены от прибора. **Частотные и амплитудные шкалы 43 полос AUX4700 ещё не сопоставлены с независимым FFT**: прямое относительное отклонение по индексу полосы не выводится как установленная истина.
- `session.json` дополнен: `received_sha256`, `socket_reads`, калибровкой восьми АЦП, FFT-схемой, флагами неисправностей по каналам, числами сохранённых спектров, ошибками и причинами остановки.
- Обычный режим не создаёт и не удаляет файлы RAW; в Session ZIP только обработанная SQLite и метаданные.
- Проверка по ранее записанному RAW прибора №84: 48 строк graph, 48 строк fft, 80–88 строк metrics (в зависимости от числа обработанных кадров при ограничении продолжительности симуляции); 8 строк calibration, integrity_check=ok, RAW в каталоге результатов нет.
- 54/54 автоматических теста PASS: старые 50 + 4 новых FFT (известная синусоида, коэффициент, интегрирование, NaN).

## Матрица выездных испытаний

1. Симуляция локальной RAW для проверки UI и таблицы FFT без подключения к прибору.
2. Два последовательных 30-секундных TCP-сеанса на №83: калибровка при каждом connect, соединение, отключение, сравнение gain и графиков.
3. Live №83 отдельно, без истории; затем запись №84 30 с, диагностика 0x400 на АЦП7/8; Live №84 отдельно.
4. Управляемая ручная остановка №83, освобождение соединения и проверка нового подключения.
5. После каждого сеанса штатная MVKView подключается **последовательно**, не параллельно.
6. Для каждого теста экспорт ZIP: session.json + processed.sqlite; при аномалиях отдельно короткий PCAPNG. Записать версии, интерфейс и адрес, UTC timestamps, received SHA256, frame counts, ADC discontinuities, status distribution, калибровку, FFT peak Hz, FFT RMS/velocity/displacement, AUX4700 original candidate metrics, длительность, размер БД, целостность, outcome.
7. Перед полевым испытанием — убедиться, что NumPy установлен и свободного места достаточно.

## Ограничения

- Реальный TCP Stage 11 **не проверен**, лабораторная регрессия выполнена только на архивных записях.
- Отметки UTC — системное время подключения/приёма, **не device timestamps**.
- FFT coherent gain подходит для сопоставления амплитуды синусоиды по линии, но не равен PSD и не строго сохраняет энергетическую нормировку для широкополосного шума; при интегрировании скорости/перемещения на низких частотах требуется дальнейшее обоснование фильтров.
- Произвольный пересчёт после завершения RAW-независимой записи невозможен.
- При аварийном отключении питания до записи итогового session.json часть метаданных может отсутствовать. Следующее улучшение — запись промежуточного журналируемого статуса.
- Сохранение каждого FFT 5-Гц полосами увеличивает объём БД, нужна политика удержания и сжатие.

Полевая матрица приложена как `FIELD_TEST_CHECKLIST_RU.md`.
