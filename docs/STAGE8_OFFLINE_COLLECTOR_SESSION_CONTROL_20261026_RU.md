# Stage 8 — управляемый офлайн Collector (2026-10-26)

Реализован и протестирован в отдельном архиве `MVK01_STAGE8_OFFLINE_COLLECTOR_20261026.zip` (полные исходники поставлены пользователю отдельно; production-ветка приложения не изменена).

## Архитектура
- Команда `record` обрабатывает доступный RAW-файл в памяти, сохраняет только графики/спектры/диагностику в SQLite, каталог сеансов с состояниями `recording/complete/interrupted/failed`, без создания копий RAW.
- Команда `realtime` полностью независима от записи: выполняет офлайн-просмотр и не создаёт SQLite/историю. Это **пока не live TCP UI**, а имитация на архиве.
- Папка-замок не допускает одновременного старта двух сеансов в одном каталоге; не снимается при аварийном падении автоматически.
- `--stop-file` обеспечивает кооперативное досрочное завершение на границе кадра: статус `interrupted`, никогда не `complete`.
- Оригинальные архивы пользователя остаются неизменными. Для настоящего TCP-Collector требуется отдельная реализация.

## Проверки
- 41/41 unittest PASS, включая шесть новых тестов Stage8.
- Реальный №84 короткий RAW: 33902 кадра: ADC24544, TACH6134, AUX44 3067, AUX160 108, AUX4700 24, AUX76 24.
- `record`: 104 графических записи, 192 расчётных записи, 0 пропусков счётчиков, обработанная SQLite 917504 bytes + каталог 16384 bytes, исходный RAW 27862260 bytes.
- `realtime` симуляция: 33902 кадра без SQLite, 12 выбранных AUX4700 preview-сообщений; №84 ADC7/8 status 0x400.
- Тест досрочного завершения: session state interrupted. Параллельный старт в одном root блокируется.

## Следующие технические задачи
Долгоживущий worker, запрет повреждения сессий при сбое питания, квота и свободное место, bounded fan-out без потери первичных данных, временные метки, отдельное утверждение реального подключения TCP, интеграция после проверки. Не называть Stage 8 production-ready.

**Важное требование:** «Запись» и «Реальное время» запускать отдельно; RAW автоматически не сохранять. Прежние исходные RAW никогда не удалять. `MVK Reader Web v0.3.40` не запускалась и не изменялась.
