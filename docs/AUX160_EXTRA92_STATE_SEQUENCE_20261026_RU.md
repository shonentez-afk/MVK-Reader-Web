# AUX160: исследование четвертого слова и переходов 0xC11/0xC15

Дата 2026-10-26. Прямое чтение трех RAW из предоставленного архивного набора: первый сеанс прибора A (15 с), сеанс прибора B (15 с), повторный сеанс A (30 с). Никаких соединений с приборами не открывалось.

## Наблюдения по A / ADC2 / entry 4

Четвертое поле 16-байтовой записи по абсолютному смещению AUX160 +92 нужно читать как **float32 little-endian**, сохраняя его исходные биты. Обнаружены точные целочисленные значения в формате float32: -1, 0, 1, 2, 3, 4. Это НЕ универсальное нулевое reserved-поле.

| Сеанс A1: индекс AUX160 | Дескриптор | Поле +92 (float32) |
|---:|---|---:|
| 0-8 | 0xC11 | 2,3,0,1,0,1,2,3,4 |
| 9 | 0xC15 | 0 |
| 10 | 0xC15 | -1 |
| 11-14 | 0xC15 | 0 |

| Сеанс A2: индекс AUX160 | Дескриптор | Поле +92 |
|---:|---|---:|
| 0-16 | 0xC11 | 0,1,2,3,0,0,1,2,0,1,2,0,0,1,2,3,4 |
| 17 | 0xC15 | 0 |
| 18-21 | 0xC15 | -1,0,0,-1 |
| 22 | 0xC11 | 0 |
| 23-29 | 0xC11 | 1,0,1,0,1,2,3 |

Во всех трех переходах код меняет бит 0x4. В тот же кадр опорное поле +88 становится побитово равно текущему +80. Предыдущий AUX4700 содержит идентичное текущее значение пикового фактора.

## Интерпретация и ограничения

Подтверждена поведенческая зависимость между накоплением значений +92 (до 4), переключением кода 0xC11 -> 0xC15, сбросом +92 до 0 и обновлением reference. Обратный переход 0xC15 -> 0xC11 также сопровождается обновлением reference и нулём +92.

**Гипотеза:** +92 — внутренний счётчик/элемент фильтра условий (возможно число последовательных проверок); -1 — сигнал противоположного условия. Это пока не установлено спецификацией, поэтому нельзя приписывать полю семантику задержки, секунды или тревоги.

Новый факт: четвертые слова могут быть float32 и у других записей (например, +44 содержит 0.5 или 1.0), поэтому декодер должен сохранять и исходные uint32 bits, и интерпретацию float32, а не принудительно считать их reserved uint32.

Для статуса прибора использовать отдельно документированные биты AUX4700, особенно состояние датчиков ADC7/8 на приборе B.
