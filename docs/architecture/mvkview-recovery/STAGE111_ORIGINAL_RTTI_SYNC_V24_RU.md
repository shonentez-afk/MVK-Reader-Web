# Atlas v24 — оригинальные RTTI, переключение каналов, raster и синхронизация

24.11.2026. Продолжение только исследования оригинальной MVKView. Рабочий Stage111, main, research, fix и PR #14 не изменялись. Приборные команды не отправлялись. Приватные источники и полный HTML не публикуются.

## Проверенные результаты

Проверены 133/133 SHA256 Pascal/DFM, SHA IDP, SQLite quick_check. Добавлены 13 карточек, 25 направленных связей, 194 уникальных адреса инструкций, 3 DFM места, 2 строки VMT. Суммарный overlay v22–v24: 53 карточки, 115 связей, 18 маршрутов, 20 строк VMT. Все 641 исторический candidate ID и предыдущие оценки сохранены. Это статические доказательства, не runtime parity.

- GetRawSignal: класс и его предок не имеют обычных classic method записей; метод есть в extended RTTI. Обычный MethodAddress на проверенной цепочке классов не разрешает цель. Для AddTask фонового потока аналогичное ограничение. Проверенный диапазон сохраненного образа не содержит E8/E9 кандидатов к GetRawSignal, Background.Create/AddTask; абсолютные ссылки относятся к extended RTTI. В выбранных прикладных модулях не найдены индексированные именованные reflection-вызовы проверенных helpers. Семь GetRawSignal ID по-прежнему открыты: extended RTTI, procedural variables, receiver/producer не доказаны. Отсутствие шаблона прямого CALL не равно отсутствию косвенного исполнения.
- Переключение ADC/SPEC: Sender, зеркальная установка TabIndex с временным обнулением пары OnChange Code/Data и ее последующим восстановлением. PagesChange выбирает фабрику активной страницы. Сбрасывается Count обеих серий, затем вызывается page dispatcher. Это не очистка кольцевого хранилища.
- GraphDefaultVScale: одна переменная формы для обеих фабрик. Найдены 37 обращений (16 write, 21 read). Подтверждены зависимости FRange, spectrum Type, шкалы по декадам, делители, необходимость порядка rebuild/draw. Численное x87 поведение на границах требует отдельной проверки. Интервал интерфейса настраиваемый: default 20 ms, clamp 5..1000 ms, не гарантированный реальный период.
- TCo2Draw: геометрия нормали линии, выбор dominant axis, clipping bitmap, центральный и соседние пиксели, коэффициент на основе корня расстояния, смешивание нового и старого цвета. Десять аналитических проверок формул; не запуск оригинала и не screenshot parity.
- Synchronize: пара Code/Data, очередь, monitor, событие и ожидание. WaitFor главного потока может вызвать CheckSynchronize и выполнить ожидающий callback до возврата. Normal Stop отключает timer, ждет возможный ProcessThread, переключает страницы, очищает регистры до RX join и освобождает storage после join. Реальный background producer и аварийные interleaving остаются открытыми.
