# Atlas v29 — объединение карты и жизненный цикл потоков

Дата: 24.11.2026. Только исследование и документация оригинала, без изменения production Stage111, main, PR #14, приборного обмена или заявления аппаратной совместимости.

## Результат

- Приватная полная карта v27 объединена с дополнением v28 и новыми результатами v29. Исторические 641 candidate ID и исходный интерфейс сохранены, базовая карта обратима побайтно.
- 177 карточек, 48 маршрутов, 324 отображаемых ребра (это не число уникальных CALL). Перенесены 26 функциональных карточек и 34 отношения v28; добавлены 18 карточек, 6 маршрутов и 48 отображаемых связей v29.
- Подтверждены общее наследование трёх классов потоков, 12 VMT ячеек и фактические машинные цели базового конструктора. Выявлено различие Terminate / WaitFor / Free и исходная логика OnTerminate. Фактическое назначение callback остаётся открытым.
- Пять прямых class-cell ссылок измерительного потока, одна калибровочного; producer фонового потока не подтверждён. Для пяти ранее открытых методов проверены extended RTTI metadata и ограниченный поиск прямых ссылок. 40 исторических кандидатов (22 SetAddr, 11 GetDwordRaw, 7 GetRawSignal) остаются caller-open. RTTI metadata не доказывает Invoke, receiver или отсутствие других вызовов.
- Разграничены normal и exception lifecycle конфигурационных Task0/3/4/5, Stop/Mode2, калибровки и FormDestroy. Возможные условные риски освобождения ресурсов не классифицируются как доказанные runtime дефекты.
- Background: Busy gate, один ожидающий task, повторное чтение выбранного канала в synchronized callback; actual producer и межпоточная активация не доказаны.

## QA

133/133 исходных файлов сверены по SHA, IDP и SQLite проверены, старые реестры не подменены. 289 статических + 497 браузерных проверок PASS, JS errors=0. Все 48 маршрутов и 324 отображаемых ребра проверены через обработчики интерфейса. file:// заблокирован браузерной политикой среды, тест выполнен загрузкой HTML в чистую about:blank. Локальный запуск на пользовательском Windows и runtime оригинала не проверены.
