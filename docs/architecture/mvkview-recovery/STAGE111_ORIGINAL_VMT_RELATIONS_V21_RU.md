# Atlas v21 — восстановление оригинальных VMT и причинно-следственных связей

24.11.2026. **Только исследование оригинальной MVKView и документационная карта.** По уточнению пользователя не продолжать исправление Stage111 в этом чате. PR #14 из v20 остаётся отдельным результатом для основного чата разработки. Main, research, fix-ветка и приборный обмен в v21 не изменены.

## Источники и масштаб

Сверены 133/133 SHA256 реконструированных файлов, SHA IDP, SQLite quick_check. В IDP найден сохранённый машинный образ; размещение подтверждено по нескольким независимым сигнатурам инструкций/данных. Проверены self-pointer, class name, method slots и машинные opcode косвенных CALL. Цели сопоставлены с SQLite и Pascal. Это не реконструированный запускаемый EXE и не runtime trace.

28 соответствий VMT, 23 уникальных места вызова, 19 уникальных целевых адресов, девять классов. 12 новых карточек маршрутов; 19 кликабельных линий. Некоторые строки отражают альтернативные классы одного места вызова или только слот таблицы. Все выводы ограничены конкретным классом и путём происхождения receiver; отсутствие подмены во время исполнения не аттестовано. Все четыре открытых VMT callsite v19 рассмотрены, не все динамические цели окончательно установлены для произвольных receivers.

## Существенные связи

- Создание TCP Client, Host/Port/Connect, стандартное создание default IOHandlerStack и публикация его в FIOHandler; точные VMT цели при соответствующем типе.
- TmpStream — объект-посредник, а не постоянная область памяти. На одном пути привязывается к буферу канала, на другом к регистровой памяти формы. Восстановлен маршрут ReadStream → ExtractToStream → stream helper → virtual Write → memory copy; SetSize и Seek разделены по слотам.
- Проверка 14 статусных ячеек после применения принятого блока PARAM (Task2), логирование изменения и кэш статусов.
- **ResultTachoImpulse не сводится к свежести одного PARAM.** При принятой порции TACH и соответствующем режиме оригинал сравнивает байты с сохранённым последним байтом канала, устанавливает индикатор изменения и сохраняет последний байт порции. При принятом триггере VALUES оба индикатора обнуляются после возможной записи строки, даже если ValuesFile отсутствует. При Freeze этот принятый путь не выполняется. Сброс при исключении writer отдельно не доказан. Точный приватный адресный маршрут сохранён локально. Это новый вопрос для основного чата разработки, не исправление Stage111.
- WriteData stage переходит в активное состояние с первого принятого ADC1; запись из FMemory не подменяется локальным FFT.
- Freeze не означает остановку TCP чтения или всего файлового менеджера. Отдельно восстановлены вход в стадии, закрытие writers и возможный TSXML.
- Mode2 Stop: Terminate, обычный выход из приёма, Disconnect/free Client, forced CloseFiles, завершение WaitFor, очистка поля формы и виртуальный destructor; последний освобождает объекты потока. Не заявлять универсальную гарантию очистки при всех исключениях.
- QGrapher: временный TCo2Draw/bitmap canvas, Font.Assign и перенос изображения; совпадающие Draw slots нескольких известных классов, не исчерпывающее доказательство всех возможных типов.

## Карта и проверка

Приватный пакет `MVK_ALIAS_V21_PRIVATE_HANDOFF.zip` продолжает v15–v19. Исторический HTML v19 сохранён побайтно за исключением добавленного раздела и названия, в том числе его исходный SVG, реестры 641/222/419 и карточки. Новые линии и узлы выполнены в прежнем визуальном стиле; нажатие открывает исходные инструкции. 35 проверок PASS, включая структурные проверки, Chromium page.set_content, переходы от линий к 12 карточкам, поиск VMT и работоспособность старых разделов; 0 JS errors. Прямое file:// открытие заблокировано политикой среды, не утверждать что оно проверено. Не публиковать исходный IDP/PAS/DFM/SQLite, приватные адресные таблицы, код извлечения или HTML.
