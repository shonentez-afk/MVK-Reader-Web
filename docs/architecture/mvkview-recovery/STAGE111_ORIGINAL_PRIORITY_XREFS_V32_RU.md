# Atlas v32 — итоговый статический проход по 8 приоритетным точкам и 40 кандидатам

24.11.2026. Только исследование оригинала. Stage111/main/research/fix/PR #14 не изменялись, команд прибору не отправлялось. Приватные адреса, исходники и граф не публикуются.

## Результат

- Все 8 приоритетных точек v31 получили статические контракты: 5 условных одиночных/штатных целей, 1 JSON target set из пяти машинных целей, 2 события с начальным nil Code/Data. Не считать это восемью фактическими runtime dispatch.
- Сверены 1737 кандидатов VMT по self/name/parent, 20 записей слотов для шести виртуальных точек, 37 именованных ссылок на Indy fields. Socket.CloseSocket связан с созданием FBinding; штатный Connected с default TIdIOHandlerStack, SetPort наследуется; Intercept и callback имеют отдельные non-nil gates. OnConnected/OnDisconnected — прямые published TMethod properties. Именованных assignment/Indy DFM components не найдено; generic RTTI/alias assignments не исключены. JSON receiver — результат lookup, не исходный TJSONObject; subtype конкретного resource value не установлен.
- Дополнительное независимое доказательство: собственные сохранённые IDR reference vectors SetAddr, GetDwordRaw, GetRawSignal имеют по одной D и нулю C. Шесть positive controls, включая GetSignal/GetSpectrum: 20 C refs совпали с E8/SQLite. У трёх методов один абсолютный указатель в extended RTTI и ноль E8/E9 в сохранённом образе. Локально перекрёстно проверенный формат ref vector, не полный парсер IDP. Не означает отсутствие косвенного исполнения.
- Все 40 исторических ID (22+11+7) сопоставлены с первоначальным writer/reader и точными инструкциями, включая 7 прежних пустых writer addresses. 0 фактических caller доказано. Writer не равен caller. Сохранить 40 как исторические гипотезы def-use, не считать обязательными runtime зависимостями и не удалять их.
- Полная карта сохраняет 641 ID и прежние версии; v31 обратим побайтно. 211 карточек, 61 маршрут, 382 семантических ребра; прямой граф v31 неизменён. 133/133 SHA Pascal/DFM, IDP SHA, SQLite quick_check; 413 static + 541 browser PASS, JS errors=0. Browser set_content; file:// не аттестован. CRC и SHA всех файлов полного приватного архива проверены.

## Граница завершения

Статический целевой проход завершён. Не повторять общий обход VCL или ещё один проход по тем же 40 кандидатам ради их формального закрытия. Фактический caller/receiver/Code/Data устанавливать только при пассивной трассировке оригинала; отсутствие hit ограничено сценариями.
