# Atlas v17 — сверка исходного каталога зависимостей

24.11.2026. Зафиксированная рабочая ревизия Stage111Z31EB: `dd020c4a8c1cd9d80440031730b7c4ee28bf8cef`.

Документ содержит только публичный итог приватного аудита, без оригинальных адресных таблиц, инструкций, пользовательских CSV или реконструированных исходников. Production, Go/TCP, main и приборный обмен не изменены.

## Результат

Пользователь передал исходный CSV Atlas v15 с 641 парой. В локальной среде повторно проверены все три приватных источника: 133/133 контрольные суммы файлов, SHA IDP, SQLite quick_check. Все 641 строки соответствуют 393 уникальным исходным инструкциям с правильными физическими владельцами, именованными полями и направлениями доступа.

Сравнение с независимой индексацией v16:
- 410 пар совпадают по функциям, полю и обеим точкам;
- 222 совпадают по функциям и полю, но используют другие точки;
- 9 исходных пар v15 не совпали по владельцу в v16; физические заголовки исходных функций подтвердили v15. При проверке всей v16 таблицы выявлены 11 строк с ошибочной атрибуцией хотя бы одной точки;
- 47 пар только в v16 сохраняются отдельно. Нельзя подменять исторические 641 строки новым счётчиком.

В локальном каталоге приняты следующие решения по **конкретным кандидатам**, а не по степени готовности приложения:

| Решение | Число |
|---|---:|
| Исключён: разные экземпляры | 88 |
| Исключён: локальная запись перекрывает значение на рассматриваемом нормальном пути | 6 |
| Статически установлен локальный маршрут с условиями | 8 |
| Условный: необходимы доказательства экземпляра/порядка | 445 |
| Не разрешён получатель или маршрут | 94 |
| Всего | 641 |

Добавлены 15 карточек доказательств и 14 дополнительных адресных отношений, не смешанных с исходным списком. В частности, различены отдельные экземпляры регистровых списков, перегрузки форматирования по ABI, указатель и содержимое регистра, границы допустимого кольцевого окна при изменении Fs, обе части 64-битной позиции, стадии файловых ресурсов и времена намерения/активации writer.
