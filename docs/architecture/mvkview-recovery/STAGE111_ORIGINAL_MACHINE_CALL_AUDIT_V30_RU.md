24.11.2026. Только документация восстановления, без изменений Stage111 и без приборных команд.

- 92 767 индексных CALL записей (92 763 уникальных места). 65 444 прежние прямые цели подтверждены, 4 исправлены, 13 354 новых прямых ребра к существующим узлам, 144 записи с точным адресом без узла. Всего 78 802 прямых записи с известным узлом, 78 946 с точной машинной целью.
- В трех основных модулях 6 911 записей: 6 486 точных прямых целей (25 из них без узла), 425 косвенных. Из последних 104 получили условные цели по declared type/DFM и VMT, 321 остаются без такой цели. Не утверждать фактический runtime dispatch.
- 40 исторических кандидатов (22 SetAddr, 11 GetDwordRaw, 7 GetRawSignal) остаются caller-open. Прямое создание BackgroundProcessThread и назначения OnTerminate не доказаны; ProcessThread инициализируется nil и очищается при Stop. Измерительный UI имеет прямые маршруты вычислений. Разобраны HideWait/ProcessMessages/CloseQuery/OnClose и 9 сценариев lifecycle; условные риски не считать подтвержденными дефектами.
- Полная приватная карта: 196 карточек, 56 маршрутов, 367 семантических отображаемых ребер. Активный граф incoming/outgoing содержит все 13 358 новых/исправленных записей. Исторические 641 ID сохранены, V29 обратим побайтно.
- QA: 133/133 SHA исходников, IDP SHA, SQLite quick_check; 237/237 static и 522/522 browser, JS errors=0. Browser set_content, file:// не проверен из-за ограничений среды. Архив проверен CRC и SHA каждого файла. EXE и прибор не запускались.

## Остаток и критерий завершения

Не повторять полный обход VCL. В приоритетном завершающем пакете исследовать 25 core address-only записей, выбирать из 321 core indirect лишь исполняемые маршруты и проверять 104 условных цели по реальному receiver. 40 кандидатов поля — отдельный реестр, не суммировать с CALL. При доступности оригинала пассивная runtime трассировка, без отправки новых команд прибору, проверка фактических caller, Background producer, OnTerminate, Stop/exception. Не закрывать статически неподтвержденные связи. Полная совместимость программы и численный паритет — отдельная приемка.
