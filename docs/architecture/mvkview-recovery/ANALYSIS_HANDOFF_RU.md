# Протокол продолжения — карта восстановления оригинальной MVKView

## Выполнено

Созданы локальный приватный IDR-граф оригинала и браузерная карта с поиском, детализацией и кандидатами сопоставления. Приватный граф **не** загружен в GitHub. В документационной ветке находятся публичный Stage111 Python AST/Go declaration анализатор, два теста и GitHub Actions workflow. Рабочая реализация desktop Stage111 не изменена.

## Границы результатов

Приватный SQLite содержит 25 404 функции, 92 767 записей вызовов, из них 65 448 разрешены до известных функций; 27 319 требуют уточнения или находятся вне индекса. Есть 7 416 `commented_stub` в реконструкции оригинала, 3 DFM-формы, 162 компонента и 95 событий. SHA256 всех 133 реконструированных исходных файлов совпал с индексом SQLite. Эти числа — **характеристики статической реконструкции**, не процент готовности Stage111.

Полный IDP RTTI/объекты и косвенные вызовы Ghidra/Dhrake пока не реконструированы. Выявленные пары оригинал/Stage111 являются кандидатами до семантической проверки. Успех синтетических тестов не является аппаратной аттестацией.

## Следующие действия

1. Получить артефакт `stage111-public-graph.json` из CI на точном SHA.
2. Локально объединить его с полным приватным графом оригинала; уточнить производственные и исследовательские пути.
3. Разобрать виртуальные вызовы, DFM, регистры, передачи данных Ghidra/Dhrake.
4. Сопоставить сценарии и алгоритмы GetSignal, GetSpectrum, GetValueText, WriteData/WriteValues, Stop, все страницы и формы.
5. Отделить реальные дефекты от областей без достаточной аппаратной верификации.
6. Сохранить подробные объяснения из старых документов при обновлении карты.

**Нельзя** отправлять команды реальному МВК01 без разрешения оператора или публиковать исходные приватные 7z/IDP/SQLite/RAW/BIN/TSXML.
