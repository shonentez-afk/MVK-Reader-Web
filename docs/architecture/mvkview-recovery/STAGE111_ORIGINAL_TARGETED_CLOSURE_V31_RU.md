24.11.2026. Только восстановление оригинальной MVKView. Рабочий код Stage111, main, research, fix и PR #14 не изменялись; приборные команды не отправлялись.

## Результат

- Сверены 133/133 SHA Pascal/DFM, IDP SHA, SQLite quick_check. Сохранены 641 исторический ID, исходный DB и прежние карты. V30 обратим побайтно.
- Все 25 адресных CALL без узла в трех основных модулях разрешены: 7 функций VCL, восстановлены машинные тела. Дополнительно те же цели для 12 записей других модулей. Всего 37 ранее индексированных прямых записей, 78 839 прямых записей с узлом из 78 946 E8. Оставшиеся 107 address-only находятся вне целевых модулей. В новых телах отдельно 15 direct edges и 10 открытых исходящих записей, не входивших в первоначальный знаменатель.
- Все 425 core indirect перепроверены по opcode/операнду. 104 прежние условные VMT цели, 11 ранее подтвержденных route VMT, 60 новых guarded receiver VMT, 4 guarded receiver sets, 1 DFM event target set (три обработчика). Всего 180 условных точек; 69 IDR annotation/class-slot only, 172 unresolved dynamic, 4 object-method pointer open. 245 остаются без доказанного receiver/target, включая 69 annotation-only. Не смешивать условные вызовы с прямыми.
- Уточнены default IOHandlerStack, Write/ReadStream, TFileStream, TRecordMemoryStream, modal/bitmap canvas, Status chart, GetTabs FSaveTabs/FTabs, Enter/OnDblClick. Normal class guards не распространяются автоматически на произвольные receiver.
- В ограниченном прямом обходе выбранных корней измерения остается 1 точка без доказанного receiver; при включении проверенных условных ребер — 8. Это частичная статическая достижимость, не runtime trace. Остальные 237 не объявлять недостижимыми в оригинале.
- 40 исторических кандидатов трех методов остаются caller-open; Background producer/OnTerminate assignment открыты. Не суммировать с CALL. Полная статическая карта достаточна для предметного сравнения с Stage111, не доказательство полной совместимости.
- 25 558 активных узлов оригинала, 203 карточки, 59 маршрутов, 375 семантических ребер. 1183/1183 static, 486/486 browser PASS, JS errors=0. Browser set_content, file:// заблокирован средой; оригинальный EXE и прибор не запускались.
