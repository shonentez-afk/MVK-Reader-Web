# Atlas v22 — оригинальная цепочка измерения, хранения и графиков

24.11.2026. Только исследование оригинальной MVKView. Рабочий Stage111, main/research/fix и приборный обмен не изменены; PR #14 не трогать в этом чате.

## Результаты

Три приватных источника повторно сверены: 133/133 SHA256 PAS/DFM, IDP SHA, SQLite quick_check. В полном историческом HTML v15 сохранены все 25 551 оригинальная функция, 65 448 resolved calls, 641 кандидат поля. Добавлены 7 маршрутов, 21 карточка, 48 направленных отношений, 301 уникальная инструкция, 8 DFM мест событий, 10 VMT соответствий (7 уникальных мест). Отношения включают причинность и условный порядок, не только прямые CALL. Приватные адреса и машинные инструкции не публикуются.

- Mode2 завершает прежний режим, создаёт восемь Float32 и два byte хранилища, по 2^21 отсчётов, отдельные ADC/Spectrum параметры каждого канала, затем Task2.
- Системная функция ThreadProc отсутствовала в Pascal/SQLite; её тело и VMT Execute/DoTerminate восстановлены из сохранённого машинного образа IDP. Обычная AfterConstruction может запускать поток до публикации его указателя в форме. Не доказанный runtime race.
- RX пишет порцию ring до Freeze, затем при условиях коммитит позицию; FRxPos публикуется двумя частями. Смена Fs инвалидирует предыдущее окно. Availability и полноценная валидность окна различны; extractor может дополнять окно нулями.
- Таймер 20 мс вызывает активный ADC/Spectrum путь непосредственно. Проверены выбранный канал, gate Fs, отдельные Params и серии, преобразование сигнала, оконная FFT/Power, шаг частоты и число отображаемых значений. Граферы независимы; установлена конкретная связь каждого PaintBox с его TControlCanvas и курсорной строкой.
- BackgroundProcessThread/AddTask существуют, но прямого producer/создания в проверенном индексе не найдено. Callback повторно вычисляет текущий выбранный канал. Не утверждать активность фонового маршрута в Mode2.
- Stop отключает таймер, ждёт возможный ProcessThread; регистровая память очищается до RX join, после join освобождаются storage slots; FormDestroy затем освобождает граферы. WaitFor главного потока может обрабатывать синхронизацию. Гонки/исключения не аттестованы. Mode1 file producer отделён от Mode2.
- Предыдущий вывод v21 по TACH accumulator/reset сохраняется.

Из 43 исходных Storage кандидатов 16 lifecycle-guarded, 11 overwrite-guarded, 4 channel/epoch-guarded, 1 mode-bound; 10 receiver/route и 1 порядок остаются открытыми. Все 641 историческая запись сохранена. Не считать 43 новых оценки доказанными runtime links.
