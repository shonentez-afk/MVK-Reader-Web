## Восстановленная цепочка
- _Unit125 00808617..0080868E, 00806964/008069AC: первый дескриптор задаёт Range и Units хранилища, включая Freeze. F32 по ADC base +0x0E, Units +0x10 (32 байта с NUL).
- _Unit115 007D23D1..007D23E1: масштабирование при приёме; 007D0CD6: прямой GetSignal; 007D0D8F/007D0DD2: нормализация и выход фильтрованного сигнала; 007D14A5: вход FFT.
- Новый домен `ORIGINAL_LIVE_ADC_LATCHED_RANGE_FLOAT32`: физические отсчёты, масштабирование один раз при записи; предыдущие отсчёты не пересчитываются. Метаданные привязаны к ADC, TCP epoch, битам Range и признакам известности. Старый домен FRange=1 сохранён для совместимости. Окна с устаревшими метаданными отклоняются.
- Python и Qt получают метаданные конкретного окна, используют правильный масштаб при FIR/FFT, а не дополнительное умножение на FRange. Модель численно допускает положительные конечные коэффициенты и заменяет ±0 на 1; неизвестные, отрицательные, NaN/Inf и переполнение не объявляются валидным физическим сигналом. RAW и запись исходных данных не изменяются. Не считать обработку исключительных значений доказанным полным эквивалентом Delphi/x87.
- Qt: метаданные графика/шкалы; представление производных единиц является кандидатом, требуется проверить порядок символов ~ / ~~ по _Unit115 007D1268 и остаточные подписи курсоров.
- _Unit125 00806A8C, 00806F93, 0080705E: TSXML при закрытии использует текущую конфигурацию, а не latched Range/Units хранилища. Независимый replay принятых PARAM и Freeze восстанавливает метаданные на границе закрытия записи. При неизвестных или небезопасных метаданных не подставляется выдуманный коэффициент. TACH: Count / Byte / 1. Старые архивы без нового журнала поддерживаются прежним путём.
