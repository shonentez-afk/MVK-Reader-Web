# Stage 13: реконструкция фиксированных полос по руководству (27.10.2026)

Источник: ВАРБ.411711.112 РЭ, приложение 1, стр. 41-44. Основа DSP: FIR-децимация 65536 до более низких частот; оконная FFT с Hann; третьоктавные весовые функции; расчет фиксированной полосы по трем энергетическим составляющим (нижняя граница, внутренняя полоса, верхняя граница).

## Реализовано
Модуль tools/mvk_fixed_band_lab/mvk_stage13_fixed_band.py (только offline):
- hann_psd: periodogram с Hann и нормировкой мощности окна;
- integrate_three_zones: раздельное суммирование PSD * энергетического веса, затем квадратный корень;
- explicit_zones: явное задание нижней / внутренней / верхней зоны с внешними коэффициентами;
- third_octave_centers и диагностическое прямоугольное суммирование третьоктавных полос, НЕ фирменные окна.
Синтетические тесты проверяют RMS синуса, правильную мощностную интерпретацию весов и обнаружение перекрытия зон. Код и команды — в tools/mvk_fixed_band_lab/README.md.

## Не реализовано, не выдумывать
Точные весовые функции окон из руководства (численные коэффициенты и переходные частоты), фирменный FIR/децимация, состав третьоктавных окон, нормировка полного DSP, буферизация/усреднение, точная методика преобразования ускорения/скорости/перемещения. Поэтому из этого каркаса пока НЕЛЬЗЯ получить доказанно сопоставимый с MVKView RMS АЦП4/6. Баттерворт 3-го порядка — только отдельная эмпирическая аппроксимация из предыдущего исследования.
