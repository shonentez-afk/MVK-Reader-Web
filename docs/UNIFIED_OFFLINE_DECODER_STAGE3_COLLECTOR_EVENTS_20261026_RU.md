# Unified MVK Decoder — Stage 3 (2026-10-26)

Создан независимый **офлайн** адаптер `collector_samples_adapter.py` с контрактом JSONL `mvk01.collector.v1`, исходный код поставляется в архиве `MVK01_UNIFIED_DECODER_STAGE3_20261026.zip`. Это **не** production Collector, сети и команд приборам в коде нет, основная v0.3.40 не менялась.

## API событий

- `calibration`: 8 коэффициентов и sample_rate_hz=65536.
- `adc_samples`: ADC 1–8, `sample_counter`, `sample_count=256`, `gain_m_s2_per_raw`, `acceleration_m_s2` (256 калиброванных отсчётов; опционально без массива по `--no-samples`).
- `aux4700`: восемь записей, float32 показатели, отдельно битовая диагностика; непроверенные поля остаются с суффиксом `candidate`.
- `aux160`: четыре 16-байтовые записи, reference, descriptor, extra float32 + uint32, без неподтверждённой семантики.
- `tach`, `aux44`, `aux76`: основные идентификаторы кадров.

Каждый кадр содержит `stream_offset`, схема событий версионирована.

## Ограничения

Файловый JSONL очень объёмен при включённых отсчётах; следующий шаг — потоковый бинарный транспорт в Collector, проверка таймштампов по sample_counter, тестирование нерегулярной сегментации и полноценная обработка потерь. Здесь нет реальных новых подключений к оборудованию. Исходники Stage 3 доступны в выдаваемом ZIP; **данный коммит содержит только отчёт**, не импорт модуля в production-ветку.
