# Первый прототип объединённого офлайн-декодера МВК01 — 2026-10-26

Собран самостоятельный Python-модуль, исходники и Windows BAT для запуска тестов доступны в прикреплённом ZIP `MVK01_UNIFIED_DECODER_OFFLINE_20261026.zip`. **Архив пока не коммитился в GitHub**, основной Reader Web v0.3.40 не изменён.

Поддержано: заголовок VAST_MVK (33064), калибровка восьми каналов, ADC1052 (8 каналов), TACH284 (2 номера каналов), AUX44/76/160/4700, статусы напряжения, изменение дескриптора/reference/extra AUX160. Поля спектра и пик-фактора помечены candidate; не утверждаем метрологически подтверждённый смысл всех полей.

## Проверки
- 5/5 синтетических unittest PASS (фрагментация 1/5/777/55000 байт, статус, повреждённый заголовок, длина и тахометр).
- Прибор A, короткий RAW: ADC 24554, TACH 6138, AUX44 3069, AUX160 108, AUX4700 24, AUX76 24, ошибок счётчика 0, хвостовых байт 0.
- Прибор B, короткий RAW: ADC 24544, TACH 6134, AUX44 3067, AUX160 108, AUX4700 24, AUX76 24, ошибок счётчика 0, хвостовых байт 0.
- Состояние у прибора B: АЦП7 и АЦП8 по 24 кадра с маской 0x400, остальные нули.
- Прибор A: АЦП1 по 24 кадра 0x800 и АЦП5 по 24 кадра 0x400.

В первых тестах обнаружена ошибка обращения к таблице типов кадров по одному magic вместо пары (magic,size); **исправлена до итоговой регрессии**. В отчёт не включены сырые записи и персональные сетевые параметры.

## Далее
