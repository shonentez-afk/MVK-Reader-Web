# Stage13 — все 8 АЦП, четыре офлайн-сеанса 83/84, 27.10.2026

## Данные и метод
Повторно использованы четыре предоставленных PCAPNG: «запись 83», «реальное время 83», «запись 84», «реальное время 84». Только офлайн-разбор. Сегменты TCP/10230 упорядочены по sequence, повторные сегменты отброшены; первые 33064 байта содержат VAST_MVK. Коэффициенты каждого канала прочитаны из заголовка: float32 LE по смещению 836 + 512*N. Из ADC кадра 1052 байта взяты 256 float32 LE; перевод в м/с2: raw*gain (калибровка подтверждалась ранее). Из расчётных кадров 4700 байт извлечены RMS ускорения по полосам 10–3000, 10–2000, 10–1000 Гц (слова 48, 51, 54 канальной записи соответственно).

Независимый расчёт: periodogram по ПОЛНОЙ записи АЦП, DC detrend, boxcar, спектральное взвешивание |HP Butterworth order3 * LP Butterworth order3|², fs 65536. Это нормативно мотивированный эквивалент, НЕ точная DSP реализация П1.4. Сравнение с **медианой** всех 4700 кадров сеанса, а не одно-в-одно выровненными внутренними измерительными окнами: статус ПРОВЕРКА НА СОГЛАСОВАННОСТЬ, НЕ метрологическая аттестация.

## Что подтверждено / чего НЕ доказали
- ПРИОРИТЕТ: ранее решённая причина ADC6 — не обрезать высокочастотный переход на 3000 Гц; нормативная АЧХ объясняет поведение. Повторные сравнения подтверждают состоятельность модели на разных приборах.
- Есть численное согласие для большинства каналов, но заметные отклонения ADC5 в «реальное время 83», ADC3/5 «запись 84»; возможно разная статистика окон и нестационарность сигнала, НЕ делаем причинного вывода без выравнивания.
- 43 спектральных поля, 4700 структура, отдельный битовый статус и индивидуальные gain уже установлены ранее. Не начинать исследования с нуля.
- НЕТ: полного P1.2/1.3/1.4 с заводскими FIR и весами; парного сравнения на точно одном и том же окне; точного знания времени генерации 4700 кадров. Нельзя объявлять 32/32 PASS.
