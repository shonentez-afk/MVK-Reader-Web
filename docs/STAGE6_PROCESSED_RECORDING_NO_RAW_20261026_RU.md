# MVK01 Stage 6 — обработанная запись без постоянного RAW

26.10.2026. По требованию пользователя архитектура разделяет **«Запись»** и **«Реальное время»**.

В режиме записи потоковые отсчёты АЦП (256 float32 на кадр) превращаются в фиксированные оконные агрегаты для графиков (min/max/mean/RMS), калибровку, метрики и диагностические статусы AUX4700, спектральные значения 43 предварительно идентифицированных полос, а также события изменения AUX160. Обработанная история — SQLite. **Повторное сохранение исходного сигнала не производится**. Исходные предоставленные пользователем RAW при офлайн-анализе остаются на месте и никогда автоматически не удаляются. В будущем live Collector должен использовать тот же RAM-only pipeline, а не сначала записывать RAW.

Отдельный скрипт `realtime_preview_offline.py` — демонстрация отображения событий без записи, на уже полученном файле; не TCP-источник.

Файлы прототипа в пользовательском пакете `MVK01_STAGE6_PROCESSED_RECORDING_20261026.zip`: `mvk_unified/record_processed.py`, `export_graphs.py`, `realtime_preview_offline.py`, тесты, BAT и инструкции. Данный коммит — **отчёт**, исходники не импортированы в production.

## Регрессия

29/29 автоматических тестов PASS. Два RAW по ~12 с (приборы №83 и №84) обработаны офлайн без сбоев. У каждого сохранены 104 записи графиков и 192 записи расчётных данных (24 отчёта × 8 АЦП). SQLite каждого — 917504 байт; исходные RAW — 27874004 и 27862260 байт соответственно. Сокращение около 96.7% на этом наборе. Статусы №84 ADC7/8 `0x400` 24/24 сохранены; №83 ADC1 `0x800`, ADC5 `0x400`. Для обоих создан автономный HTML viewer (min/max/RMS и последний сохранённый AUX4700 spectrum). Графики показывают индекс полосы, пока соответствие полос частотам не подтверждено.

## Важные ограничения

- Пока только **офлайн**, а не действующий Collector Server. Не подключались к приборам.
- Невозможно вычислить произвольную новую FFT из агрегатов после окончания записи: исходного сигнала нет. При необходимости новые спектральные признаки должны рассчитываться в RAM **до** отбрасывания данных, либо пользователь должен явно выбрать отдельный режим временной сырой записи.
- Не подтверждены точные частотные метки 43 спектральных полей AUX4700 и метрологическая интерпретация ряда полей.
- Исторические отметки по счётчикам АЦП относительные; UTC не восстановлено.
- Для будущего production нужны контроль сбоя носителя, восстановление сеанса, сегментация, квоты, хранение состояний и политики целостности. Недопустимо незаметно терять результаты.
