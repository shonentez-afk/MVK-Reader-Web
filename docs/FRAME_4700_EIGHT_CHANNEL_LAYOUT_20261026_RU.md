# Формат 4700-байтового кадра: обнаружены восемь записей

Дата: 2026-10-26. Проведена офлайн-проверка двух ранее записанных RAW. Сетевые соединения не выполнялись.

## Подтверждённая структура

Общий размер 4700 = 28 байт заголовка + 8 * 584 байта.

Каждая запись занимает 584 байта: первый uint32 little-endian — идентификатор записи, за ним 145 значений float32 little-endian (4 + 145*4 = 584).

Идентификаторы восьми записей первого кадра одинаковы на обоих приборах и равны: 19013632, 19014144, 19014656, 19015168, 19015680, 19016192, 19016704, 19017216. Разность между соседними значениями равна 512.

Периодичность нулевых полей 146 слов float32 из ранее замеченного анализа теперь объясняется границами восьми записей. Первоначальная трактовка всех 1167 слов после +32 как однородного массива была неполной: идентификаторы следующих записей нельзя считать измеренными float32.

## Вывод

Структура намного лучше согласуется с восемью наборами расчётных данных — вероятно, по АЦП 1–8, — чем с единым классическим FFT-спектром. Это структурный вывод: назначение 145 значений и единицы измерения **ещё не установлены**. Сопоставление с Modbus требуется отдельно.

## Код

`tools/raw_offline_audit/frame_4700_eight_channels.py` воспроизводит выделение записей и проверяет идентификаторы. Сырые рабочие RAW и PCAPNG остаются вне GitHub.
