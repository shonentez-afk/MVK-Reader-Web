# Stage 13.23 — новая покадровая проверка третьоктавного IIR-ядра, 2026-10-28

Исполнено на новых BIN с заголовком `MVK00000043`, каналы ADC1, ADC3, ADC6 (65536 Гц, 32.4 с); VALUES с 63 строками по 0.5 с. **Название BIN содержит 43, принадлежность физическому прибору №84 не подтверждена по одному имени**, не смешивать с прежним помеховым АЦП4 №84.

Точно сохранена архитектура Stage13.15: causal 4-order Butterworth SOS bandpass, 34 третьоктавы 5..10000 Гц с базой 2, resample_poly, trailing RMS 1с. Перебор лишь относительного временного сдвига начала ряда CSV: 0..3 с через 0.25 с на **ADC1, строки 10–34**. Победил +0.75 с (медианная абсолютная ошибка 3.242%; +0.50 с — 3.601%). Это эффективная привязка по данным, не физическая задержка DSP. Сдвиг фиксирован для остальных каналов. Контроль — строки 35..60 (26 строк).
