# Коэффициенты калибровки в начальном заголовке TCP/10230 — 2026-10-26

**Подтверждено на двух независимо записанных 12-секундных RAW-потоках.** Исследование выполнено без подключения к приборам.

## Расположение полей
- Начальный блок до первого измерительного кадра — 33064 байта.
- Сигнатура `VAST_MVK` с байта 24.
- Восемь повторяющихся групп с шагом 512 байт.
- Чувствительность АЦП N (нумерация N=0..7): `float32 LE` по смещению `812 + 512*N`.
- Gain АЦП N для `acceleration_m_s2 = raw_float32 * gain`: `float32 LE` по смещению `836 + 512*N`.

## Проверка других сообщений
Ни один из 16 соответствующих коэффициентов float32 LE не обнаружен побайтово в повторяющихся кадрах типов 44, 76, 160, 284, 4700 байт. Это не доказывает, что значения никогда не встречаются в других представлениях/прошивках, но поддерживает вывод: исходный 33064-байтовый блок — основной источник калибровки в TCP/10230.

## Вывод
Можно вычислять ускорение на основании TCP/10230, **без обязательного подключения к TCP/502 для получения коэффициентов**, если начальная калибровка получена и прошла проверку. Modbus FC03 остаётся независимым источником сверки, а поведение при изменении калибровки во время сеанса неизвестно.
