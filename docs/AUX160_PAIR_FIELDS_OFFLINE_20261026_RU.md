# Поля AUX160: сравнение по двум RAW

В 12 записях каждого канала обнаружены пары чисел по смещениям +32/+40, +48/+56, +64/+72 и +80/+88. На первом из двух исследованных устройств первый элемент пары меняется во времени, а второй, как правило, постоянен.

Пример АЦП 4, первая запись: +32=4.7658744, +40=4.6668158; +48=4.4657860, +56=4.6520534; +64=0.3734325, +72=0.3638401; +80=4.2912068, +88=7.9638128. Напряжение датчика по +144=10.6228180 В.

На первом устройстве динамические данные обнаружены для шести каналов. Два канала с ранее выявленными флагами питания датчика не содержат динамических измерительных величин в этих полях. На втором устройстве числовые поля всех восьми записей канала равны нулю, хотя AUX4700 содержит измерения.

Возможная интерпретация — текущее и опорное значения. Пока это не доказано. У АЦП 4 поле +64 имеет масштаб, близкий к широкополосному СКЗ из AUX4700, но синхронное равенство не подтверждено. Для дальнейшей работы нужна лаговая корреляция со всеми 24 показателями.

Основное приложение не запускалось и не менялось. Исследование полностью офлайн.
