## Контракт

- `SampleTimeline`: относительное время `(sample_counter - origin)/65536`, приращение по каналу +256 для последовательных кадров, явные `gap`, `overlap`, `duplicate_or_reverse`, wrap uint32. **UTC не выводится по счётчику**; нужно учитывать время соединения/получения и точность привязки.
- `ChannelAligner`: группирует по одинаковому 32-bit счётчику восемь ADC, выдаёт неполные группы со списком отсутствующих каналов; граничные группы не означают ошибки сети.
- `BoundedEventQueue`: ограничения по числу элементов, явные политики `drop_newest`, `drop_oldest` и `raise`, счётчик потерь. **Не применять drop-политику к потоку первичных измерений**, если требуется безошибочное сохранение.

Никаких TCP соединений не открывалось; Stage5 не является production Collector и не включает многосуточные испытания, долговременную запись, связь device-clock c UTC и сетевой backpressure.
