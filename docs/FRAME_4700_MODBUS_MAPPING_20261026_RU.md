# Подтверждённая карта кадра 4700 байт — 26.10.2026

Данные: две сохранённые 12-секундные RAW-записи, по 24 кадра на прибор, всего 384 записи каналов. Все расчёты выполнены офлайн, без запуска программы и подключения к МВК01.

## Формат
Общий заголовок 28 байт + 8 структур по 584 байта. Каждая структура: `uint32 LE` идентификатор + 144 слова по 4 байта + завершающее 4-байтное поле. Далее позиции обозначены индексами 4-байтных слов относительно 32-го байта блока соответствующего канала.

| Индексы полей канала | Число | Соответствие приложению 2, таблица 3.4 ВАРБ.411711.112 РЭ | Уверенность |
|---|---:|---|---|
| 0 | 1 | Напряжение на датчике | Высокая (позиция + диапазон) |
| 1–43 | 43 | Дольоктавный спектр виброускорения | Высокая (совпадает число 43) |
| 44–45 | 2 | Выравнивание/резерв | Подтверждены нули в двух записях |
| 46 | 1 | Пик-фактор виброускорения до 25 кГц | Вероятное соответствие по порядку |
| 47 | 1 | СКЗ ускорения до 25 кГц | Вероятное соответствие по порядку |
| 48–71 | 24 | СКЗ вибрации в полосах / фильтрах (пп. 5–28 таблицы) | Высокая (позиция, число и числовые соотношения) |
| 72–79 | 8 | Выравнивание/резерв | Нули во всех исследованных кадрах |
| 80–103 | 24 | Эквивалентные пиковые значения для пп. 5–28 | Подтверждено численно |
| 104–111 | 8 | Выравнивание/резерв | Нули во всех исследованных кадрах |
| 112–135 | 24 | Эквивалентный размах для пп. 5–28 | Подтверждено численно |
| 136–143 | 8 | Выравнивание/резерв | Нули во всех исследованных кадрах |
| 144 | 1 | Индикатор состояния канала | Высокая; читать как uint32, не float32 |

**Проверка по всем значениям**: ненулевых элементов СКЗ 4032 у прибора A и 4608 у прибора B. Для каждой пары выполняется `peak ≈ sqrt(2) * RMS` (максимальная относительная ошибка соответственно 7.43e-8 и 7.50e-8). Для всех пар выполняется `peak_to_peak = 2 * peak` (побайтовая численная точность float32 для изученных массивов). Ненулевых пиков при нулевом СКЗ не обнаружено.

Разделы исходного руководства: приложение 2, таблица 3.4, печатные страницы 50–52; A = 0x2000 + N*0x200, N=0..7. В документе описаны 43 полосы, СКЗ по 24 позициям, пиковые по 24 и размахи по 24, а также индикаторы состояния. Источник PDF: `docs/vendor/ВАРБ.411711.112 РЭ МВК.pdf`.

## Важные ограничения
Внешняя форма этого TCP-сообщения не описана напрямую в руководстве: сопоставление получено сравнением порядка, длины и чисел. Полная метрическая проверка каждого из 24 параметров независимым FFT или синхронным FC03 ещё не проведена. Сигнал имеет разные частотные полосы, поэтому сравнение с широкополосным СКЗ само по себе не является доказательством конкретного поля.

Не трактовать позиции 144 как float32: наблюдавшиеся маленькие поднормальные float значения соответствуют битовым индикаторам целого числа. Точный смысл битов следует брать из раздела формата индикатора состояния.

## Решение
Карта достаточно надёжна для **офлайн-декодера с пометкой provisional**, но не для выпуска Live-версии без независимых тестов. Рабочие RAW и PCAPNG не загружать в GitHub.
