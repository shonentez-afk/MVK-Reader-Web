# Проверка числовых полей AUX160 против расчётного блока 4700

Дата: 2026-10-26. Проверены два сохранённых 12-секундных RAW. Для каждой записи AUX160 индекс канала определён из поля идентификатора +28.

## Доказанный результат

В 160-байтовых сообщениях типа 0x00402130..0x00402F30 обнаружено поле float32 LE по смещению **+144**. На приборе A оно согласуется с напряжением канала из поля float32 index 0 соответствующей записи AUX4700.

| Канал | AUX160 A, диапазон В | AUX4700 A, диапазон В | AUX160 B | AUX4700 B, диапазон В |
|---|---|---|---|---|
| 1 | 0.0715–0.0723 | 0.0712–0.0726 | 0 | 10.5779–10.5787 |
| 2 | 10.7979–10.8004 | 10.7978–10.8004 | 0 | 10.4002–10.4019 |
| 3 | 10.6111–10.6122 | 10.6111–10.6125 | 0 | 10.8198–10.8203 |
| 4 | 10.6228–10.6253 | 10.6228–10.6253 | 0 | 10.6182–10.6192 |
| 5 | 18.5681–18.5856 | 18.5681–18.5876 | 0 | 10.5295–10.5304 |
| 6 | 10.7599–10.7622 | 10.7596–10.7622 | 0 | 10.6525–10.6542 |
| 7 | 10.3787–10.3804 | 10.3782–10.3804 | 0 | 18.9598–18.9616 |
| 8 | 10.8094–10.8115 | 10.8094–10.8118 | 0 | 18.8401–18.8411 |

У каждого прибора проверено 12 AUX160-сообщений каждого канала и 24 AUX4700-сообщения каждого канала: всего 192 + 384 записей. У A AUX160 +144 ненулевой в 96/96 записей, у B нулевой в 96/96, несмотря на ненулевое напряжение в 4700 (192/192).

## Другие изменяющиеся позиции AUX160

- У A большинство записей ADC имеют изменяющиеся float32 по смещениям +32, +48, +64, +80, +144 (в ряде каналов также +44 и +92). Позиции +32/+48/+64/+80 пока не сопоставлены однозначно с группами параметров 4700 и не должны получать окончательные наименования.
- У B в восьми записях каналов все 40 uint32 слов неизменны и равны нулю, **кроме идентификатора типа на +28 и иных полей заголовка**. Поле +144 — нуль. При этом общие 160-байтовые кадры B содержат динамические счётчики. 
- Разница A/B говорит о неодинаковом содержимом AUX160. Нельзя считать +144 универсальным резервным источником напряжения без проверки состояния и прошивки.

## Вывод

AUX160 несёт часть телеметрии канала, которая на A согласуется с расчётным напряжением из AUX4700. Но AUX160 другого прибора не содержит этих чисел. Следовательно, для Reader Web источником напряжения по данным измерения остаётся ранее подтверждённый AUX4700.

Наличие 36-байтового клиентского сообщения не было причинно связано с обнаруженной разницей: обе пассивные записи делались без такого сообщения.

Основная программа v0.3.40 не запускалась, сетевых команд не отправляли.
