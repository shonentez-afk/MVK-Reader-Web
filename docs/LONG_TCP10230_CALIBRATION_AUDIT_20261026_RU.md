# Длительный захват TCP/10230: аудит обновления калибровки

Дата: 2026-10-26. Исходный файл пользователя: `1111.pcapng` (не загружать в GitHub).

## Результаты

В PCAPNG имеется один TCP-поток данных прибора в сторону клиента. Сессия начинается в середине передачи (начальный TCP handshake и метаданные VAST_MVK в захвате отсутствуют).

- Восстановлено 196 694 316 байт TCP application payload без пропущенных последовательностей в захваченной части.
- Оценочная длительность по числу отсчётов восьми АЦП при 65536 Гц: примерно 84.7 с.
- Обнаружено кадров: ADC 1052 байта — 173469; тахометрические 284 байта — 43368; служебные 44 — 21684, 160 — 765, 4700 — 170, 76 — 170.
- Разбор начинается с корректного ADC-кадра и заканчивается точно в конце TCP-потока без повреждённых границ.
- Сигнатура `VAST_MVK` не встречается.
- Ни один из восьми ранее измеренных коэффициентов прибора B не обнаружен в виде точной последовательности байт float32 little-endian в реконструированном потоке.

## Вывод и ограничения

В наблюдаемом интервале не найден повторный полный заголовок калибровки или прямая передача восьми известных gain в исследованном бинарном представлении. Это **не доказательство отсутствия изменения настроек**: запись не содержит исходного VAST_MVK, а изменённый коэффициент мог иметь другое значение или иное представление.

Формальная проверка работы при смене настроек требует отдельного согласованного испытания или захвата, в котором известен момент изменения; не изменять настройки действующего оборудования ради теста.

MVK Reader Web v0.3.40 не изменяли и не запускали. Весь разбор — офлайн.
