# Протокол и калибровка МВК01 — актуализация 2026-10-29

> **Главный контракт:** [ADR — оригинальные данные DSP являются источником истины](ADR_2026_10_29_ORIGINAL_MVK_DSP_DATA_SOURCE_RU.md). После Stage109 подтверждён read-only Live TCP/10230 без прикладных команд на реальном №84. Помимо исходных АЦП передаются AUX4700 с готовыми DSP-расчётами и штатными 43 третьоктавами, два TACH, первичный регистровый образ с K; для штатных СКЗ/спектров **не нужен повторный собственный расчёт**. Протокол TCP/502 остаётся отдельным опциональным read-only путём.

## TCP/10230
Передача временного сигнала по 8 АЦП. Разобранный измерительный блок: 1052 байта; маркер `0xFF800ADC`; заголовок 28 байт; в нём индекс канала со смещения 20 (0–7) и номер последовательности со смещения 12; полезные данные — 256 `float32 LE` со смещения 28. Частота дискретизации 65536 Гц на канал.

## TCP/502 — FC03, только чтение
- 0x0020, 16 регистров: восемь коэффициентов калибровки тракта.
- Для канала N (0…7) база `A=0x0100+N*0x0100`.
- `A+0x02`: чувствительность датчика, `float32`, В/(м/с²).
- `A+0x0E`: автоматический коэффициент пересчёта, `float32`.
- Порядок байтов `CDAB` (переставленные 16-битные слова).

## Проверка шкалы
Для проверенных пар PCAPNG и BIN (АЦП 4 обеих машин) подтверждено:
```python
acceleration_m_s2 = raw_float32_tcp10230 * conversion_gain
```
Точность совпадения находится на уровне погрешности float32. **Уточнение 29.10.2026:** в R6.1 для реального сеанса прибора №84 независимо побитово сверены все восемь собственных BIN (15 725 824 float32), а 33 600 значений AUX сопоставлены с VALUES. Это подтверждает корректное декодирование/экспорт, **не** идентичность оригинальным файлам MVKView из того же сеанса. Экспортированный BIN уже имеет физические единицы: повторно применять gain к BIN **нельзя**.

## Неопределённость и безопасность
**Обновлено:** реальным Stage109 подтверждено: после обычного TCP Connect прибор начинает передачу без клиентского прикладного payload. Не отправлять неидентифицированную 36-байтовую посылку, Modbus-записи и команды управления. Подключение к работающему прибору разрешается только оператором. Рабочие адреса приборов в этом файле приведены как лабораторные метки прошлых результатов; перед публикацией репозитория заменить на обезличенные.
