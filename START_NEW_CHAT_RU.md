## Последние подтверждённые технические результаты
- TCP/10230: 8 АЦП, блок 1052 B и 256×float32 LE на канал; отдельные тахо 8/9. Приборы IP .83→серийный 00000050, IP .84→00000043 подтверждены 160-байтными сообщениями.
- Modbus FC03 (TCP/502) позволяет читать калибровку; параметр канала `A+0x0E` — готовый множитель `K`, `A+0x02` — чувствительность датчика, `0x0020` — калибровка АЦП. Преобразование raw TCP→м/с²: raw×K; записанный BIN уже масштабирован.
- Живая MVKView задаёт FRange по `A+0x0E` (Stage 52); архив с TSXML — через `InternalChannelGain` с резервным расчётом calibration/sensitivity (Stages 61–62). Повторно не масштабировать BIN.
- Официальный протокол производителя **версии 1.0.39**, предоставленный пользователем, описывает Modbus-регистры и диагностику. Он не описывает собственный TCP/10230; структурные совпадения проверены по захватам. Версия устройства в других материалах 1.0.59 — совместимость ещё проверить.
- AUX4700 — восемь записей по 144 float32 плюс статус; A=0x2000+N*0x200; 43 дольоктавные полосы и другие расчётные значения по официальной таблице.
- Сообщения длиной 160 байт: 128 байт контроля = 8 × (current float32, status u32, at_change float32, reserved u32). Коды зон: 0, 0x11–0x15, события в битах 9–11. Нулевые блоки прибора .84 не означают отсутствие вибрации.
- Конфигурация контролируемого слота j: `0x0100+N*0x100+0x60+j*0x10`; состояние: `0x2000+N*0x200+0x130+j*8` (N,j=0..7). **Номер слота не равен реальному номеру параметра.** Шаблон DefaultConfig не отражает реальные назначения приборов.
- Stage 64–66: MVKView создаёт 8 списков `ResultAlarmCellList`, для каждого слота показывает значение/зону/события, конфигурационный редактор содержит 8×8 полей.
- Stage 67–68: выпадающий список 115 параметров: 2–44 (полосы), 49–72 СКЗ, 81–104 эквивалентный пик, 113–136 размах. Восемь диапазонов: 10..3000, 10..2000, 10..1000, 2..1000, 0,8..300, 0,8..150 Гц, Польз. 1/2.
- **Stage 69:** `TMvkAdvancedCell.Add` сохраняет числовой ID; `GetID`/ `GetIndexByID` связывают индекс/ID; `GetValueText` преобразует сохранённый DWORD в подпись через `GetTitleByID`. **Запись выбранного пункта в память и отправка на прибор ещё НЕ установлены.**
