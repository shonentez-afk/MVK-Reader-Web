# v0.3.20 — History usability LAB

Добавлены фильтр истории по локальным датам «С/По» и экспорт отображаемых точек в CSV с датами UTC. Данные истории берутся только из SQL через прежний API. Опрос МВК01 не изменён. Обратите внимание: API возвращает максимум последние 1000 записей; выбор периода фильтрует загруженные точки, а не всю базу.
