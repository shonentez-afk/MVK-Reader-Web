# Установка и проверка v0.3.20

1. Остановить старую программу Ctrl+C.
2. Распаковать сборку в отдельную папку. Не удалять прежнюю SQL-базу.
3. В CMD: `python -m venv .venv`
4. `.venv\Scripts\python.exe -m pip install -r requirements.txt`
5. `.venv\Scripts\python.exe CHECK_PC.py`
6. `.venv\Scripts\python.exe START_READER.py`
7. Открыть http://127.0.0.1:8080, карточку МВК01 -> История. Убедиться в реакции на пустую историю. При наличии записей проверить фильтр и CSV.

Не копируйте прежний `devices.json` с включённым опросом без отдельной проверки. Опрос настоящих приборов для теста не требуется.
