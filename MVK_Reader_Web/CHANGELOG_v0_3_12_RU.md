# MVK Reader Web v0.3.12 — Lifecycle & Stress LAB

## Изменения
- Убраны устаревшие FastAPI `@app.on_event` из Collector.
- Запуск и остановка потока опроса теперь управляются через lifespan.
- Исправлен объединённый запуск: lifespan смонтированного приложения FastAPI не вызывается автоматически, поэтому объединённый `integrated.py` явно запускает Collector вместе с Reader.
- При исключении верхнего уровня в цикле планировщика выполняется запись ошибки в журнал, поток продолжает работу.
- Поток опроса останавливается по событию и ожидается `join` до 3 секунд. Если текущая операция блокирует завершение, журнал сообщает об этом.
- Добавлены лабораторные тесты: 1000 циклов без незапланированного опроса; 300 циклов двух виртуальных приборов с повторяющимися отказами; запуск/остановка интегрированного веб-сервера.

## Проверка
40 / 40 тестов pytest успешно. Прогон локальный, ускоренный; это **не** 24-часовое испытание и **не** подтверждение работы с физическими МВК01.

## Зафиксированные ограничения
- Период опроса приборов не определён; `interval_seconds: null` и `enabled: false` в исходной конфигурации.
- Не реализованы потоковые осциллограммы с прибора и не подтверждены контрольные зоны.
- Нагрузку производственной сети не измеряли.
- Базовый механизм коротких TCP-соединений требует испытаний на настоящем приборе после согласования безопасной нагрузки.

## Запуск Windows 11
Из распакованной папки:
`python -m pip install -r requirements.txt`
`python -m uvicorn integrated:app --host 127.0.0.1 --port 8080`
Открыть `http://127.0.0.1:8080`.
Изменение серверных IP/портов — только в `collector/devices.json`.
