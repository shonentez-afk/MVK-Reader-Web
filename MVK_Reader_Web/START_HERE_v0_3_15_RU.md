# MVK Reader Web v0.3.15 — Offline Capture Comparison LAB

## Что добавлено

Новый `pcap_session_compare.py`: сравнительный анализ **двух сохранённых классических PCAP**.
Один файл записывается при обычном подключении MVKView к прибору, другой — при открытом окне временного сигнала на том же приборе. Инструмент сравнивает число потоков, объёмы неизвестных TCP-данных, запросы Modbus, адреса читаемых регистров, пропуски TCP-сегментов. Результат — JSON-отчёт **без содержимого пакетов**.

Команда из корня архива:

```
python pcap_session_compare.py idle.pcap time_signal.pcap --output comparison.json
```

Сначала проверьте действующую локальную политику ИБ и согласуйте захват трафика. В Wireshark допустим только **пассивный** захват на испытательном ПК. Не изменяйте конфигурацию МВК01 и не отправляйте пробных команд. Если разрешено, сделайте два сопоставимых сеанса одинаковой длительности, сохраняя исходный PCAP локально. Захваты могут содержать IP-адреса и чувствительные сведения: не отправляйте их за пределы разрешённого контура без согласования.

Программа поддерживает только classic `.pcap` Ethernet/IPv4/TCP, не `.pcapng`. Экспорт в PCAP можно выполнить в Wireshark через **File → Save As** с соответствующим форматом. Результат не подтверждает способ передачи осциллограмм: отличия трафика лишь выявляют кандидатов для последующего анализа. Различия объёмов между записями разной длительности нельзя трактовать как скорость потока.

## Что не изменено

* Нет подключения к реальным приборам и нет сетевых операций в инструментах PCAP.
* Collector опрашивает приборы только при явной настройке; рабочая частота опроса не выбрана.
* Нет отправки функций Modbus записи и нет изменения конфигурации прибора.
* Живой поток отсчётов ещё не декодирован. Все прежние Reader Web, SQL, BIN/TSXML функции сохранены из v0.3.14.
