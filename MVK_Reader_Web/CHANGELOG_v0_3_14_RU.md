# v0.3.14 — Offline Protocol Investigation LAB

## Выполнено
- Добавлен `pcap_offline_analyzer.py`: офлайн-анализ классических Ethernet PCAP с IPv4/TCP, без сетевых подключений.
- Группировка TCP-потоков, сборка сегментов с учётом номера последовательности, обнаружение пропусков, выделение документированных Modbus/TCP-кадров с кодом функции, адресом и числом регистров.
- Выделение неизвестных TCP-потоков по портам и объёму полезной нагрузки — без утверждения, что это осциллограммы.
- Выходной JSON **не содержит сырых данных пакетов**, чтобы снизить риск распространения производственной информации.
- Добавлены синтетические тесты PCAP; активных подключений к МВК01 нет.

## Исследовательское ограничение
В предоставленном `Data.zip` есть `mvkview.exe` и конфигурация, но нет захваченного реального сетевого обмена. По строкам EXE и руководству нельзя доказать транспорт временных отсчётов. Пока **нет оснований** реализовывать отправку команд запроса потока, даже если они потенциально существуют.

## Как использовать
`python pcap_offline_analyzer.py file.pcap --output protocol_summary.json`

Поддерживается классический PCAP/Ethernet/IPv4/TCP. PCAPNG и IPv6 нужно конвертировать/доработать отдельно. Нужна разрешённая пассивная запись штатного обмена с тестовым прибором; не включайте запись содержимого сторонних сервисов. Отчёт позволяет определить TCP-порты и объёмы; полноценный декодер осциллограмм будет возможен лишь после проверки реального обмена и соответствия BIN/TSXML.

## Безопасность
- Ни одно соединение к прибору не инициируется данным модулем.
- МВК01 только для чтения. Запись в SQL не означает запись в прибор.
- Частоты опроса не изменены.
