# Проверка v0.3.31 на Windows

1. Не удалять рабочую v0.3.18. Распаковать эту лабораторную версию отдельно.
2. Создать venv и установить requirements.txt (при необходимости).
3. Проверка: `.venv\Scripts\python.exe CHECK_PC.py`
4. Запуск в другом окне: `.venv\Scripts\python.exe START_READER.py`
5. Параллельные запросы (ещё одно окно cmd): `.venv\Scripts\python.exe VERIFY_MULTIUSER.py`
6. Ожидание: `Requests: 18 / OK: 18 / errors: 0`.

Важно: это несколько HTTP-клиентов с одного ПК, а не испытание реального корпоративного LAN. Сервер слушает только 127.0.0.1 и не доступен другим компьютерам. Не выставляйте 8080 в сеть без аутентификации, HTTPS и ограничений доступа. Не включайте опрос МВК01.
