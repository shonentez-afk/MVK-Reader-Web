# v0.3.30 — безопасный перенос данных при обновлении

- `TRANSFER_OLD_DATA.py`: перенос SQL-базы через SQLite backup API и JSON конфигурации между папками.
- Проверка целостности SQL, отказ от перезаписи файлов в новой установке.
- Запрет переноса конфигурации, включающей опрос приборов.
- Новые тесты сохранности и отказа при конфликте.
- В архив не входит рабочая SQLite-база.
- Ограничения: тесты не заменяют опытную проверку Windows и многопользовательской работы.
