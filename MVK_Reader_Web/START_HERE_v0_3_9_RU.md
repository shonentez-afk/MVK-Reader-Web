# Как проверять v0.3.9

1. Распакуйте архив, убедитесь, что Python установлен.
2. Из корня проекта установите зависимости: `python -m pip install -r requirements.txt`.
3. Запустите тесты: `python -m pytest -q` (при отсутствии pytest: `python -m pip install pytest`).
4. Запуск объединённого приложения: `python -m uvicorn integrated:app --host 127.0.0.1 --port 8080`.
5. Откройте браузер: `http://127.0.0.1:8080`.

Все приборы в `collector/devices.json` выключены, `interval_seconds` равен `null`. Поэтому подключений к настоящим приборам после запуска не будет.

Для проверки без приборов достаточно автоматических тестов. Не включайте реальные IP до согласования сетевой нагрузки.
