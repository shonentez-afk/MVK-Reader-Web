# MVK Reader Web + Collector v0.3.1 LAB

В этой сборке Reader Web и Collector доступны на одном локальном веб-сервере.

## Запуск на Windows 11

1. Установите Python 3.11–3.13 и зависимости: `python -m pip install -r requirements.txt`.
2. Запустите `START_INTEGRATED_WINDOWS.cmd` или вручную: `python -m uvicorn integrated:app --host 127.0.0.1 --port 8080`.
3. Откройте `http://127.0.0.1:8080/`.
4. На главной странице Reader Web появится раздел «Приборы МВК01». API: `/collector/api/devices`, `/collector/api/devices/{id}/live`, `/collector/api/devices/{id}/history`.

## Безопасность и ограничения

- По умолчанию все приборы отключены (`enabled: false`) и `interval_seconds: null`, автоматического опроса нет.
- Все IP и номера приборов задаются только в `collector/devices.json`. Reader Web IP приборов не задаёт.
- Modbus-клиент поддерживает только функцию `0x03` (чтение). Устройства не конфигурируются и не перезагружаются.
- В веб-интерфейсе пока отображаются статус и **сырые регистры**, а не рассчитанные СКЗ/ПИК/ПИК-ПИК.
- В базе SQLite `collector/collector.sqlite3` хранятся считанные регистры и журнал ошибок. Не использовать этот лабораторный модуль для производственного опроса без дополнительных испытаний, аутентификации и сетевых ограничений.
- Период опроса не утверждён. Система не создает лишних запросов при открытии нескольких браузеров; браузер запрашивает только кеш сервера.
- Потоковые сигналы и онлайн FFT пока не реализованы, так как протокол потока отдельно не подтверждён.

## Примечание

Существующие обработчики анализа BIN/TSXML Reader Web сохранены. Для доступа с других ПК в ЛВС потребуются средства контроля доступа и отдельное согласование настройки сетевого интерфейса.
