# Сборка v0.3.7 LAB — начало работы

Разработка продолжается без доступа к реальному МВК01. Основное изменение — декодирование состояний АЦП из регистров `A+0x120` (раздел 3.5.7 руководства) и их вывод в «Расчётные данные → АЦП 1–8». Добавлен экран системной диагностики.

Настройка приборов находится только в `collector/devices.json`. По умолчанию `enabled:false`, `interval_seconds:null` — сетевой опрос отключён. **Не включать реальные приборы до безопасного стендового теста и согласования интервалов опроса.**

Для запуска на тестовом Windows 11: установить зависимости из `requirements.txt`; выполнить `python -m uvicorn integrated:app --host 127.0.0.1 --port 8080`; открыть `http://127.0.0.1:8080`. В этом режиме доступен офлайн-анализ BIN и API зарегистрированных приборов без фактического опроса.

Новое API: `/collector/api/devices/{id}/channel-status?channel=1` (до 8). Регистр состояния канала должен входить в явно разрешённый диапазон `read_ranges`, иначе возвращается «нет данных». Автоматически расширять диапазоны опроса нельзя без проверки нагрузки.

Раздел «Контрольные зоны» оставлен неподтверждённым, поскольку карта соответствующих регистров не установлена. Не выдавать его за реализованный модуль.
