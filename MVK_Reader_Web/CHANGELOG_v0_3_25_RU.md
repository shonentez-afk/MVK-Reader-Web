# v0.3.25 — согласованность экспорта

Исправлено расхождение PDF, XLSX, JSON с экранным спектром при выборе полосового фильтра. Все форматы используют одинаковый массив амплитуд и метрики с учётом `filter_id`. В сводных отчётах указан идентификатор фильтра. CSV сохраняет BOM UTF-8. Расчёты пока не являются метрологически утверждённым эквивалентом MVKView. Работа с физическими МВК01 не изменена.
