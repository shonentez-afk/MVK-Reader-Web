# MVK Reader Web 0.3.10 — Operational Safety LAB

## Реализовано
- GET `/collector/api/server-status`: количество сконфигурированных/активных/запланированных приборов, их статус, размер SQLite, количество исходных снимков, расчётных величин и событий.
- Онлайн-копирование SQLite через Python SQLite backup API без остановки коллектора: `python backup_collector.py --output-dir backups`.
- Контроль целостности резервной копии через `PRAGMA quick_check`.
- Запрет перезаписи работающей базы и существующего резервного файла.
- Все диагностические запросы и резервирование работают только с локальной SQL и оперативным буфером, не вызывая Modbus.

## Проверки
- 34/34 автоматических теста; 4 предупреждения о `FastAPI.on_event`, не устранены.
- Реальные приборы не опрашивались, частота опроса не устанавливалась.

## Ограничения
- Это лабораторная сборка: нет нагрузочных многосуточных испытаний и испытаний в Windows-браузере.
- Не настроены автоматическая ротация архива, PostgreSQL, резервирование по расписанию и потоковые осциллограммы.
- Диагностика возвращает примерный размер SQLite по страницам базы, без размера файлов WAL/журнала.

## Порядок запуска
Из корня архива: `python -m pip install -r requirements.txt` затем `python -m uvicorn integrated:app --host 127.0.0.1 --port 8080`.
API статуса: http://127.0.0.1:8080/collector/api/server-status
Резервирование: `python backup_collector.py --output-dir backups`
Опрос по умолчанию выключен, приборы в `collector/devices.json` отключены.
