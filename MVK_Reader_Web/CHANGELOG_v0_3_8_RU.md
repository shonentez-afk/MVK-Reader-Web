# MVK Reader Web v0.3.8 — LIVE CACHE LAB

- Добавлен серверный SSE `/collector/api/events`, публикующий только изменения оперативного состояния приборов.
- Подписка браузера НЕ инициирует Modbus-чтение. Несколько браузеров получают один и тот же уже собранный снимок.
- Статус `connection_error` и `not_polled` явно различается с `connected`.
- В интерфейсе отображается предупреждение, если текущие данные недоступны.
- Настройка частоты опроса МВК01 не изменена; в `devices.json` интервал `null`, прибор отключён.
- Непрерывный поток осциллограмм пока не реализован: протокол не подтверждён.

## Запуск
`python -m pip install -r requirements.txt`
`python -m uvicorn integrated:app --host 127.0.0.1 --port 8080`
Открыть http://127.0.0.1:8080 — служебный SSE: `/collector/api/events`.

Версия лабораторная. Подключение к производственной сети и автоматический опрос без отдельного согласования не выполнять.
