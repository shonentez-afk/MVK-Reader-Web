# MVK Reader Web v0.3.39 — ручное управление Modbus TCP/502

База: v0.3.38. Сохранены Reader Web, NETWORK GUARD, Collector, история и вкладки.

В панели «Управление приборами МВК01» добавлены подключение/отключение Modbus, интервал опроса и отдельный просмотр статуса портов. В API: `GET /api/mvk/devices/{id}/connection`, `POST /api/mvk/devices/{id}/modbus/start`, `POST /api/mvk/devices/{id}/modbus/stop`.

Кнопка «Подключить» включает периодический FC03 опрос планировщиком существующего Collector, а не запускает новый самостоятельный сокет. Для запуска требуются явные `read_ranges` в `collector/devices.json`; пустые диапазоны блокируют запуск. Новая карточка прибора по умолчанию отключена.

Отключение прекращает планирование будущих запросов, но уже начатая операция может завершиться. Успешность подключения определяется только после фактического чтения: `enabled` НЕ означает `connected`. Время и достоверность последних данных показываются отдельно.

TCP/10230 не запускается: процедура инициирования временного потока ещё не подтверждена. Приборы в ходе офлайн-тестов не опрашивались.

Проверка: `python -m pytest tests/test_modbus_control_339.py -q`; для полного набора тестов `python -m pytest -q` с корректным PYTHONPATH.
