# v0.3.26 — длинные тренды и полный SQL CSV

- `series-overview`: серверный min/max envelope, до 2000 групп, сохраняет всплески и ограничивает размер ответа.
- `history-export.csv`: потоковая передача всех строк выбранной SQL-истории без ограничения 5000, с датами и всеми единицами/источниками.
- График использует overview, CSV скачивается отдельно прямо с SQL-сервера.
- Только SQL-чтение, запросов к МВК01 нет.

Ограничение: полный экспорт длительного периода может надолго занять SQLite read connection, потоковая передача не включает архивные BIN.
