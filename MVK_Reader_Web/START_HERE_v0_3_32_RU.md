# MVK Reader Web 0.3.32 — проверка безопасности локального режима

1. Не заменяйте установленную v0.3.18: распакуйте эту сборку в отдельный каталог.
2. Создайте .venv и установите requirements.txt как прежде.
3. Выполните `.venv\Scripts\python.exe CHECK_PC.py` и `.venv\Scripts\python.exe CHECK_NETWORK_SECURITY.py`.
4. Запустите `.venv\Scripts\python.exe START_READER.py`; откройте http://127.0.0.1:8080.
5. НЕ открывайте порт 8080 в корпоративной сети: защита не заменяет TLS и учётные записи пользователей.

Команды на запись в приборы не используются. Опрос приборов отключён по умолчанию.
