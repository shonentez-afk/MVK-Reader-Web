Расчётные данные МВК01
Состояния датчиков, контрольные зоны, тахометры и штатные СКЗ/ПИК/ПИК-ПИК выдаются прибором через Modbus. Эти параметры отсутствуют в сохранённом BIN и сейчас не выводятся как реальные.


Временной сигнал
TCP/10230: офлайн-импорт; прибор не опрашивается.
Для архива доступны только записанные каналы. AC — локальное удаление среднего; фильтры — локальный расчёт, не точная копия DSP.


Спектральный анализатор
TCP/10230: без калибровки доступна только PSD исходных отсчётов.
Линейные спектры рассчитываются по BIN (Welch/Hann). Режим «Логарифмич.» показывает предварительный уровень виброскорости в дБ относительно 1 мм/с; точная логарифмическая шкала MVKView ещё не установлена. CSV экспортирует линейные амплитуды с тем же частотным фильтром; логарифмический пересчёт дБ доступен пока только на графике. Выбранная полосовая фильтрация выполняется локально; метод и значения пока не метрологически эквивалентны MVKView.

Управление приборами МВК01 (настройки подключения)
  
Добавление или редактирование карточки не подключает прибор. Для сигнала TCP/10230 живой запуск заблокирован до подтверждения протокола.

  
  
  
  
  
  
  
  
  
Подключение Modbus TCP/502 — только FC03

  
Выберите ID прибора выше. Опрос запускается только по нажатию. Диапазоны чтения должны быть заранее настроены в карточке Collector. TCP/10230 не запускается.
