# MVK Reader Web v0.2.1 — FULL UI

Реальная веб-сборка с офлайн-архивом BIN/TSXML, осциллограммами, оценочными спектрами, PDF и XLSX. **Это не законченная система онлайн-вибромониторинга**. Приборы в v0.2.1 не опрашиваются. Команды записи, изменения конфигурации, Flash и перезагрузки отсутствуют.

## Запуск на Windows

1. Установить Python 3.11+.
2. Распаковать архив; в каталоге программы выполнить `py -m pip install -r requirements.txt`.
3. Запустить `start_windows.bat`.
4. На сервере открыть `http://127.0.0.1:8080`, на других ПК — `http://<IP_сервера>:8080` (доступность определяется настройками брандмауэра).

**Важно:** пока нет входа пользователей, ограничивайте доступ доверенной подсетью, не публикуйте сервер в Интернет. Сервер хранит архив локально в `data/`. Резервное копирование этой папки выполняется администратором.

## Что работает

- Навигация: Главная, Расчётные данные, Временной сигнал, Спектр, Параметры записи, Архив, Отчёты, Настройки.
- Загрузка / открытие / удаление одно-канальной записи `BIN+TSXML`; данные на сервере, SQLite-индекс.
- Осциллограмма AC и AC+DC, выбор длительности, вертикального масштаба и фильтра. Полосовые фильтры применяются **локально** (Butterworth) и не считаются аналогом DSP МВК01.
- FFT-спектры ускорения, скорости и перемещения, управление разрешением, полосой просмотра, экспорт PNG и CSV.
- Оценка третьоктавных полос из BIN; не эквивалент сертифицированных третьоктавных фильтров прибора.
- PDF с табличными показателями и графиком; XLSX со сводкой и частотными значениями; JSON, BIN/TSXML.
- Вкладки прибора, расчётных значений, контрольных зон и тахометров оформлены, но честно показывают недоступность без сетевого драйвера.
- Настройки записи сохраняются **только в localStorage браузера**, НЕ инициируют запись прибора.

## Что пока НЕ реализовано

- Онлайн-чтение МВК01, состояния датчиков, порогов, регистров и тахометров;
- безопасная потоковая передача осциллограмм и серверный рекордер;
- полное соответствие фильтров, СКЗ и FFT штатному MVKView;
- несколько исходных каналов в одном BIN; сравнение нескольких записей;
- авторизация, производственное развёртывание, высоконагруженные испытания.

Поля графика в BIN не следует путать с реальными расчётными регистрами прибора. Расчётные результаты — инженерные **оценки**, пока валидация на MVKView не завершена.

## Проверка

`py -m unittest discover -s tests -v`

8 серверных тестов, в том числе на реальном примере записи, были пройдены в рабочем окружении. Полный E2E-тест в Windows/браузере не выполнен.

## Безопасность

В программной сборке нет Modbus-клиента или сетевых вызовов к МВК01. Единственная функция удаления — удаление локальной записи из архивной базы сервера.

### Исправление v0.2.1.1: логарифмический спектр
В выпадающий список «Тип спектра» добавлен режим «Логарифмич.». Сейчас это **предварительное** представление амплитуды спектра виброскорости в дБ относительно 1 мм/с (20 log10), а не подтверждённое точное поведение MVKView. Экспорт CSV пока содержит линейные значения. При выборе режима вертикальный линейный масштаб отключается.
