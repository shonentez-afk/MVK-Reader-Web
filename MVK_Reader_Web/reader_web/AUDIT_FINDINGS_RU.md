# Аудит соответствия MVK Reader Web v0.2.1.2 — 21.10.2026

## Исправлено и проверяется тестами
- Выбранный фильтр спектра теперь передаётся серверу, применяется **до** прореживания точек графика и сохраняется в CSV; раньше график и экспорт расходились.
- СКЗ и пиковые параметры спектра вычисляются по полному набору частотных отсчётов (после фильтрации), а не только по прореженному графику.
- Запрещено строить спектр выбранного канала АЦП, если в архивном файле записан другой канал.

## Неполное соответствие оригиналу — открытые задачи
- Логарифмический режим: опорный уровень 1 мм/с принят предварительно. Экспорт CSV содержит линейную амплитуду, не дБ.
- По одному BIN отсутствуют статусы каналов, зоны контроля, измерения других АЦП и тахометров. Эти данные требуют живого Modbus.
- В интерфейсе показаны фильтры по скриншотам, но Butterworth четвёртого порядка не эквивалентен оригинальному DSP; некоторые частоты недоступны при низком Fs или коротких записях.
- «Третьоктавные» значения — аппроксимация из БПФ, а не подтверждённый метрологический метод МВК01.
- FFT/нормировка скорости и СКЗ по прежнему отличаются от исходного MVKView.
- Вертикальные шкалы спектра пока представлены значениями 0.1/1/10/100/1000/10000 без всех единиц и точного набора оригинальных списков.
- Нет отдельного окна списка нескольких пиков, гармоник и сравнения спектров; нет сохранения полного сеанса конфигурации анализа.
- Параметры записи сохраняются только локально в браузере; онлайн-рекордер отсутствует.
- PDF/XLSX являются базовыми отчётами; полной формы диагностического протокола нет.
- Не реализованы роли пользователей, единая многопользовательская конфигурация, контроль доступа, live Modbus, перенос BIN на сервер из приборного потока.
- Диапазоны частоты/разрешения подтверждены интерфейсом, но некоторые сочетания несовместимы с Fs и длиной конкретного файла; UI пока полагается на ошибку API.
- Онлайн-чтение временных сигналов нельзя включать до отдельной проверки безопасности протокола.

## Гарантии
В этой версии **нет подключения к прибору** и нет команд записи, сброса, перезагрузки, изменения Flash либо конфигурации.
