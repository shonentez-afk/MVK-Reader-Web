# MVK Reader Web v0.3.22 — Archive Browser LAB

- Архив BIN/TSXML: фильтрация по номеру МВК01, АЦП и дате измерения из имени файла.
- Кнопки открытия осциллограммы и спектра непосредственно из строки архива.
- Отдельный счётчик результатов и сообщение при пустой выборке.
- Старые записи без даты остаются доступными без фильтра по датам.
- Путь данных и SQLite без изменений. Modbus-соединения не затронуты; интервалы опроса не назначались.
- Дата измерения определяется из типового имени файла, не из момента загрузки.
