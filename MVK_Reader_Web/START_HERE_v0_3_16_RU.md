# MVK Reader Web v0.3.16

1. Основная сборка остаётся Collector + SQLite + Reader Web с режимом Modbus/TCP только для чтения.
2. Новый автономный анализатор `pcap_stream_diagnostics.py` не создаёт сетевых соединений.
3. Для самостоятельной проверки из каталога проекта запустите `python -m pytest -q`.
4. Для анализа трафика используйте два санкционированных захвата PCAP, снятых на испытательном ПК, и команду из `CHANGELOG_v0_3_16_RU.md`.
5. Реальный формат потокового сигнала не установлен. После появления захвата сначала проверять отсутствие пропусков и наличие отдельного потока, затем анализировать структуру только офлайн.
