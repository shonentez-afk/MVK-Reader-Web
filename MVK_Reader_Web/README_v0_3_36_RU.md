# v0.3.36 — офлайн-навигация PCAPNG

Вкладки «Временной сигнал» и «Спектр» (TCP/10230) получили выбор начала участка записи и длины анализируемого интервала. По умолчанию показывается конец записи — совместимость с v0.3.35. Вкладка «Расчётные данные» продолжает использовать Modbus TCP/502. Никаких новых сетевых команд прибору нет.

Новый импорт сохраняет до 128 секунд на АЦП (8 388 608 отсчётов); ранее импортированный 4-секундный snapshot требуется создать повторно, чтобы открыть предысторию. Для более длинных файлов пока остаётся ограничение 128 секунд; это не бесконечный дисковый архив.
