# MVK Reader Web v0.3.35 PORT TABS (офлайн)

Основа: v0.3.34, сохраняется FastAPI, Collector Server, SQLite и NETWORK GUARD.

* «Временной сигнал» -> TCP/10230, существующий BIN/TSXML или восстановленный PCAPNG (сырые отсчёты).
* «Спектр» -> TCP/10230, BIN/TSXML или PCAPNG. PCAPNG без подтверждённой калибровки показывается только в единицах исходных отсчётов PSD.
* «Расчётные данные» -> Modbus TCP/502, только штатные данные прибора, без зависимости от импортированного PCAPNG.

Убрана дублирующая вкладка «Сигнал TCP/10230». Живой TCP/10230 не подключается. Интерфейс пока использует последние 4 секунды импортированного PCAPNG; полный архив/прокрутка требуют отдельной реализации.

Текущие элементы фильтров и частотных настроек BIN/TSXML не применяются к PCAPNG; для PCAPNG доступны выбор АЦП, FFT и явный коэффициент калибровки. Не считать параметры метрологически идентичными MVKView.
