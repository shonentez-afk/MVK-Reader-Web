# v0.3.34 — Signal UI + сохранение Modbus TCP/502

- Основа: оригинальный Reader Web v0.3.32 NETWORK GUARD, расширенный v0.3.33 Signal Bridge.
- Добавлена вкладка «Сигнал TCP/10230» с осциллограммой, спектральной плотностью, настройками АЦП/FFT/фильтра и явно заданной физической калибровкой.
- Сохранена отдельная подсистема Modbus TCP/502: `collector/core.py`, `collector/decoder.py`, `collector/service.py`; только функция 03 — чтение регистров. Ни новый Signal Bridge, ни его интерфейс не отправляют команды на прибор.
- Обработка сигнала работает только с предварительно импортированным PCAPNG, живой TCP/10230 отложен до подтверждения запуска потока.
- Приборы .83 (PCAPNG) и .84 (Modbus) — разные источники, показатели нельзя сопоставлять как синхронные.
