# MVK Reader Web v0.3.34 — Signal UI

Основа v0.3.33 (прямое развитие v0.3.32 NETWORK GUARD). Добавлен пункт «Сигнал TCP/10230» в существующее боковое меню. Прежние вкладки, Collector, SQLite, Plotly, безопасность и API без изменений.

На новой вкладке: выбор АЦП 1–8, осциллограмма исходных отсчётов, PSD, выбор длительности, FFT, диапазона и фильтра; для физических величин обязательно вручную вводить проверенную индивидуальную калибровку м/с² на сырой отсчёт. Отображение PSD НЕ равнозначно амплитудному спектру MVKView.

Запуск как прежде: START_INTEGRATED_WINDOWS.cmd. Импорт сигнала до запуска: `python -m signal_bridge.import_capture "C:\captures\file.pcapng" --device 10.13.42.83 --output signal_data`. Без импортированного сигнала вкладка показывает сообщение, остальные вкладки продолжают работать. Действующий прибор не опрашивается новым модулем.
