# MVK Reader Web v0.3.5 — System Diagnostics LAB

- Добавлена расшифровка документированной системной области Modbus: серийный номер 0x1000, прошивка 0x1004, битовая маска ошибок 0x1006, время наработки 0x1008, память 0x100A, MD5 DSP 0x100C, индикаторы перегрузки 0x1020.
- Добавлен read-only API `/collector/api/devices/{id}/diagnostics` и таблица состояния в Reader Web.
- Уточнены третьоктавные частоты: приложение 2 руководства прямо перечисляет **43** полосы 0,63–10000 Гц.
- Контрольные зоны НЕ реализованы: без подтвержденной карты регистров показывать не будем.
- Снятие данных с реальных приборов отсутствует. Настройки `interval_seconds=null`, `enabled=false` не изменены.
- Для появления диагностики сервер должен читать соответствующие диапазоны `0x1000...0x1020`; в демонстрационной конфигурации эти диапазоны намеренно не включены.
- Запросы к МВК01 — только FC03. Запись в SQLite допускается.
