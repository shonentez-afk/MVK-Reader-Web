# MVK Reader Web v0.3.17 — лабораторная сборка

Текущий релиз исправляет обработку отсутствующих данных и включает интеграционные тесты. Существующий офлайн-анализ BIN/TSXML сохранён.

## Запуск на тестовом Windows 11
1. Распаковать архив в отдельную папку.
2. В командной строке в папке проекта выполнить: `python -m pip install -r requirements.txt`.
3. Запустить: `python -m uvicorn integrated:app --host 127.0.0.1 --port 8080`.
4. В браузере открыть `http://127.0.0.1:8080`.
5. В разделе онлайн-приборов должен отображаться настроенный МВК01 №44 без опроса; это не подключение к прибору.
6. Для проверки тестов выполнить `python -m pytest -q` (если pytest не установлен: `python -m pip install pytest`).

## Безопасность
- В `collector/devices.json` прибор отключён (`enabled=false`), интервал не назначен (`interval_seconds=null`).
- Единственная реализованная Modbus-операция — функция 03 (чтение).
- В работе с данными сервера просмотр в браузере не инициирует опрос МВК01.
- Для доступа с других ПК необходимы отдельная настройка безопасности и сетевой доступ; текущий пример слушает только localhost.

## Открытые вопросы
PCAP реального MVKView потребуется для восстановления потока отсчётов. Не требуется для запуска лабораторного Reader Web.
