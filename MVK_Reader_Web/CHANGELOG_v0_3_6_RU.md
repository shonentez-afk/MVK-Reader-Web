# MVK Reader Web v0.3.6 — Third Octave LAB

- Устранена ошибка интерфейса: документированная привязка 43 третьоктавных полос ускорения уже присутствовала в декодере, но экран АЦП утверждал обратное.
- Добавлен read-only API `/collector/api/devices/{id}/third-octave?channel=1..8`.
- Для АЦП 1–8 после таблицы выводится график третьоктавного СКЗ виброускорения (м/с²).
- Пустые и нечитаемые полосы остаются `null`, а не нулями; без данных график не строится.
- Не выдумываются спектры виброскорости и перемещения: их точная карта регистров требует отдельной проверки.
- Установки `enabled=false` и `interval_seconds=null` не изменены. Только FC03; тесты не подключаются к реальным МВК01.
- Не изменены алгоритмы анализа BIN/TSXML.
