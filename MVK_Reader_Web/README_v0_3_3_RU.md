# Запуск лабораторной сборки v0.3.3

Требуется Python 3.11–3.13. В каталоге проекта выполните:

```powershell
python -m pip install -r requirements.txt
python -m uvicorn integrated:app --host 127.0.0.1 --port 8080
```

Откройте http://127.0.0.1:8080/; в списке приборов нажмите «Подробнее», выберите АЦП и нажмите «Показать историю». Без опроса прибора и без ранее накопленных данных график останется пустым — это штатное поведение.

Конфигурация приборов: `collector/devices.json`. По умолчанию приборы `enabled:false`, `interval_seconds:null`. Не включайте промышленное оборудование до проверки реестра регистров, политики сетевых запросов и согласования эксплуатационных испытаний. SQLite-файл будет создан локально в `collector/collector.sqlite3`. Запуск через `.cmd` необязателен.
