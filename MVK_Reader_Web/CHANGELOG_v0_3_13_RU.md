# MVK Reader Web v0.3.13 — Data Freshness LAB

- Добавлены возраст текущего снимка (`age_seconds`) и достоверность актуальности (`freshness`) без обращения к прибору.
- Если для конкретного прибора назначен интервал опроса, данные старше 3 интервалов получают статус `stale` и не выдаются за текущие.
- Пока периодичность опроса не согласована (`interval_seconds: null`), актуальность остается `unknown`, без самовольного выбора порога.
- API `/collector/api/devices`, `/live`, `/measurements`, `/diagnostics`, `/third-octave`, `/channel-status` различают устаревшие данные.
- Добавлены тесты старения, восстановления и отсутствия лишних запросов Modbus.
- Фоновый сбор в поставке отключен, никаких управляющих Modbus-функций не добавлено.

**Ограничения:** это не реализация передачи временных сигналов. Контрольные зоны и протокол потока остаются открытыми задачами. Работа реального МВК01 не проверена.
