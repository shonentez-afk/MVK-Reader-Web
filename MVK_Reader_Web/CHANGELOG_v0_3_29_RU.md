# v0.3.29 — эксплуатационная диагностика SQL

- Добавлен read-only API GET /api/storage-diagnostics: проверка доступности, служебных таблиц, quick_check(1), режима журнала и времени ответа SQL.
- Запрос диагностики не обращается к устройствам МВК01.
- Тест повторного создания Collector на существующей базе подтверждает сохранность истории и конфигурации.
- Конфигурация пользователя и действующая база SQLite исключены из дистрибутива; обновление производить в отдельную папку, существующую базу не перезаписывать.
- Реальная нагрузка корпоративной сети и подключение к МВК01 пока не проверялись.
