# MVK Reader Web v0.3.7 — Channel Diagnostics LAB

- Реализовано чтение **битовых** индикаторов состояния каждого из АЦП 1–8 (`A+0x120`, A = 0x2000 + 0x200*N), согласно разделу 3.5.7 руководства.
- Поддерживаются документированные биты 0,4,5,6,10,11. Неизвестные биты сохраняются в `unrecognized_bits`; отсутствующие регистры не заменяются нулями.
- Отображение диагностических признаков добавлено в таблицу отдельного АЦП; системная диагностика теперь доступна также во вкладке «Состояние системы».
- Добавлен API `GET /collector/api/devices/{id}/channel-status?channel=1..8`.
- Раздел «Контрольные зоны» не выдаёт придуманные значения. Для него не подтверждена карта адресов/событий.
- Сбор регистров **не расширялся**: если необходимые регистры не включены в `read_ranges`, показания останутся недоступными.
- Не менялись частота опроса, `enabled=false`, алгоритмы BIN/TSXML. Нет запросов на запись в прибор.

Проверка: 26/26 тестов, синтаксис JavaScript `node --check` пройден. В браузере Windows 11 и с реальным прибором не тестировалось. Отладочные значения из регистров имеют статус предварительных до стендовой проверки.
