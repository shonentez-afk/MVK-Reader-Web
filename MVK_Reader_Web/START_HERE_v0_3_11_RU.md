# MVK Reader Web v0.3.11 — Resilience LAB

Лабораторное продолжение v0.3.10. Результат: 37 автоматических тестов пройдено (в том числе 3 новых теста планировщика). Четыре предупреждения FastAPI о `on_event` остались.

## Запуск на тестовом Windows 11
1. Распаковать архив в отдельную папку.
2. В терминале в папке проекта выполнить `python -m pip install -r requirements.txt`.
3. Выполнить `python -m uvicorn integrated:app --host 127.0.0.1 --port 8080`.
4. Открыть в браузере `http://127.0.0.1:8080`.

Адреса МВК01 задаются только в `collector/devices.json`. В комплекте демонстрационная запись выключена (`enabled: false`), а интервал отсутствует (`interval_seconds: null`). Это означает **никакого автоматического сетевого опроса**. Не включайте реальные приборы до отдельного согласованного испытания. Не задавайте частоту без замеров нагрузки.

`/collector/api/server-status` содержит поле `polling_scheduler`: состояние повторных попыток, длительность и тип последней ошибки. Это только диагностическая информация.

## Ограничения
Реальные МВК01 не тестировались. Живые осциллограммы, потоковый протокол и контрольные зоны остаются исследовательскими задачами. Не путать лабораторные тесты с испытаниями промышленной эксплуатации. SQL используется SQLite.
