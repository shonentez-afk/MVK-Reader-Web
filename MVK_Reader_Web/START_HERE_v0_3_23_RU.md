# Запуск v0.3.23 на Windows 11

1. Распакуйте архив в новую папку. Старую сборку и её базы данных сохраните.
2. В CMD в папке проекта выполните `python -m venv .venv`, затем `.venv\Scripts\python.exe -m pip install -r requirements.txt`.
3. Запустите `.venv\Scripts\python.exe CHECK_PC.py`, затем `.venv\Scripts\python.exe START_READER.py`.
4. Откройте http://127.0.0.1:8080, зайдите в «Архив» и нажмите «Сведения».

Архивная SQLite и данные находятся отдельно от исходников, пути можно сохранить через `MVK_DATA_DIR`. Не копируйте файлы БД во время работы без резервного копирования.

Автоматический опрос приборов отключён. Реальные МВК01 не подключайте до согласованного теста.
