# MVK Reader Web v0.3.40 — Расчётные данные: Live / Archive

База: v0.3.39. Во вкладке «Расчётные данные» в режиме Live используется `/collector/api/devices/{id}/measurements` (последний ответ Modbus FC03), с обновлением каждые 5 секунд при активной вкладке. В режиме Archive используется `/collector/api/devices/{id}/series` (SQLite, последний исторический отсчёт 10–3000 Гц виброскорости на каждый из восьми АЦП) с отдельной явной подписью архивного источника. Показатели без архивных значений отмечаются «—». Изменений процесса опроса или команд TCP/10230 нет.

Ограничение: архивное представление пока показывает только последний сохранённый показатель одной полосы по АЦП; расширенный выбор исторических полос и времени остаётся в планах. Для полной истории используйте существующий раздел «Архив». Не запускалось на промышленном приборе.
