# Начало работы с v0.3.22

Сначала сохраните копию каталогов data и collector из используемой версии. Распакуйте сборку в новую папку, установите зависимости из requirements.txt.

Запуск на Windows: `.venv\Scripts\python.exe START_READER.py` после создания .venv и установки зависимостей. Откройте http://127.0.0.1:8080.

Во вкладке «Архив» доступны фильтры по номеру прибора, АЦП и датам измерения, кнопки открытия осциллограммы и спектра. Пока это фильтрация по уже загруженным записям BIN/TSXML, не SQL-история Collector.

В тестовой конфигурации подключение к приборам отключено.
