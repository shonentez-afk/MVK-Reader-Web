# MVK Reader Web v0.3.2 — decoded registers LAB

Основа: v0.3.1 Integrated LAB. Офлайн-анализатор BIN/TSXML сохранен без изменений.

## Новое
- `collector/decoder.py`: безопасное преобразование полностью считанных соседних регистров Modbus в IEEE754 float32 (Big Endian) по ВАРБ.411711.112 РЭ, приложение 2, страницы 50–52.
- Поддержаны блоки АЦП 1–8 (A=0x2000+N*0x200): напряжение датчика, пик-фактор, общее ускорение до 25 кГц, 8 групп по три СКЗ, 24 эквивалентных ПИК, 24 эквивалентных ПИК-ПИК, 43 элемента спектра ускорения. Флаги статуса оставлены сырыми до проверки спецификации.
- Поддержаны тахометры 1–2 (A=0x3000+N*0x100): частота вращения, среднее приращение, код ошибки датчика (сырой).
- Endpoint GET `/collector/api/devices/{id}/measurements` для декодированных данных; никакие запросы Modbus при его вызове не отправляются.
- Экран списка приборов теперь показывает реальные расшифрованные значения при наличии считанных регистров, не подставляет фиктивные значения.
- 3 теста декодера, 15 тестов успешно.

## Важно
- Все приборы в devices.json отключены; `interval_seconds` = null. Автоматического опроса нет. Частота будет определена после испытаний.
- Чтобы получить измерения, необходимо настроить `read_ranges` на сервере, включить прибор и отдельно согласовать запуск опроса. Не включайте оборудование в испытательную сеть без согласования.
- Веб-клиент читает кеш сервера, не обращается к МВК01.
- Третьоктавный массив содержит 43 элемента согласно таблице регистров, хотя в другом месте руководства приведен список 42 полос. Соответствие индексов частот нужно подтвердить отдельно; в UI пока нет ошибочной разметки.
- Состояния канала требуют дополнительной расшифровки формата из руководства.
- Поток реального времени для осциллограмм по-прежнему не реализован и не имитируется чтением Modbus.
- SQL SQLite содержит исходные регистры, что позволяет повторно расшифровывать снимки при уточнении форматов; нормализованные таблицы истории измерений — следующий шаг.
