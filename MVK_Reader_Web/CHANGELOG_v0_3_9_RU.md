# MVK Reader Web v0.3.9 — Multi-device integration LAB

## Сделано
- Испытана работа двух одновременно доступных локальных эмуляторов Modbus/TCP с разными значениями регистров.
- Проверена раздельность SQL-истории по номерам приборов.
- Проверена потеря соединения: старый снимок остаётся в истории, но не выдаётся как текущие данные.
- Проверено отсутствие запросов к МВК01 при чтении кэша, SQL-истории и трендов из интерфейса.
- Исключено ошибочное состояние «подключён» при включённом приборе с пустым списком регистров для чтения.
- Добавлена защита от одновременных ручных опросов одного и того же прибора.
- Сохранена только Modbus FC03; частота автоматического опроса НЕ задана.

## Испытания
`python -m pytest -q` — 32 passed, 4 warnings (FastAPI on_event deprecation).
Все эмуляторы прослушивают только loopback 127.0.0.1. Никакого обращения к производственным приборам.

## Ограничения
- Это лабораторная версия. Протокол потоковых осциллограмм пока не установлен.
- Настоящие МВК01 не подключались. Математическое декодирование физических величин нуждается в контрольном сравнении с прибором.
- Контрольные зоны остаются неподтверждёнными.
- Частота опроса устанавливается позднее после обследования сети.
- Дополнительная защищённость для развёртывания в корпоративной сети (авторизация, TLS, ACL, резервное копирование) не завершена.
- Полное тестирование в браузере Windows 11 не проводилось.
