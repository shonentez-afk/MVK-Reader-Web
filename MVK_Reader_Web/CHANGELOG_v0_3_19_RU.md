# v0.3.19 — History Button Fix (LAB)

Исправлена обратная связь кнопки «Показать историю» на карточке МВК01. Сообщение отображается рядом с кнопкой даже при пустой SQL-базе. Добавлено состояние загрузки, сообщение об ошибке, счётчик точек, повторное включение кнопки после запроса. SQL API и настройки опроса приборов не изменены.

Для установки на ПК: остановить сервер Ctrl+C, сохранить при необходимости свою папку collector/ и перенести исходную конфигурацию/базу. Затем распаковать новую сборку в отдельную папку, заново создать .venv и запустить CHECK_PC.py / START_READER.py. Нельзя удалять старую SQLite-базу, если есть измерения.
