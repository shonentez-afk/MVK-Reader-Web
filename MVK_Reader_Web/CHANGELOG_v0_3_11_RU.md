# MVK Reader Web v0.3.11 — RESILIENCE LAB

- Добавлен изолированный PollScheduler для фонового опроса уже настроенных приборов.
- Не задан ни один новый интервал: `interval_seconds: null` означает отсутствие опроса.
- При ошибке вводится ограниченная экспоненциальная пауза до следующей попытки; пауза не короче настроенного интервала.
- Счётчики подряд идущих ошибок, длительность последней операции, тип последней ошибки доступны в `/collector/api/server-status`.
- При восстановлении успешного чтения счётчик ошибок обнуляется.
- На отключённых приборах или приборах без интервала планировщик не выполняет сетевых запросов.

**Ограничения:** это лабораторный тестовый код без длительного испытания с реальным оборудованием. Механизм запуска FastAPI по-прежнему использует устаревающий `on_event`; его обновление требует совместной проверки Reader Web. Потоковые осциллограммы и реальные контрольные зоны не реализованы.
