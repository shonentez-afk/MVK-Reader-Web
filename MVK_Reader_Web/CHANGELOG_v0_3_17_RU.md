# MVK Reader Web v0.3.17 — Integration Contract LAB

## Исправления
- Backend: диагностика, третьоктавные спектры и состояние АЦП устойчивы к частично заполненным ответам декодера; отсутствующие поля возвращаются как null/пустые массивы, а не HTTP 500.
- Reader Web: отсутствие отдельных полосовых величин СКЗ/ПИК/ПИК-ПИК не приводит к ошибке JavaScript при отрисовке канала.
- Reader Web: на общей странице приборов явно отображается состояние `stale` («Данные устарели»).
- Добавлены 4 интеграционных сценария API: отсутствие измерений, неполный ответ, устаревшие данные и монтирование Collector в Reader Web.

## Проверено
