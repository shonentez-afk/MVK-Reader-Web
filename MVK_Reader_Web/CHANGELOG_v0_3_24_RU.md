# MVK Reader Web v0.3.24 — Archive Navigation LAB

- Сортировка архивных записей: новые даты сверху, затем имя файла.
- Выбор архивной записи из таблицы сразу для сигнала, спектра или отчётов.
- Навигация к предыдущей и следующей записи из экранов сигнала, спектра и отчётов.
- Показ номера записи в текущей отфильтрованной выборке и кнопка возврата к архиву.
- Автоматический выбор реально записанного канала при переключении записи.
- При удалении текущей записи навигация обновляется и выбранная запись сбрасывается.
- Modbus/Collector, расписание опроса и формулы не изменены.
