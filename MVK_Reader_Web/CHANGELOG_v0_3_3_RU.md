# MVK Reader Web v0.3.3 — SQL Measurement History LAB

## Выполнено
- Отдельная SQL-таблица `measurements` с индексом для исторических рядов по номеру прибора, типу канала, показателю и полосе.
- Во время успешного чтения FC03 сохраняются одновременно сырой снимок регистров и только реально расшифрованные конечные значения (нет подставленных нулей).
- API `/collector/api/devices/{id}/series?channel_type=adc&channel=1&metric=rms&band=10-3000:velocity` для чтения ранее накопленного ряда без сетевого обращения к прибору.
- На карточке прибора Reader Web — просмотр истории СКЗ виброскорости 10–3000 Гц по любому из восьми АЦП.
- Дополнительные автоматические тесты SQL истории и отключенного прибора.

## Границы и безопасность
- Опрос приборов по умолчанию выключен; частота не назначена.
- Декодер использует предыдущие экспериментально непроверенные привязки регистров, поэтому измерения должны быть сверены с настоящей MVKView до эксплуатационного применения.
- Просмотр истории читает только SQL, а не прибор.
- Потоковые осциллограммы и полноценное развертывание в производственной ЛВС не готовы.
- Web API без авторизации: не открывайте его в недоверенные сети.
- Modbus клиент отправляет только FC03, других функций записи в коде нет.
