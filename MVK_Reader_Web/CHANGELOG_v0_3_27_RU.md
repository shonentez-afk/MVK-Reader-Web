# v0.3.27 — устойчивость истории и производительность

- Убрана оконная функция ROW_NUMBER() из обработки больших SQL-трендов.
- Обзор строится потоковым проходом по индексированной серии, по-прежнему сохраняя min/max.
- Запоздавшие ответы истории не перерисовывают экран другого прибора.
- Не меняет Modbus, сеть приборов, частоту опроса и права на запись.
