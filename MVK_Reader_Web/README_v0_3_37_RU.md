# MVK Reader Web v0.3.37 — выбор МВК01 и режимов

База: v0.3.36; прежний UI, API и NETWORK GUARD сохранены.

Новая общая панель: выбранный прибор из реестра Collector и режим представления «Реальное время / Архив». Выбор сохраняется локально в браузере. API GET /api/mvk/devices и GET /api/mvk/capabilities.

ОГРАНИЧЕНИЯ: панель режимов пока представляет интерфейсный каркас. Архивный расчёт TCP/502 всё ещё осуществляется через существующие историю/Архив и API, без автоматического переключения всех запросов. Список устройств редактируется в collector/devices.json по прежнему правилу, изменение конфигурации из UI пока не реализовано. Подключение/команда запуска TCP/10230 отсутствуют. Нет автоматической записи нового сигнала или управления сессиями. У прибора TCP/502 в конфигурации настраиваемый порт (по умолчанию должен быть 502 на рабочем приборе). В комплекте лабораторная конфигурация 127.0.0.1:15020, disabled.

Запуск: используйте прежние стартовые сценарии v0.3.36.
