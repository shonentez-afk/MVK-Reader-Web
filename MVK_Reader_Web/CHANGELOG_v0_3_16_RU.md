# v0.3.16 — OFFLINE STREAM DIAGNOSTICS LAB

Добавлен `pcap_stream_diagnostics.py`: анализирует **два сохранённых PCAP** (без соединения с МВК01), сопоставляет направления потоков, нормирует полученные байты по длительности каждого TCP-потока, сообщает о пропусках TCP и отмечает кандидатов на передачу сигнала. Выводится только метаинформация. Декодер осциллограмм и команды управления прибором не добавлялись.

## Использование

Из каталога проекта:

```powershell
python pcap_stream_diagnostics.py idle.pcap signal.pcap --output stream_report.json
```

`idle.pcap` — подключение MVKView без просмотра временного сигнала; `signal.pcap` — сопоставимый по условиям сеанс с временным сигналом. Поддерживаются **классические PCAP Ethernet/IPv4/TCP**; PCAPNG пока не поддерживается.

## Контроль

`python -m pytest -q` — 49 passed (автоматические тесты на симулированных данных).

Важные ограничения: кандидаты на поток не подтверждают формат отсчётов; при пропусках TCP нельзя заключать о структуре кадров; неизвестные TCP-потоки сохраняются **без экспорта содержимого**. Реального PCAP МВК01 нет. Фоновый интервал опроса не назначен, конфигурация реальных приборов не активирована.
