MVK Reader Web v0.3.18 — ПОДГОТОВКА К ЗАПУСКУ НА WINDOWS 11

ВАЖНО: это лабораторная версия; не подключайте к производственным приборам.
По умолчанию все приборы выключены и интервал опроса не назначен.

1. Распакуйте ZIP в обычную папку, например C:\MVK_Reader_Web.
2. Откройте терминал в папке проекта (в Проводнике в адресной строке набрать cmd и нажать Enter).
3. Рекомендуется Python 3.13 x64. Проверить: python --version.
   Если установлен Python 3.15, совместимость пакетов numpy/scipy с ним не гарантируется:
   для данного испытания используйте отдельный Python 3.13.
4. Создать окружение: python -m venv .venv
5. Установить зависимости: .venv\Scripts\python.exe -m pip install -r requirements.txt
6. Самопроверка: .venv\Scripts\python.exe CHECK_PC.py
7. Запуск: .venv\Scripts\python.exe START_READER.py
8. Открыть в браузере: http://127.0.0.1:8080
9. Завершить: Ctrl+C в окне терминала.

ЧТО ПРОВЕРИТЬ:
- Главная страница загружается.
- МВК01 №44 отображается как not_polled / без опроса.
- Открывается раздел анализа файлов BIN + TSXML.
- Системные страницы API: /collector/api/devices и /collector/api/server-status.

Для работы с приборами нельзя менять enabled=false без отдельного согласованного испытания.
Сборка слушает только 127.0.0.1 и недоступна другим компьютерам.
Реальная передача осциллограмм и контрольные зоны ещё не закончены.

Если возникают проблемы: пришлите вывод CHECK_PC.py и текст ошибки из терминала.
