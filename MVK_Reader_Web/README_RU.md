# MVK Collector Server v0.3.0 LAB — первый этап

Это независимый безопасный прототип для чтения МВК01 и записи сырых регистров в SQLite. Существующий `reader_web/` сохранён как исходная версия v0.2.1.2, пока **НЕ интегрирован** с Collector.

## Windows 11

1. Установить Python и выполнить из каталога пакета: `py -m pip install -r requirements.txt`.
2. Изменить `collector/devices.json`: задать **номер МВК**, IP, порт, разрешённые диапазоны регистров, `enabled`.
3. По умолчанию `enabled:false`, `interval_seconds:null` — сетевых запросов к приборам нет. Интервал намеренно не выбран.
4. Запустить `START_COLLECTOR_WINDOWS.cmd`, проверить `http://127.0.0.1:8091/api/health` и `http://127.0.0.1:8091/api/devices`.

## Доступные API

- `GET /api/devices` — номера приборов и статусы;
- `GET /api/devices/{id}/live` — последний ответ;
- `GET /api/devices/{id}/history` — история сырых регистров из SQLite.

Сырьё регистров пока **не объявляется** виброскоростью, СКЗ или состоянием прибора до реализации и проверки карты регистров из приложения 2 РЭ. Отсутствие `interval_seconds` исключает фоновый опрос. SQL хранит историю прочитанного, не изменяя МВК. Протокол клиента реализует только функцию 0x03, одно завершённое обращение без конвейеризации, таймаут 1 секунда.

**Важно:** API лабораторное, без авторизации, слушает только 127.0.0.1. Не публиковать в производственную сеть. Не менять `enabled` на true для настоящих устройств до согласования программы испытаний. Read-only по отношению к МВК; не записывает регистры, не подтверждает аварии и не перезагружает прибор.
