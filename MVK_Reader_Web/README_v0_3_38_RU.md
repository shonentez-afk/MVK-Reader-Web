# MVK Reader Web v0.3.38 Device Manager

База: v0.3.37. Реестр приборов доступен в существующем Reader Web, отдельный новый интерфейс не создаётся.

- GET/POST /api/mvk/devices; PUT/DELETE /api/mvk/devices/{id}.
- Изменения только для отключённых приборов; новые карточки disabled, interval_seconds=null.
- Настройки сохраняются атомарно в collector/devices.json, затем Collector перечитывает конфигурацию.
- Для каждого прибора независимо показывается status TCP/502 и not_implemented TCP/10230.
- Конфигурация не включает живой TCP/10230 и не передаёт прибору команды.
- NETWORK GUARD сохраняется: API доступно только локальному клиенту.

Необходимо отдельно согласовать и реализовать включение опроса TCP/502 через интерфейс; текущий релиз не запускает его при добавлении.
