# MVK Reader Web v0.3.4 — Calculated Tables LAB

## Реализовано
- Раздел «Расчётные данные» подключен к API MVK Collector Server, в том числе выбор прибора по номеру, заданному в серверной конфигурации.
- Таблицы «Все каналы СКЗ», «Все каналы ПИК», «Все каналы ПИК-ПИК» по АЦП 1–8, всем восьми объявленным полосам и трём физическим величинам.
- Для АЦП 1–8 доступны индивидуальные таблицы и напряжение датчика, при наличии считанных регистров.
- Для тахометров 1–2 отображаются доступные поля, без неподтвержденной интерпретации кода ошибки.
- «Состояние системы» и «Контрольные зоны» явно отмечены как ожидающие подтверждения регистров; фиктивных результатов нет.
- Офлайн-подсистема Reader Web и SQL Collector не изменены.

## Испытания
- pytest: 17 passed (включает существующие тесты Modbus, декодирования и SQL).
- node --check: синтаксис встроенного JavaScript проверен.
- Физический прибор и браузерный UX в Windows не испытывались.

## Безопасность
- Только Modbus FC03. IP задается только в collector/devices.json.
- В поставляемой конфигурации enabled=false и interval_seconds=null; автоматические запросы к прибору отсутствуют.
- Полные таблицы появятся после настройки правильных read_ranges и успешного получения данных.

## Дальнейшие работы
- Подтверждение адресов диагностики/контрольных зон по полным таблицам приложения 2 и безопасные тесты на эмуляторе.
- Третьоктавные частоты: в текущем декодере 43 float-ячейки без подтвержденной частотной привязки; не подписывать автоматически как 42 полосы.
- Реальные браузерные тесты с Windows 11, затем испытания прибора по согласованному плану.
- Частота опроса остается неутвержденной.
