# Проверка калибровочных регистров MVK01 по TCP/502

Это отдельный диагностический инструмент. Он **не изменяет настройки прибора**: только FC03 (чтение Holding Registers). Он **не подключается** без явного флага `--confirm-read`.

Перед тестом согласуйте чтение на работающем оборудовании с ответственным специалистом. Программа может встретить Modbus exception при недоступности адресов. При ошибке каждого запроса продолжает остальные. Внешний таймаут 2 секунды; каждое чтение устанавливает отдельное TCP соединение; 17 небольших последовательных запросов, задержка 120 мс.

## Порядок действий

1. Открыть Wireshark и включить захват сетевой карты, через которую доступен МВК01. Display filter: `ip.addr == 10.13.42.84 && (tcp.port == 502 || tcp.port == 10230)` (подставить IP нужного прибора). Display filter не заменяет запуск захвата.
2. Запустить MVKView и записать стабильный поток временного сигнала 10–20 секунд.
3. **Если опрос разрешён**, отдельно выполнить команду из CMD для того же прибора:

```cmd
py -3 probe_fc03.py --host 10.13.42.84 --confirm-read --output calibration_84.json
```

4. Сделать экспорт BIN+TSXML того же АЦП в MVKView, отметить номер АЦП, время и экранный показатель пика/СКЗ.
5. Отключиться от МВК01 штатным способом в MVKView. Остановить захват Wireshark и сохранить PCAPNG.
6. Передать `calibration_84.json`, PCAPNG, BIN+TSXML. Не изменять настройки датчиков ради теста.

## Что запрашивается

- `0x0020`, 16 регистров: 8 float32 коэффициентов АЦП в вольтах на максимальную амплитуду.
- Для АЦП N (0..7) A = `0x0100 + N*0x0100`: `A+0x02`, 2 регистра — коэффициент датчика в В/(м/с²); `A+0x0E`, 2 регистра — автоматически вычисляемый коэффициент.

Адреса и количество регистров соответствуют таблицам 3.1 и 3.2 приложения 2 к ВАРБ.411711.112 РЭ. В сохранённых прежних ответах FC03 эти адреса не опрашивались. Некоторые прошивки могут отклонить запросы; результат с кодом ошибки тоже полезен.

Отчёт сохраняет HEX-ответы, коды ошибок и альтернативные порядки байтов ABCD / CDAB / BADC / DCBA. **Не выбирайте правильный порядок по одному похожему числу:** требуется сопоставление с настройкой 0,01019 и другими физически ожидаемыми величинами.

Отдельно: порт TCP/10230 — поток временных отсчётов и спектры, его инициализацией занимается MVKView; данная утилита вообще не обращается к 10230.
