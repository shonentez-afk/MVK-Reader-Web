# MVK IDR Bridge — быстрый запуск на Windows

1. Распакуйте архив `MVK_IDR_Bridge_v1_Ready.zip` в `C:\MVK_IDR_Bridge\` (либо в другую папку без ограничений прав).
2. Убедитесь, что установлен Python 3.10+ и в PowerShell работает `py -3 --version`.
3. При необходимости исправьте путь к `.cmd` в `mcp_config_example.json`; перенесите его содержимое в **раздел MCP вашего конкретного клиента** (DeepSeek Harness, Cline и т. п.). Запустите/переподключите клиент.
4. MCP-сервер запустится командой `run_mcp.cmd`, не будет открывать оригинальную MVKView и не будет обращаться к прибору.
5. В чате MCP-клиента попросите вызвать `idr_stats`, затем `idr_component` с `name=bTaskConnect`, `idr_callers` c `address=007D13D4`, `idr_event_chain` c `component_name=bTaskView`.
6. Если MCP-клиент не отображает сервер, откройте CMD, выполните `py -3 -u C:\MVK_IDR_Bridge\mcp_server.py --db C:\MVK_IDR_Bridge\data\mvk_idr.sqlite --sources C:\MVK_IDR_Bridge\data\sources`. Успешный MCP stdio-процесс **не показывает графическое окно и ожидает сообщения по стандартному вводу**. Завершите проверку Ctrl+C; диагностируйте ошибки Python или пути.

Внутри `data/sources` находятся 129 PAS + 3 DFM + 1 DPR из твоего исходного `Projects.7z`. Это **закрытая локальная копия** для просмотра восстановленных строк методом `idr_code`; не публикуйте этот каталог в общедоступном репозитории. Исходный IDP в архив не дублируется: его метаданные уже извлечены в базу.

Результаты статического анализа нельзя использовать как доказательство запуска измерения или правильности аппаратных операций. MCP предоставляет **только чтение данных**.
