# Пассивный тест TCP/10230 — адаптер Ethernet

Для Windows используется **сетевой адаптер с точным именем `Ethernet`** (по предоставленному пользователем скриншоту). Скрипт через PowerShell `Get-NetAdapter` и `Get-NetIPAddress` узнаёт его IPv4, затем **делает bind к этому локальному адресу перед connect**.

Если адаптер выключен или нет допустимого IPv4, соединение не начинается. Если IPv4 несколько, скрипт требует явного `--bind-ip`; при завершении записывает адрес источника в JSON. Привязка не изменяет маршрутизацию ОС; если сеть недоступна с адреса Ethernet, connect завершится ошибкой.

**Никакие прикладные данные на TCP/10230 не отправляются.** Однако обычное TCP-подключение создаёт обмен SYN/ACK/FIN и может вызвать поток на приборе.

## Запуск
Только с разрешения на испытание: закрыть MVKView, настроить Wireshark на нужный Ethernet, запустить `RUN_TEST.cmd` и выбрать прибор. Скрипт принимает до 12 секунд или 40 МиБ, сохраняет `results/*.raw` и `*.json`. Сохранить PCAPNG отдельно для анализа рукопожатия.

С явным адресом Ethernet:

```cmd
py -3 passive_test.py --host 10.13.42.84 --bind-ip 10.13.42.100
```

`10.13.42.100` — пример, **не подтверждённый адрес ПК**. Для других ОС требуется `--bind-ip`, имя интерфейса в них автоматически не определяется.

Эти утилиты запускаются отдельно; запуск основной программы MVK Reader Web v0.3.40 не требуется. Данный сценарий ещё **не проверен на работающем МВК01**.
