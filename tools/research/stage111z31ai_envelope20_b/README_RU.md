## Использование на рабочем Windows-ПК

**Не запускать без отдельного разрешения.** Локальные оригинальные инструменты лежат в `C:\MVK_TOOLS\Z31R_LOCAL\src`. Сценарии лучше скачать в отдельную папку `C:\MVK_TOOLS\Z31AI_B_REVIEWED`, не перезаписывая источники.

Создать чистые папки:
```powershell
New-Item -ItemType Directory -Force 'C:\MVK_LOG\STAGE111Z31AI_B_CAPTURE\B'
```

Поместить `capture_config.json` непосредственно в `C:\MVK_LOG\STAGE111Z31AI_B_CAPTURE`, сценарий использует абсолютный путь `C:\MVK_LOG\STAGE111Z31AI_B_CAPTURE`. Проверить, что этой папки не было от предыдущего неудачного запуска: `savedata` может заменить старые файлы. Не сохранять в эталон `Z31R_20261110_091023_bb6fb473`.

Перед запуском проверить live EIP14AA, PID/TID/EBX/EBP, `[EBX+4]=262195`, `[EBX+8]=20`, `[EBX+18]=0`, `[EBX+20]=557107`, FRange и исходный файл. Исправленный сценарий **сам** продолжает процесс до 1900 и **не предусматривает ручную промежуточную проверку на 153D**; если нужен промежуточный ручной контроль, не использовать его, подготовить двухфазный вариант.

После **отдельно разрешённого выполнения** запускать:
```powershell
python Verify-Capture-Code20-BOnly.py C:\MVK_LOG\STAGE111Z31AI_B_CAPTURE
```

На нештатном EIP или ошибке — не нажимать F9, не повторять скрипт; сохранить хэшированные результаты, лог и точный регистр EIP. Приватные BIN, IDP, EXE и сырой дамп в открытый GitHub не публиковать. GitHub ведёт ChatGPT.
