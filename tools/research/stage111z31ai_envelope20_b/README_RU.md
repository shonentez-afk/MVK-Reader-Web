# STAGE111Z31AI: исправленный EnvelopeCode20 B-ONLY захват

**Статус: offline-reviewed, x32dbg runtime ещё не выполнялся.** Не запускать до явного разрешения пользователя и повторного read-only подтверждения остановки `EIP=007D14AA`.

В качестве основы использован исходный Z31R v1.5. Исправлен опасный перенос `rawN=262195` на preFFT: **rawN=262195 → stage5 51 taps/decim2 → FFTN=131072 → Power/Y=65536**, Fs 65536→32768. По приватному `_Unit115.pas` длина `[EBX+4]` пересчитывается до `007D153D`, а `[EBX+28]` выставляется до `007D154B`. Это source-derived ожидание, не runtime PASS.

## Файлы

- `RESUME_B_CODE20_Z31AI_REVIEWED.txt`: жёсткие guard для Mode0, Code20, rawN262195, WindowEnd557107, storage oldest294912, capacity2097152, mask0x1fffff, FRange0x43ff4853, далее FFTN131072 и Fs32768 на 153D, halfN65536 на 154B. Пять `run` переходов 14AA→14B8→153D→154B→17E7→1900 с full snapshots; при FAIL оставляет остановку без автоматического повтора.
- `Verify-Capture-Code20-BOnly.py`: отдельный офлайн B-only verifier, НЕ требует A/, проверяет все 6 snapshots, размеры arrays, исходную работу `work_raw.bin` по заранее подтверждённому SHA `868562...949c5`, source position, FRange, ring geometry, summaries. Успешный структурный отчёт **не является** доказательством численной parity.
- `capture_config.json`: полноценный JSON, только для этого конкретного ADC1-окна.

## Использование на рабочем Windows-ПК

**Не запускать без отдельного разрешения.** Локальные оригинальные инструменты лежат в `C:\MVK_TOOLS\Z31R_LOCAL\src`. Сценарии лучше скачать в отдельную папку `C:\MVK_TOOLS\Z31AI_B_REVIEWED`, не перезаписывая источники.

Создать чистые папки:
```powershell
New-Item -ItemType Directory -Force 'C:\MVK_LOG\STAGE111Z31AI_B_CAPTURE\B'
```

Поместить `capture_config.json` непосредственно в `C:\MVK_LOG\STAGE111Z31AI_B_CAPTURE`, сценарий использует абсолютный путь `C:\MVK_LOG\STAGE111Z31AI_B_CAPTURE`. Проверить, что этой папки не было от предыдущего неудачного запуска: `savedata` может заменить старые файлы. Не сохранять в эталон `Z31R_20261110_091023_bb6fb473`.

Перед запуском проверить live EIP14AA, PID/TID/EBX/EBP, `[EBX+4]=262195`, `[EBX+8]=20`, `[EBX+18]=0`, `[EBX+20]=557107`, FRange и исходный файл. Исправленный сценарий **сам** продолжает процесс до 1900 и **не предусматривает ручную промежуточную проверку на 153D**; если нужен промежуточный ручной контроль, не использовать его, подготовить двухфазный вариант.

После **отдельно разрешённого выполнения** запускать:
```powershell
python Verify-Capture-Code20-BOnly.py C:\MVK_LOG\STAGE111Z31AI_B_CAPTURE
```

На нештатном EIP или ошибке — не нажимать F9, не повторять скрипт; сохранить хэшированные результаты, лог и точный регистр EIP. Приватные BIN, IDP, EXE и сырой дамп в открытый GitHub не публиковать. GitHub ведёт ChatGPT.

Список доказанной части: Stage111Z31AH подтвердил bitwise input и physical BIN; **FIR/FFT/LOG Y оригинала после фильтра 20 ещё не сняты**.
