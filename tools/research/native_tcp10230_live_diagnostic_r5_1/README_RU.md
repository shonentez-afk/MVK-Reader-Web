# MVK10230 Diagnostic R5.1 — Windows x64, явный Ethernet

29 октября 2026. Независимый диагностический приёмник оригинального MVK01. Исходники Go включены в комплект. **Транспорт — только TCP/10230** поверх IPv4. Документация Modbus/502 использовалась исключительно как справочная карта регистров, Modbus TCP здесь нет.

## Почему обновлена R5

R5 устанавливает `net.DialTimeout("tcp", targetIP:10230)` и сразу читает: это **правильная модель запуска потока самим соединением**, без команды запуска прибора. Но R5 позволяла Windows самостоятельно выбрать исходящую сетевую карту по таблице маршрутов. На ПК с проводным Ethernet, Wi-Fi и VPN такой выбор может оказаться неверным.

R5.1 устраняет это ограничение в **LIVE**:
- Показывает сетевые адаптеры UP, не loopback, с назначенным IPv4 (название, индекс, адрес, префикс, MAC).
- Требует явного выбора проводного адаптера при двойном щелчке; в командной строке — обязательный `-local-ip`.
- Сопоставляет выбранный IP с реально назначенным локальным интерфейсом; не разрешает произвольный или отсутствующий адрес.
- Использует `net.Dialer.LocalAddr` для конкретного IPv4. В Windows дополнительно устанавливает `IP_UNICAST_IF=31` (Winsock) с индексом интерфейса в network byte order. Ошибка настройки интерфейса **не** вызывает автоматическое переключение на другой маршрут.
- Проверяет после соединения `LocalAddr()` и фиксирует фактические адреса в `summary.json`, `summary_ru.txt` и `events.log`.

Оператор должен выбрать **физический проводной Ethernet** по названию Windows; медиатип автоматически не определяется. Для полноты проверки на конкретной Windows требуется реальный тест.

## Запуск без терминала

Запустить `MVK10230_Diagnostic_R5_1_Windows_x64.exe` двойным щелчком. Ввести IP МВК01, длительность (рекомендуется 15 секунд), номер Ethernet-адаптера и подтверждение `YES` после разрешения на подключение.

## Дополнительные параметры

```text
MVK10230_Diagnostic_R5_1_Windows_x64.exe -list-interfaces
MVK10230_Diagnostic_R5_1_Windows_x64.exe -ip 192.168.1.83 -local-ip 192.168.1.100 -seconds 15 -approve
MVK10230_Diagnostic_R5_1_Windows_x64.exe -replay DEMO_SYNTHETIC.raw -out OFFLINE_RESULTS
```

В этих примерах адреса условные и должны быть заменены реальными. Опция `-list-interfaces` не подключается к прибору. `-replay` вообще не использует сеть. Живой режим командной строки не разрешает автоопределение исходящего интерфейса.

## Что делает TCP-программа

1. Устанавливает **одно** TCP/IPv4-соединение с указанным МВК01:10230 через выбранную локальную карту.
2. Не передаёт никакого прикладного payload, команды выбора частоты, настройки, Flash или reboot.
3. Переходит непосредственно в `Read()`; прибор при открытии сокета должен начать поток, по имеющимся данным пользователя.
4. Сохраняет `incoming.raw` целиком, таблицу входящих порций `chunks.csv`, идентификаторы кадров в `frames.csv`, расчётные каналы в `aux4700.jsonl`, события и JSON/русский отчёты.
5. Через заданное время или лимит размера закрывает соединение и упаковывает результаты в `MVK10230_TEST_RESULTS.zip`.

**Никаких исходящих команд МВК01 в программе нет.** Штатные SYN/ACK/FIN и управляющие пакеты TCP формирует операционная система; это не прикладной протокол МВК. Наличие подключения может занять единственный доступный слот на приборе. Использование согласовать с ответственным специалистом.

При нераспознанном или повреждённом сообщении программа сохраняет все последующие байты в `incoming.raw`, но не выдаёт некорректные значения за вычисленные. Это диагностика, а не штатный контроль или поверенный измеритель. Исходный сетевой поток **не** равен калиброванному BIN MVKView.

## Исследовательские проверки

Go unit tests: **13/13 PASS**, `go vet` и `go test -race` пройдены в контейнере Linux. Архивный replay `DEMO_SYNTHETIC.raw` дал 15 кадров, 1 AUX4700, 1 снимок; архивный реальный фрагмент «83 спектр» (20 МиБ) — 25 512 кадров, 18 AUX4700, 1 снимок, 188 байт незавершённого хвоста. Локальный тест TCP-сервера подтверждает отсутствие исходящих прикладных байтов. Windows x64 PE собран кросс-компилятором Go; **нативный Windows runtime, Windows IP_UNICAST_IF на рабочей сетевой карте и настоящий МВК01 в этом тесте НЕ проверены**.

Для разработчика: `go test ./...` и `GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -o MVK10230_Diagnostic_R5_1_Windows_x64.exe .`. В комплект входят файлы с Windows и не-Windows реализациями назначения интерфейса и unit tests.

## Данные и ограничения

Не публикуйте диагностический ZIP в открытом репозитории; он может содержать технологические данные. Не подключайтесь одновременно с MVKView без проверки, что МВК01 поддерживает более одного клиента. Доступность Ethernet/VLAN, допустимость подключения и настройку IP определяет персонал предприятия.
