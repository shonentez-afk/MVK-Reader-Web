# MVK10230 Diagnostic R5.1 — Ethernet исправление

**R5 оставлена как историческая предыдущая сборка.** Для первого испытания на МВК01 рекомендуется R5.1. Пользователю нужен только EXE.

Главное изменение: программа не полагается на автоматическую маршрутизацию Windows. Перед Live-тестом вы выбираете конкретную проводную сетевую карту. Исходящий сокет закрепляется за ней через локальный IPv4 и Windows IP_UNICAST_IF, а фактические адреса фиксируются в архиве результатов. При невозможности привязки программа останавливается.

Механизм активации потока **только подключением к TCP/10230 сохранён**; никаких команд МВК не отправляется.

Уровень готовности: код и Windows PE x64 собраны, 13 Go-тестов и архивный replay проходят; натурный тест на Windows + приборе ещё требуется.
