# Native R5.1 / Stage102: Ethernet NIC binding audit

Дата: 2026-10-29. Дополнение к проверенному Stage101 Native R5.

## Подтверждено в R5

`main.go` исходного R5: TCP `DialTimeout("tcp", 10230)` без передачи прикладных данных; затем только `SetReadDeadline` и `Read`. Это соответствует пользовательскому свойству МВК01: **само подключение активирует поток**. Значит, отдельную команду старта посылать не нужно. Но выбор Ethernet интерфейса исходный R5 **явно не контролировал** — это был пробел, даже если по таблице маршрутов Windows фактически выбирал Ethernet.

## Исправления в R5.1

- Обязательный явный выбор локального интерфейса при двойном щелчке или `-local-ip` из командной строки.
- Привязка источника `TCPAddr.IP`; в Win64 дополнительно Winsock IP_UNICAST_IF=31, индекс в сетевом порядке байтов. Подтверждено по Microsoft Windows WinSock API docs.
- После подключения программа подтверждает, что `LocalAddr.IP` совпадает с выбранным адресом, логирует локальный/удалённый сокет и адаптер, иначе останавливается без fallback.
- Отклоняются несуществующие или отключенные интерфейсы. Нет активации порта 502, исходящих команд, настройки прибора/маршрутизатора или попыток ping.

## QA

- `go test -count=1 ./...`: 13/13 PASS.
- `go vet ./...`: PASS.
- `go test -race -count=1 ./...`: PASS.
- Native Linux loopback TCP listener: payload от тестера 0 байт; со стороны сервера тестер получил identity, в `summary.json` сохранён фактический локальный сокет.
- `-list-interfaces`: список отображается, сетевой Dial не вызывается.
- Синтетический replay: 46 952 байта, 15 кадров, 1 AUX4700, 1 полный снимок, VALID_FRAMES.
- Реальный архивный replay «83 спектр» первые 20 МиБ: 20 971 520 байт, 25 512 кадров, 18 AUX4700, 1 снимок, 188 байт неполного хвоста, результат VALID_FRAMES_WITH_INCOMPLETE_LAST_FRAME.
- Windows PE32+ x64 собран успешно через Go cross compilation; реальная Windows-карта Ethernet и промышленный прибор НЕ тестировались. IP_UNICAST_IF проверен на уровне исходника и официального API, но реальный WinSock вызов не исполнялся.

## Ограничения

`net.Interfaces` позволяет показывать название адаптера, индекс, MAC, IPv4 и флаг UP; **не различает надёжно физический Ethernet, Wi-Fi и виртуальные интерфейсы**. Оператор выбирает правильную проводную карту по имени Windows. Интерфейс Windows после запуска не проверен физически: необходимо подтвердить на ПК прибора. Программа использует IPv4 через Ethernet, НЕ raw Ethernet протокол. При ошибке соединения дополнительный канал/порт или приложение MVKView автоматически не запускаются.

Никакие Live-соединения к МВК01 не выполнялись, никаких изменений stable v0.3.40.
