# Stage108 / R6.1 — независимая приёмка (29.10.2026)

## Что запускалось

- Объединённый Go-пакет: исходники Native R5.1 receive-only + Stage107 exporter + новый `LiveBinSpool` и мост автоматической атомарной публикации.
- Go tests: **39/39 PASS**, проверены синтетические корректные/повреждённые кадры, локальная безкомандная TCP-сессия, авторизация выбора NIC, запрет fallback, локальные часово́й пояс.
- `go vet ./...` и `go test -race -count=1 ./...`: PASS.
- `GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w"`: PE32+ Windows x64 PASS. `GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go vet ./...`: PASS. Тестовый Windows PE скомпилирован, **не выполнялся**.
- На локальном TCP/loopback отправитель отдал синтетический поток из ID264, полного REG32800, ADC×8 и AUX4700: устройство получило **0 байт** прикладных запросов; результирующие BIN/TSXML/VALUES/TABLE созданы и проверены.
- Проверено отсутствие записи любых MVK команд в сетевой код и отсутствие сетевых вызовов в экспортёре/потоковом BIN writer.

## Реальные офлайн-источники

## Проверки безопасности/отказов

- Отсутствие первоначальной валидной калибровки, недопустимые значения gain/NaN, разрыв ADC счётчика → экспорт `FAILED_CLOSED` или `REFUSED` с исходным RAW.
- Неверный SHA256 RAW, несовпадающий `frames.csv`, повторный вывод в готовую папку, повреждённый физический `.bin.partial` → публикации нет.
- Штатное ограничение времени с неполным последним кадром → только задокументированный хвост (с указанной длиной) исключён из расчётных файлов, исходный RAW сохранён побайтно; произвольное усечение по-прежнему ошибка.
- Аварийное закрытие соединения (`REMOTE_DISCONNECTED`) не объявляется нормальным завершением BIN.
- Все промежуточные BIN строятся только внутри скрытой `.stage108_live_calibrated_pending/`, а публикуются **после** независимой повторной верификации и атомарного переименования.
- `-export=false` оставляет оригинальную R5.1-диагностику без BIN.

## Непроверенное

**Windows Winsock `IP_UNICAST_IF` и пакет целиком на физическом Windows при подключении к МВК01 новой версии R6.1 ещё не проверены.** Стадия имеет Linux loopback + offline реальные PCAP/R5/R5.1 RAW + PE32+ crossbuild QA. Оригинальные TSV/XML/VALUES нового сеанса должны быть сравнены с MVKView. Отсутствие реакции оборудования на само TCP-подключение не доказывается отсутствием прикладных команд.
