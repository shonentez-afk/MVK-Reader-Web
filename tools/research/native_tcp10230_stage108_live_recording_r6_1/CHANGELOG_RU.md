# Stage108 / R6.1 — изменения относительно R5.1 и Stage107

1. Native Ethernet/TCP10230 из R5.1 без новых приборных команд.
2. Реальное поочерёдное поступление ADC кадров сразу записывает 8 скрытых файлов `ADC*.bin.partial`, индивидуальный gain того же сеанса.
3. После окончания — независимый повторный разбор RAW, полная проверка SHA/границ/статусов, сверка 8 временных BIN по on-disk SHA и размерам.
4. Атомарное создание полного комплекта 8 BIN/TSXML, VALUES (60×585 в 30-с тестах), TABLE, TIMELINE, EXPORT_AUDIT.
5. Безопасная обработка неоконченного *конечного* кадра только при штатном окончании, полный RAW всегда сохраняется.
6. Автоматический системный часовой пояс ПК (флаг `-offset` для подмены при offline replay).
7. Новая `STAGE108_EXPORT_STATUS.json` со статусами и флагом `during_capture_bin_spool_verified`.
8. Обратная совместимость: CLI `-list-interfaces`, `-replay`, `-ip`, `-local-ip`, `-approve`, `-seconds`, `-max-mb`; новый `-export=false` отключает автоматическую запись BIN.
9. Стабильная v0.3.40 и отдельные R5.1 / Stage107 исходники не изменялись.
