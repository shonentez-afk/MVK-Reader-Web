MVK Reader Web — Native R6.1 / Stage 108
======================================
29 октября 2026. Исследовательская Windows x64 программа.

ВАЖНО: Не подменяйте ею основную стабильную MVK Reader Web v0.3.40.
Испытание на работающем оборудовании только с разрешения ответственного.

БЫСТРЫЙ СТАРТ НА WINDOWS (никаких BAT, Python, Go не требуется)
1. Распакуйте ZIP полностью в отдельную папку.
2. Дважды щёлкните MVK_Native_R6_1_Stage108_Windows_x64.exe.
3. Укажите реальный IPv4 прибора МВК01 (порт строго TCP/10230).
4. Укажите время, для первого опыта рекомендуется 30 секунд.
5. Выберите ПРАВИЛЬНЫЙ проводной интерфейс Ethernet из списка, проверьте его IP.
6. Прочтите предупреждение, подтвердите разрешение словом YES.
7. По возможности параллельно запишите Wireshark, Capture Filter: tcp port 10230.
8. После остановки ожидайте завершения проверки и формирования восьми BIN/TSXML.

Результаты по умолчанию:
  Документы/MVK10230_Tests/TEST_дата_время/
    incoming.raw                       <- полный необработанный поток без изменений
    frames.csv                         <- список кадров и отметки времени ПК
    summary.json, summary_ru.txt        <- диагностика TCP, ошибок и каналов
    MVK10230_TEST_RESULTS.zip          <- диагностический архив R5.1
    STAGE108_EXPORT_STATUS.json        <- итог проверки и публикации
    BIN_TSXML_VALUES_TABLE_RECONSTRUCTED/
       8 файлов .bin                   <- физическое ускорение, float32 LE
       8 файлов .bin.tsxml             <- метаданные каналов, CP1251
       VALUES_ALL_ADC_RECONSTRUCTED.csv <- 60 строк, 585 колонок в испытании 30 c
       TABLE_LAST_AUX_RECONSTRUCTED.csv
       EXPORT_AUDIT.json, TIMELINE.json, README_RU.txt

Во время сетевой записи в скрытой служебной папке временно создаются
калиброванные ADC*.bin.partial. После остановки приборного потока программа
независимо пересчитывает весь оригинальный RAW, сравнивает исходные SHA256,
побайтовую структуру и SHA256 каждого BIN, затем публикует готовую папку.
Неисправный/неполный файл никогда не выдаётся за законченный результат.

Если STAGE108_EXPORT_STATUS.json показывает FAILED_CLOSED или REFUSED,
готовой директории BIN нет. Файлы incoming.raw и исходная диагностика сохранены.
Неполный последний сетевой кадр допускается исключить только при штатной
остановке, при этом его байты остаются в исходном incoming.raw.

ОТЛИЧИЕ ОТ R5.1: никаких команд прибору НЕ добавлено. TCP Connect -> Read.
IP-адрес и Ethernet выбирает пользователь. Программа сама ничего не посылает.

РЕЖИМЫ КОМАНДНОЙ СТРОКИ (необязательные)
  MVK_Native_R6_1_Stage108_Windows_x64.exe -list-interfaces
  MVK_Native_R6_1_Stage108_Windows_x64.exe -ip <IPv4_MVK> -local-ip <IPv4_Ethernet_PC> -seconds 30 -approve
  MVK_Native_R6_1_Stage108_Windows_x64.exe -replay "C:\capture\incoming.raw" -out "D:\QA" -offset +07:00
  MVK_Native_R6_1_Stage108_Windows_x64.exe -export=false -ip <IPv4_MVK> -local-ip <IPv4_Ethernet_PC> -seconds 15 -approve

По умолчанию -export=true. Флаг -offset=auto использует текущий часовой пояс ПК.
Для повторного открытия чужой записи укажите фактический UTC offset исходного ПК.
Все экспортированные VALUES/TABLE представляют собой восстановленные таблицы
реальных AUX-регистров, а НЕ побайтно доказанные файлы оригинальной MVKView.

Windows EXE собран под x64, на реальном Windows его ещё необходимо проверить.
Безопасность: оригинальные производственные RAW и PCAPNG не публикуйте на GitHub.
