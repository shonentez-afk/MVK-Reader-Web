# mvk_tcp_reader_v2.py — сохранённый читатель МВК01 (Stage 40)

**Исходный проверенный файл:** `mvkview_reverse/stage40/mvk_tcp_reader_v2.py`, Stage 40 от 2026-10-28. Это отдельный исследовательский скрипт, **не часть production v0.3.40**.

## Назначение
Подключается к работающему прибору МВК01 по TCP/10230, **только читает данные**. Формирует кадры из произвольных TCP-чанков, декодирует восемь АЦП (каналы 0–7), два тахометра (8–9) и вложенные структурированные сообщения `0xFF800C0D`. При указании `--out` сохраняет float32 little-endian payload основных АЦП в отдельные `ADC1.bin` ... `ADC8.bin`.

## Запуск
```bash
python3 tools/research/mvk_tcp_reader_v2.py 192.168.0.30 --seconds 10
python3 tools/research/mvk_tcp_reader_v2.py 192.168.0.30 --seconds 10 --out mvk_capture
```
Заменить IP на реальный адрес прибора. Для работы нужен только Python 3, внешние пакеты не требуются. Команды настройки, калибровки, записи Flash и перезагрузки **не отправляются**.

## Что подтверждено
- TCP/10230; фрейминг: `T:u32le`, `L:u32le`, тело `L-8`; `8<=L<=131072`, `L%4==0`.
- 8 обычных каналов АЦП + 2 канала тахометра; значения сигналов — float32 LE.
- 5 допустимых значений `fs`: 512, 2048, 8192, 32768, 65536 Гц.
- В рамках **Stage 40** версия испытана **офлайн** на `83 первый(1).pcapng`: 42410 кадров, ошибок синхронизации 0, последние 816 байт — незаконченный кадр из-за конца записи.

## Границы применимости
- Подключение этого скрипта к реальному работающему прибору **не подтверждено**.
- Он не реализует повторное подключение, GUI, запись файлов для тахометров, весь расчёт спектра и интерпретацию всех служебных идентификаторов.
- При `--out` файлы `ADC*.bin` создаются заново — выбрать отдельную пустую папку, чтобы избежать перезаписи.
- Скрипт прекращает обработку при некорректном кадре; это не сетевой сервис промышленного уровня.
- Перед окончательным использованием проверить совместимость заголовков `fs` и форматов BIN на каждом поддерживаемом режиме.
