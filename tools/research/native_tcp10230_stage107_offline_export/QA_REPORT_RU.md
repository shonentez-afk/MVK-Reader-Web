# Stage107 QA — два реальных тридцатисекундных теста МВК01 №84

Дата: 2026-10-29.

**Входы:** 2× `incoming.raw` + соответствующие `frames.csv`, `summary.json` из Stage106. Входной архив Test1 — Native R5 1.0, Test2 — Native R5.1 1.1 с явной привязкой к Ethernet.

1. Исходный RAW: SHA256 повторно рассчитан и совпал с логом каждой тестовой программы. Каждый кадр проверен по манифесту `frames.csv` в исходном порядке.
2. Каждый из 16 BIN построен отдельно из соответствующего ADC payload (256 float32 на кадр) с учётом **индивидуального gain из регистра собственного сеанса**. Независимый Python/NumPy векторно пересчитал **31 448 064 отдельных float32-отсчёта** и сравнил битовую запись результата с BIN. **0 ошибок**.
3. Для каждого из 120 AUX-обновлений независимый парсер по исходным 4700-байтовым кадрам сформировал 70 численных полей × 8 каналов = **67 200** сравнений с экспортированным VALUES CSV (учтено штатное округление до четырёх значащих цифр). **0 ошибок**.
4. Итого **31 515 264** сравнений всех отсчётов и численных полей VALUES, **0 расхождений** (подробнее `QA_RUN1.json`, `QA_RUN2.json`). Это не доказательство полного совпадения с внутренним DSP, а проверка точности экспортирования записанного приборного stream.
5. TSXML: 16 файлов проходят XML-разбор, схема, DataLength, FrequencyPerChannel, Units и длительность синхронизированы с соответствующими BIN. Формат сверялся с 4 ранее полученными оригинальными TSXML из MVKView.
6. CSV: `sep=|`, кодировка CP1251, исходная последовательность из 73 названий параметров на каждый АЦП, 585 столбцов, 60 записей, сводный TABLE из 30 параметров каждого АЦП + тахометрических регистров.
7. Тесты Go 13/13 PASS: корректная синтетическая сессия; отсутствие/изменение gain; нулевой gain; NaN-отсчёт; разрыв последовательности; подменённый `frames.csv`; неверный SHA; обрезанный кадр; запрет перезаписи; структура TSXML и CP1251; структура VALUES/TABLE; недопустимый timezone offset; отсутствие network imports.
8. `go vet ./...`, `go test -race ./...` — PASS. `GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build` — PASS, создан PE32+ Windows x64 console EXE.

**Не доказано:** byte-for-byte оригинальный MVKView экспорт на тех же live-сессиях; GetValueText для статусов, формат пользовательских TABLE при реальном нажатии, полная синхронизация времени DSP с компьютером, случайные сетевые потери/переподключения в новых сеансах, Windows runtime. Восстановление алгоритмов фильтрации DSP ведётся в отдельной ветке по прошивке.

**Финальная приёмка Stage107 ограничена офлайном.** Не интегрировать напрямую в production v0.3.40 до сравнения с оригинальным MVKView.
