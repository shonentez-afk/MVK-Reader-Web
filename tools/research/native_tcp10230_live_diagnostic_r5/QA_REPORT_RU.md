# Stage 101 / Native R5 — подготовка первой Windows-диагностики TCP/10230

Дата: 2026-10-29. Базовые доказательства: оригинальный IDR `Projects.7z` и Native R3/Stage99, Native R4/Stage100, два ранее предоставленных PCAPNG. Контрольная программа написана заново на Go, не использует `mvk_tcp_reader_v2`.

## Выполнено

1. Независимый исполняемый файл PE32+ Windows x64 (Go без внешних библиотек). Только TCP connect/read и отключение. Отправка прикладных команд отсутствует. Пользователь отдельно вводит `YES` перед соединением.
2. Приём кадров АЦП 1052, TACH 284, произвольных корректных структурированных (включая AUX4700 4700 и снимок 32800), ID/ACK/DENIED; fail-closed на неизвестных границах, raw всегда пишется.
3. Извлечение спектров и 24 расчётных величин каждого типа, статусов и признаков готовности, мониторинг индексов АЦП, частот, NaN/Inf.
4. Автоматический локальный архив `MVK10230_TEST_RESULTS.zip`, вместе с `incoming.raw`, `frames.csv`, `chunks.csv`, `aux4700.jsonl`, `summary.json`, `summary_ru.txt`, `events.log`.
5. `go test` 8/8 PASS; `go vet` без ошибок; PE executable проверен `file`, SHA256 в `SHA256SUMS.txt`.

## Реальная офлайн-регрессия, не Live-подключение

| | «83 спектр» | «1111» |
|---|---:|---:|
| Тестовая длина непрерывного входного потока | 20 МиБ | 20 МиБ |
| Разобрано корректных кадров | 25 512 | 25 548 |
| AUX4700 | 18 | 18 |
| Полные снимки регистров 32800 | 1 | 0 |
| Ошибки разбора | 0 | 0 |
| Независимых точных сравнений AUX-полей | 16 704 | 16 704 |
| Хвост неполного кадра при искусственном обрезании по 20 МиБ | 188 байт | 908 байт |

Эти короткие фрагменты выбраны из настоящих захватов после офлайн-реконструкции с Native R3. Реальные сырые данные в выпуск **не включены** и в GitHub **не отправляются**. Так как срезы обрываются точно на 20 МиБ, незавершённый последний кадр ожидаем и отмечен.

Отдельный тест с фиктивным локальным TCP-сервером подтвердил два полученных кадра и отсутствие прикладных данных **от клиента к серверу**. Он не заменяет теста на промышленном оборудовании.

## Что ещё не подтверждено

- Совместимость этого конкретного PE на настоящей Windows-машине предприятия.
- Приём без исходящего сообщения на конкретном промышленном МВК01.
- Взаимодействие с уже запущенной MVKView и ограничения числа TCP-клиентов.
- Получение корректных меток времени самого прибора (в нынешнем отчёте используются локальные часы ПК).
- Совпадение исходного DSP на устройстве со сторонними расчётами.
- Безопасная и полная многоканальная запись оригинальных BIN/TSXML/VALUES/TABLE.

## Следующее действие оператора

15-секундная проба на разрешённом приборе, затем передача одного `MVK10230_TEST_RESULTS.zip` через приватный канал. На первом тесте не активировать команды установки частоты/записи/Flash.
