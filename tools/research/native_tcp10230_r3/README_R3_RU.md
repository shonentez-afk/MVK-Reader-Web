# MVK TCP/10230 Native R3 — проверенный автономный декодер

**Задача:** собственный обмен МВК, без зависимости от `mvk_tcp_reader_v2`.

## Выполнить все тесты

```bash
python -m unittest -v test_protocol test_r3
```

## Повторить анализ архивного PCAPNG (без сети)

```bash
python r3_replay.py /path/to/capture.pcapng --out r3_results.json
```

При конфликте повторно переданных байтов стандартная политика `reject` прерывает анализ. Для **только офлайн** исследования с пометкой риска:

```bash
python r3_replay.py /path/to/capture.pcapng --out r3_results.json --overlap-policy preserve_assembled
```

Никаких команд приборам не отправляется, сокеты не используются. Реальная сетевая сессия, авто-восстановление после отключения и запись файлов являются будущими этапами и не заявляются реализованными.

## Назначение файлов

- `protocol.py` — декодер основных кадров TCP/10230, регистров и параметров МВК;
- `tcp_r3.py` — PCAPNG/IPv4/TCP, сортировка и проверка диапазонов seq, восстановление после разрыва;
- `r3_replay.py` — независимая повторная проверка всех полей AUX4700;
- `test_protocol.py`, `test_r3.py` — самотесты;
- `STAGE99_R3_REPORT_RU.md` и `r3_*.json` — подтверждённые результаты двух записей.

**Ограничения:** обрабатываются pcapng Enhanced Packet Block с Ethernet IPv4/TCP; IP-фрагментация не восстанавливается, повреждения вызывают явную ошибку. TCP-сегменты разных сеансов с одинаковыми четырьмя адресными полями без явной информации о новом SYN нельзя смешивать — для таких захватов требуется дополнительная идентификация сеанса. Заявления о полноте DSP/управляющего рукопожатия не делаются.
