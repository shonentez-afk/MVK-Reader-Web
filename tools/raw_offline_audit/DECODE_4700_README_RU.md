# Офлайн-декодер кадров 4700 байт

Файлы: `decode_4700.py` и `test_decode_4700.py`. Работают с сохранёнными RAW, не открывают сокеты и не запускают Reader Web.

Запуск из папки `tools/raw_offline_audit`:

```cmd
py -3 decode_4700.py capture.raw --out summary.json
py -3 -m unittest test_decode_4700.py -v
```

Декодер выделяет восемь записей, массив из 43 значений, блоки СКЗ/пика/размаха и 32-битный статус. Соответствие физическим величинам предварительное, пока не завершена независимая метрологическая проверка. Сохранённые RAW и JSON производственного оборудования не размещать в репозитории.
