# АЦП6: временное сравнение с VALUES (offline)
Запуск из Windows CMD после установки numpy и scipy:
```cmd
python tools/adc6_values_alignment/compare.py "C:\\private\\capture.bin" "C:\\private\\VALUES.csv" --window 2 --first-values-offset -0.089
```
Режим: **offline only**. Прибор и сеть не используются; исходные файлы не изменяются.
Вход: BIN float32 LE (уже м/с²), VALUES cp1251, разделитель |, десятичная запятая.
Параметр `--first-values-offset` задаёт предполагаемое положение первого VALUES относительно начала BIN. -0.089 соответствует рабочей гипотезе начала BIN 10:34:14.000 при первом VALUES 10:34:13.911. Это **не** доказанная синхронизация.
Скрипт не подгоняет коэффициенты/границу фильтра; интегрирует PSD прямоугольным FFT с полуоткрытой полосой [10,F).
Результат: число пригодных окон, медианы BIN и VALUES, медианное построчное отношение и корреляция. Отчёт исходных измерений: `docs/STAGE13_ADC6_VALUES_TIME_ALIGNMENT_20261027_RU.md`.
